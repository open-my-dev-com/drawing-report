# 용어 사전

> 같은 대상을 서로 다른 이름으로 부르지 않기 위한 목록입니다(`CLAUDE.md`의 `언어` 절).
> **새 개념의 이름을 정하기 전에 이 파일을 먼저 확인합니다.** 기존 용어와 겹치거나 혼동하기 쉬운
> 이름은 사용하지 않습니다.

## 혼동하기 쉬운 용어

| 우리말 | 가리키는 것 | 쓰지 말 것 |
|---|---|---|
| **그리드** | 요소 `grid`입니다. 고정된 표와 반복 목록을 하나의 구조로 다루며, 표를 나타내는 요소는 그리드 하나뿐입니다(ADR-037). | ~~격자~~ · ~~고정 그리드~~ · ~~동적 표~~ |
| **격자** | 캔버스에 표시하는 모눈입니다. 툴바의 `격자` 버튼으로 간격과 색을 정하며, 요소를 이동할 때 위치를 맞추는 기준입니다(F-20, 화면 전용). | ~~그리드~~ |
| **눈금자** | 용지 위쪽과 왼쪽에 표시하는 mm 단위 자입니다. 10mm마다 숫자, 5mm마다 눈금을 표시합니다(F-20). | ~~자·룰러~~ |
| **병합** | 양식에 고정된 셀 병합입니다. 그리드 셀의 `rowSpan`과 `colSpan`으로 나타냅니다. | ~~머지~~ |
| **데이터 자동 병합** | 항목 구간에서 앞 항목과 값이 같을 때 셀을 합치는 기능입니다. 열마다 `autoMerge`로 설정합니다(ADR-038). | ~~그룹핑~~ · ~~묶음~~ |

`헤더`, `페이지`처럼 한국 개발자가 일반적으로 사용하는 용어는 그대로 사용합니다.
(`CLAUDE.md`의 `언어` 절). `머리행`, `쪽`처럼 임의로 바꾼 표현은 사용하지 않습니다.

이전 이름인 `고정 그리드`(`fixedGrid`)와 `동적 표`(`dynamicTable`)는 공개 전 개발 단계에서만
사용했으며 현재 형식(0.1.0)에는 없습니다. 새 문서와 주석에는 사용하지 않고, 개발 이력을 설명할
때만 이전 이름임을 밝힙니다.

`병합`과 `데이터 자동 병합`은 서로 다른 기능입니다. 병합 범위는 양식에 저장되어 데이터와 관계없이
항상 같지만, 데이터 자동 병합은 인접한 항목의 값이 같을 때만 적용됩니다. `그룹`은 이미
**요소 그룹화**(`group` 필드, ADR-032)를 뜻하므로 데이터 자동 병합을 가리킬 때 사용하지 않습니다.

`그리드` 요소와 캔버스 모눈인 `격자`는 서로 다른 대상입니다. 그리드는 파일에 저장되지만 격자는
화면에만 표시됩니다. 한쪽 문구를 수정할 때 다른 쪽까지 함께 바꾸지 않습니다.

## 그 밖의 고정 용어

| 우리말 | 가리키는 것 |
|---|---|
| **양식** | `kind: 'template'`인 값 입력 전의 틀입니다. |
| **전표** | `kind: 'voucher'`인 값이 입력된 문서입니다. |
| **키** | 파라미터나 페이지를 파일·수식·외부 연계에서 식별하는 이름(`key`)입니다. 화면에 표시할 문장이 아니라 데이터 식별자입니다. |
| **표시 이름** | 파라미터를 작성 폼과 디자이너 화면에 표시할 이름(`label`)입니다. 생략하면 키를 표시합니다. |
| **셀** | 그리드의 `cells[]` 항목입니다. 일반적으로 쓰이는 용어이므로 ~~칸~~으로 바꾸지 않습니다. |
| **셀 기본 테두리** | 셀에 개별 테두리 설정이 없을 때 적용하는 그리드의 공통값(`cellBorder*`)입니다. |
| **셀 테두리** | 셀 하나에 지정하여 셀 기본 테두리를 덮어쓰는 값(`cells[].border*`)입니다. |
| **그리드 테두리** | 셀 경계선과 별도로 그리드 전체를 감싸는 선(`outline*`)입니다. ~~외곽 테두리~~와 ~~그리드 외곽선~~은 사용하지 않습니다. |
| **직접 입력** | 셀이나 요소에 직접 입력한 글(`content`)입니다. 파라미터·수식과 함께 세 가지 값 입력 방식을 구성합니다. ~~고정 문구~~는 이전 이름입니다. |
| **파라미터** | 전표 `values`의 키입니다. 저장 이름인 `key`와 표시 이름인 `label`로 구성됩니다(ADR-032/047). 목록 종류에는 항목의 **하위 필드**(`fields`)가 있습니다. 양식 본문에서는 `parameters[]`로 정의하고, 요소·셀·반복 설정에서는 `parameter`로 키를 참조합니다(ADR-051). ~~바인딩~~과 ~~`binding`~~은 이전 이름과 키이므로 사용하지 않습니다. |
| **행 구간** | 반복 그리드의 원본 행에 출력 역할을 지정한 범위(`repeat.bands[]`, ADR-065)입니다. 역할은 `placement` 값 일곱 가지로 구분합니다. ~~반복 구간~~은 이전 모델의 이름이므로 새 문서와 주석에 사용하지 않습니다. |
| **항목 구간** | `placement: 'item'`인 행 구간입니다. 데이터 항목마다 복제되며 그리드마다 하나만 둡니다. |
| **페이지 방식** | 반복 그리드의 페이지 배치 방식(`pagination`)입니다. **자동 확장**(`auto`)과 **고정 페이지**(`fixed`)가 있습니다. |
| **흐름 영역** | 반복 그리드가 항목을 채우는 페이지의 세로 범위(`flowArea`)입니다. 기본값은 용지의 여백 경계입니다. |
| **출력 페이지** | 양식 페이지 하나가 페이지 계획을 통해 만드는 실제 PDF 페이지입니다. 양식 페이지와 구분합니다. |
| **항목 인스턴스** | 출력 페이지에 배치된 항목 구간 하나입니다. 데이터가 없는 자리는 **빈 항목**이라고 합니다. |
| **헤더** | 표나 그리드의 제목 행입니다. 일반적으로 `page-start` 행 구간으로 구성합니다. ~~머리행~~은 사용하지 않습니다. |
| **페이지** | 양식이나 PDF의 한 장(`pages`)입니다. ~~쪽~~은 사용하지 않고 `페이지 분할`, `페이지마다`, `한 페이지에`처럼 씁니다. |
| **발행** | 무결성 정보를 기록한 뒤 전표를 잠그는 작업입니다(SPEC §7.1). |
| **조건부 서식** | 값에 따라 색을 바꾸는 규칙(`conditionalFormats`, ADR-062)입니다. 규칙에 사용하는 수식은 **조건식**이라고 합니다. |
| **편집 대상** | 수식 모달을 열 때 정하는 저장 위치(`FormulaTarget`, ADR-068)입니다. 필드·바코드·그리드 셀·조건부 서식 규칙이 해당합니다. |
| **계산 문맥** | 수식을 평가할 때 전달하는 값과 예약 참조의 모음입니다. 캔버스·인라인 검사·수식 모달이 같은 계산 문맥을 사용합니다(ADR-068). |
| **샘플 항목** | 반복 그리드를 미리 계산할 때 사용하는 `sampleValues`의 항목 하나입니다. `샘플 데이터`는 파라미터별 값 전체를 뜻하므로 구분합니다. ~~견본 항목~~은 사용하지 않습니다. `견본`은 색상 견본이나 바코드 견본처럼 화면에 표시하는 예시를 가리킵니다. |

## 용어를 바꿀 때

`CLAUDE.md`의 단일 원천 규칙에 따라 다음 대상을 **한 번에 모두** 변경합니다.

1. 문서: 루트 `README*` · `docs/SPEC.md` · `DECISIONS.md` · `REQUIREMENTS.md` · `TEST-PLAN.md` ·
   `ARCHITECTURE.md` · `RELEASE.md` · `ROADMAP.md` · `docs/guide/*`(영어·한국어·일본어 모두)
2. 코드 주석 (TSDoc·`//` 둘 다)
3. **사용자 대면 오류 메시지**: `SlipRenderError`·`SlipParseError` 등에 담기는 문구
4. UI·MCP 문구: `packages/elements/src/strings.ts`와 `packages/mcp/src/storage.ts`의 `MCP_TEXT`
   한국어·영어·일본어 사전
5. 테스트 설명 (`describe`·`it` 제목)
6. 커밋 메시지·PR 제목·본문

변경 후 `rg -n "<이전 용어>"`로 남은 사용처가 없는지 확인합니다. 위 표의 `격자`처럼 다른 뜻으로
사용해 남겨야 하는 경우에는 이 파일에 그 이유를 기록합니다.

## 문서 세 언어 유지(ADR-042·066)

가이드(`docs/guide/*`)와 저장소 `README`는 **영어·한국어·일본어 세 언어**로 관리합니다.
접미사가 없는 `*.md`가 기준인 영어판이고, `*.ko.md`가 한국어판, `*.ja.md`가 일본어판입니다.
문안은 영어판에서 확정한 뒤 나머지 두 언어에 같은 내용을 반영합니다. 한 언어의 문서를 수정하거나
새 가이드를 추가할 때는 세 언어 문서를 함께 갱신합니다.

설계 문서(`docs/SPEC.md`·`DECISIONS.md`·`REQUIREMENTS.md`·`ROADMAP.md`·`ARCHITECTURE.md`·
`OPEN-QUESTIONS.md`·`TECH-RESEARCH.md`)와 규칙 문서는 한국어판만 둡니다.

## 일본어 용어 대응 (ADR-042)

다음 표는 일본어 사전과 문서에서 혼동하기 쉬운 한국어 용어의 대응입니다. 일본어 문구를 작성할 때
이 표를 따릅니다.

| 우리말 | 일본어 | 비고 |
|---|---|---|
| 그리드(요소) | グリッド | 표 요소 `grid` |
| 격자(캔버스 모눈) | 方眼 | 화면에서만 사용합니다. 그리드와 혼동할 수 있으므로 `グリッド`로 쓰지 않습니다. |
| 헤더 | ヘッダー | |
| 병합 | 結合 | 셀 결합(`rowSpan`·`colSpan`) |
| 양식(template) | テンプレート | `kind: 'template'` |
| 전표(voucher) | 伝票 | `kind: 'voucher'` |
| 발행 | 発行 | |
| 행 구간 | 行範囲 | `repeat.bands[]` |
| 항목 구간 | 項目範囲 | `placement: 'item'` |
| 흐름 영역 | フロー領域 | `flowArea` |
| 출력 페이지 | 出力ページ | |
| 자동 확장 / 고정 페이지 | 自動拡張 / 固定ページ | `pagination.mode` |
| 파라미터 | パラメータ | 전표 `values`의 키입니다. ~~バインディング~~은 사용하지 않습니다. |
| 조건부 서식 | 条件付き書式 | 조건식은 条件式 |
| 셀 기본 테두리 | セルの既定の枠線 | `cellBorder*` |
| 셀 테두리 | セルの枠線 | `cells[].border*` |
| 그리드 테두리 | グリッドの枠線 | `outline*` |
