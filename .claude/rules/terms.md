# 용어 사전

> 같은 것을 두 이름으로 부르지 않기 위한 목록이다 (CLAUDE.md 「언어」).
> **새 개념에 이름을 붙이기 전에 이 파일부터 본다.** 여기 있는 말과 겹치거나 헷갈릴 이름은 쓰지 않는다.

## 헷갈리기 쉬운 것 — 반드시 구분해서 쓴다

| 우리말 | 가리키는 것 | 쓰지 말 것 |
|---|---|---|
| **그리드** | 요소 `grid` — 고정 틀과 반복 목록을 하나로 다루는 표. 표 요소는 이것 하나뿐이다 (ADR-037) | ~~격자~~ · ~~고정 그리드~~ · ~~동적 표~~ |
| **격자** | 캔버스에 까는 모눈 — 툴바 `격자` 버튼의 간격·색, 요소를 옮길 때 맞아떨어지는 대상 (F-20, 화면 전용) | ~~그리드~~ |
| **눈금자** | 용지 위·왼쪽의 mm 자 — 10mm마다 숫자, 5mm마다 눈금 (F-20) | ~~자·룰러~~ |
| **병합** | 양식에 고정된 셀 합치기 — 그리드 셀의 `rowSpan`·`colSpan` | ~~머지~~ |
| **데이터 자동 병합** | 항목 구간에서 앞 벌과 **값이 같아서** 합쳐지는 것 — 열별로 켠다 (`autoMerge`, ADR-038) | ~~그룹핑~~ · ~~묶음~~ |

표기를 우리말로 순화하지 않는다 — `헤더`·`페이지`처럼 한국 개발자가 그대로 쓰는 말을 쓴다
(CLAUDE.md 「언어」). `머리행`·`쪽`처럼 풀어 쓴 말은 쓰지 않는다.

옛 이름 `고정 그리드`(`fixedGrid`)·`동적 표`(`dynamicTable`)는 공개 전 개발 단계에서만 쓰였고
지금 포맷(0.1.0)에는 없다 — 새 글에는 쓰지 않고, 개발 이력을 설명할 때만 "옛 ~"으로 적는다.

`병합`과 `데이터 자동 병합`도 **다른 것이다.** 앞은 양식에 박힌 숫자라 데이터와 무관하게 늘 같고,
뒤는 값이 같을 때만 그때그때 합쳐진다. `그룹`은 **요소 그룹화**(`group` 필드, ADR-032)에 이미 쓰고
있으므로 자동 병합을 가리키는 데 쓰지 않는다.

`그리드`(요소)와 `격자`(캔버스 모눈)는 **다른 것이다.** 파일에 저장되는 것은 그리드뿐이고,
격자는 화면에만 있다. 한쪽 문구를 고칠 때 다른 쪽을 함께 바꾸지 않는다.

## 그 밖의 고정 용어

| 우리말 | 가리키는 것 |
|---|---|
| **양식** | `kind: 'template'` — 값이 비어 있는 틀 |
| **전표** | `kind: 'voucher'` — 값이 채워진 문서 |
| **셀** | 그리드의 한 칸 — `cells[]`의 항목. 한국 개발자가 그대로 쓰는 말이라 ~~칸~~으로 풀어 쓰지 않는다 |
| **직접 입력** | 셀·요소에 사람이 그대로 적어 넣은 글 (`content`) — 파라미터·수식과 함께 값 소스 3종을 이룬다. ~~고정 문구~~는 옛 이름이다 |
| **파라미터** | 전표 `values`의 키. 물리명 `key` + 논리명 `label` (ADR-032/047). 목록 종류면 항목의 **하위 필드**(`fields`)를 갖는다. 정의부는 양식 본문의 `parameters[]`, 요소·셀·반복 설정이 가리키는 값 키는 `parameter`다(ADR-051). ~~바인딩~~·~~`binding`~~은 쓰지 않는다 — 옛 이름·옛 키다 |
| **행 구간** | 반복 그리드의 원본 행에 출력 역할을 부여한 범위 (`repeat.bands[]`, ADR-065). 역할은 placement 7종. ~~반복 구간~~은 옛 모델의 이름이라 새 글에는 쓰지 않는다 |
| **항목 구간** | `placement: 'item'`인 행 구간 — 데이터 항목마다 복제되는 부분. 그리드당 정확히 하나 |
| **페이지 방식** | 반복 그리드의 페이지 배치 방식 (`pagination`) — **자동 확장**(`auto`)과 **고정 페이지**(`fixed`) |
| **흐름 영역** | 반복 그리드가 항목을 채우는 페이지의 세로 범위 (`flowArea`, 기본은 용지 여백 경계) |
| **출력 페이지** | 양식 페이지 하나가 페이지 계획으로 만들어 내는 실제 PDF 페이지. 양식 페이지와 구분한다 |
| **항목 인스턴스** | 출력 페이지에 배치된 항목 구간 한 벌. 데이터가 없는 자리는 **빈 항목**이라 부른다 |
| **헤더** | 표·그리드의 제목 행. 보통 `page-start` 행 구간으로 구성한다. ~~머리행~~은 쓰지 않는다 |
| **페이지** | 양식·PDF의 한 장 (`pages`). ~~쪽~~은 쓰지 않는다 — 「페이지 분할」·「페이지마다」·「한 페이지에」 |
| **발행** | 무결성 기록 후 잠그는 것 (SPEC §7.1) |
| **조건부 서식** | 값에 따라 색을 바꾸는 규칙 (`conditionalFormats`, ADR-062). 규칙의 수식은 **조건식**이라 부른다 |
| **편집 대상** | 수식 모달이 열릴 때 확정하는 저장 위치 (`FormulaTarget`, ADR-068) — 필드·바코드·그리드 셀·조건부 서식 규칙 |
| **계산 문맥** | 수식을 평가할 때 넘기는 값과 예약 참조 묶음. 캔버스·인라인 검사·수식 모달이 같은 것을 쓴다 (ADR-068) |
| **샘플 항목** | 반복 그리드의 미리 계산에 쓰는 `sampleValues`의 항목 하나. `샘플 데이터`는 파라미터별 값 전체라 다른 말이다. ~~견본 항목~~은 쓰지 않는다 — `견본`은 색상 견본·바코드 견본처럼 화면에 보여 주는 표본을 가리킨다 |

## 용어를 바꿀 때

CLAUDE.md의 SSOT 규칙대로 **한 번에 전부** 바꾼다 — 일부만 바꾸지 않는다:

1. 문서 — `docs/SPEC.md` · `DECISIONS.md` · `REQUIREMENTS.md` · `ROADMAP.md` · `docs/guide/*`(영어·한국어·일본어 모두)
2. 코드 주석 (TSDoc·`//` 둘 다)
3. **사용자 대면 오류 메시지** — `SlipRenderError`·`SlipParseError` 등에 담기는 문구
4. UI 문구 — `packages/elements/src/strings.ts`의 한국어·영어·일본어 사전
5. 테스트 설명 (`describe`·`it` 제목)
6. 커밋 메시지·PR 제목·본문

바꾼 뒤 `grep -rn "<옛 용어>"`로 잔존 0건을 확인한다. 남겨야 할 것이 있으면
(위 표의 `격자`처럼 다른 뜻으로 쓰이는 경우) 이 파일에 그 이유를 적는다.

## 문서 3벌 유지 (ADR-042·066)

가이드(`docs/guide/*`)와 리포 `README`는 **영어·한국어·일본어 3벌**이다 —
접미사가 없는 `*.md`가 **영어판(기준)**, `*.ko.md`가 한국어판, `*.ja.md`가 일본어판이다.
문안은 영어판에서 확정하고 나머지 두 벌을 맞춘다. 한 벌을 고치면 나머지 두 벌도 같은 자리에서
함께 고친다 — 한 벌만 바뀌면 어긋난다. 새 가이드를 추가할 때도 세 언어의 문서를 함께 작성한다.

설계 문서(`docs/SPEC.md`·`DECISIONS.md`·`REQUIREMENTS.md`·`ROADMAP.md`·`ARCHITECTURE.md`·
`OPEN-QUESTIONS.md`·`TECH-RESEARCH.md`)와 이 규칙 문서들은 한국어 한 벌만 둔다.

## 일본어 용어 대응 (ADR-042)

일본어 사전·문서에서 헷갈리기 쉬운 우리말 용어의 대응이다. 새 일본어 문구를 쓸 때 맞춘다.

| 우리말 | 일본어 | 비고 |
|---|---|---|
| 그리드(요소) | グリッド | 표 요소 `grid` |
| 격자(캔버스 모눈) | 方眼 | 화면 전용. `グリッド`로 쓰지 않는다 — 그리드와 겹친다 |
| 헤더 | ヘッダー | |
| 병합 | 結合 | 셀 결합(`rowSpan`·`colSpan`) |
| 양식(template) | テンプレート | `kind: 'template'` |
| 전표(voucher) | 伝票 | `kind: 'voucher'` |
| 발행 | 発行 | |
| 행 구간 | 行範囲 | `repeat.bands[]` |
| 항목 구간 | 項目範囲 | `placement: 'item'` |
| 흐름 영역 | フロー領域 | `flowArea` |
| 출력 페이지 | 出力ページ | |
| 자동 확장 / 고정 페이지 | 自動拡張 / 固定ページ | `pagination.mode` |
| 파라미터 | パラメータ | 전표 `values`의 키. ~~バインディング~~은 쓰지 않는다 |
| 조건부 서식 | 条件付き書式 | 조건식은 条件式 |
