# 수식 함수 참조

[English](formula.en.md)

SlipKit 수식 엔진의 내장 함수 29종입니다. 등록되지 않은 함수 이름은 파싱 단계에서 거부됩니다.

---

## 집계

| 함수 | 사용법 | 설명 |
|---|---|---|
| `SUM` | `SUM(값, ...)` | 합계. 범위(`items.amount`)도 가능 |
| `AVG` | `AVG(값, ...)` | 평균. 값이 없으면 오류 |
| `COUNT` | `COUNT(값, ...)` | 빈 값(null·빈 문자열)을 제외한 항목 수 |
| `MIN` | `MIN(값, ...)` | 최솟값. 값이 없으면 0 |
| `MAX` | `MAX(값, ...)` | 최댓값. 값이 없으면 0 |

```
SUM(items.amount)                → 항목별 금액의 합
SUM(items.amount, shippingFee)   → 항목 합계 + 배송비
AVG(items.unitPrice)             → 단가 평균
COUNT(items.productName)         → 상품명이 있는 행 수
MIN(price1, price2, price3)      → 세 값 중 최솟값
```

## 조건부 집계

| 함수 | 사용법 | 설명 |
|---|---|---|
| `SUMIF` | `SUMIF(조건범위, 조건, [합계범위])` | 조건에 맞는 항목의 합. 합계범위를 생략하면 조건범위를 합산 |
| `COUNTIF` | `COUNTIF(범위, 조건)` | 조건에 맞는 항목 수 |

조건은 엑셀 스타일 문자열을 지원합니다: `">=10"`, `"<>완료"`, `"지급"` 등.

```
SUMIF(items.category, "식품", items.amount)   → 식품 카테고리 합계
COUNTIF(items.status, "완료")                  → 완료 상태 행 수
```

## 산술

| 함수 | 사용법 | 설명 |
|---|---|---|
| `ROUND` | `ROUND(수, [자릿수])` | 반올림. 자릿수 생략 시 정수로 |
| `FLOOR` | `FLOOR(수, [자릿수])` | 내림 |
| `CEIL` | `CEIL(수, [자릿수])` | 올림 |
| `ABS` | `ABS(수)` | 절댓값 |

```
ROUND(1234.567, 2)    → 1234.57
FLOOR(VAT(10000), 0)  → 1000 (부가세 절사)
```

## 문자열

| 함수 | 사용법 | 설명 |
|---|---|---|
| `CONCAT` | `CONCAT(값, ...)` | 문자열 이어붙이기 |
| `LEFT` | `LEFT(문자열, [글자수])` | 왼쪽부터 자르기. 글자수 생략 시 1 |
| `RIGHT` | `RIGHT(문자열, [글자수])` | 오른쪽부터 자르기. 글자수 생략 시 1 |
| `MID` | `MID(문자열, 시작, 길이)` | 시작 위치(1부터)에서 길이만큼 자르기 |
| `REPLACE` | `REPLACE(문자열, 찾기, 바꾸기)` | 모든 일치를 치환 |
| `TRIM` | `TRIM(문자열)` | 앞뒤 공백 제거 |
| `UPPER` | `UPPER(문자열)` | 대문자로 |
| `LOWER` | `LOWER(문자열)` | 소문자로 |

```
CONCAT(businessName, " 귀중")       → "ABC상사 귀중"
LEFT("2026-08-21", 4)                → "2026"
MID("123-45-67890", 5, 2)           → "45"
REPLACE("견적서", "견적", "거래명세") → "거래명세서"
```

## 조건

| 함수 | 사용법 | 설명 |
|---|---|---|
| `IF` | `IF(조건, 참값, 거짓값)` | 조건이 참이면 참값, 아니면 거짓값. 지연 평가 |
| `AND` | `AND(조건, ...)` | 모두 참이면 참. 지연 평가 (거짓을 만나면 나머지 평가 안 함) |
| `OR` | `OR(조건, ...)` | 하나라도 참이면 참. 지연 평가 (참을 만나면 나머지 평가 안 함) |

```
IF(total >= 100000, "대량", "일반")
IF(AND(quantity > 0, unitPrice > 0), quantity * unitPrice, 0)
```

## 포맷

| 함수 | 사용법 | 설명 |
|---|---|---|
| `FORMAT_NUMBER` | `FORMAT_NUMBER(수, [소수자릿수])` | 자릿수 구분 표기. 로케일에 따라 표기가 바뀜 |
| `FORMAT_DATE` | `FORMAT_DATE(날짜, [패턴])` | 날짜 포맷. 패턴 생략 시 `YYYY-MM-DD` |
| `NUMBER_TO_KOREAN` | `NUMBER_TO_KOREAN(정수)` | 금액 한글 표기 (위변조 방지용) |

```
FORMAT_NUMBER(1234567)            → "1,234,567" (ko-KR)
FORMAT_NUMBER(0.123, 2)           → "0.12"
FORMAT_DATE("2026-08-21", "YYYY년 MM월 DD일")  → "2026년 08월 21일"
NUMBER_TO_KOREAN(110)             → "일백일십"
```

`FORMAT_DATE` 패턴 토큰: `YYYY` `YY` `MM` `M` `DD` `D` `HH` `mm` `ss`

## 날짜

| 함수 | 사용법 | 설명 |
|---|---|---|
| `TODAY` | `TODAY()` | 오늘 날짜 (`YYYY-MM-DD`) |
| `DATE_ADD` | `DATE_ADD(날짜, 증감, [단위])` | 날짜 더하기. 단위: `"days"` (기본) / `"months"` / `"years"` |
| `DATE_DIFF` | `DATE_DIFF(시작, 끝, [단위])` | 날짜 차이. 단위: `"days"` (기본) / `"months"` / `"years"` |

날짜는 ISO 형식 문자열(`YYYY-MM-DD`)을 씁니다.

```
TODAY()                                    → "2026-08-21"
DATE_ADD("2026-08-21", 30)                 → "2026-09-20"
DATE_ADD("2026-01-15", 2, "months")        → "2026-03-15"
DATE_DIFF("2026-01-01", "2026-08-21")      → 232
```

## 세무

| 함수 | 사용법 | 설명 |
|---|---|---|
| `VAT` | `VAT(공급가액, [세율])` | 부가세액 계산. 세율 생략 시 10% |

절사·반올림은 `ROUND`/`FLOOR`와 함께 씁니다.

```
VAT(10000)                → 1000
VAT(10000, 8)             → 800
FLOOR(VAT(12345), 0)      → 1234  (원 미만 절사)
```

## 수식 작성 규칙

- **문자열**: 큰따옴표로 감쌉니다. 문자열 안에 따옴표를 넣으려면 두 번 씁니다 (`""`)
- **범위 참조**: `바인딩명.열키` 형태로 동적 표의 열 데이터를 가리킵니다 (예: `items.amount`)
- **사칙연산**: `+` `-` `*` `/` 를 쓸 수 있고, 괄호 `()` 로 우선순위를 정합니다
- **비교**: `=` `<>` `<` `>` `<=` `>=`
