# 数式関数リファレンス

[한국어](formula.md) · [English](formula.en.md)

SlipKit 数式エンジンの組み込み関数 32 種です。登録されていない関数名はパース段階で拒否されます。

デザイナーの数式編集ウィンドウでは、パラメータチップと関数一覧を見ながら数式を作り、結果をすぐ確認できます。

![デザイナーの数式編集ウィンドウ](images/ja/formula.png)

> デザイナーで数式を扱う流れは **[フォームデザイナー利用ガイド §5](designer.ja.md#5-数式)** を参照してください。

## 集計

| 関数 | 使い方 | 説明 |
|---|---|---|
| `SUM` | `SUM(値, ...)` | 合計。範囲参照（`items.amount`）も可能 |
| `AVG` | `AVG(値, ...)` | 平均。値がない場合はエラー |
| `COUNT` | `COUNT(値, ...)` | 空の値（null・空文字列）を除いた項目数 |
| `MIN` | `MIN(値, ...)` | 最小値。値がない場合は 0 |
| `MAX` | `MAX(値, ...)` | 最大値。値がない場合は 0 |

```
SUM(items.amount)                → 項目ごとの金額の合計
SUM(items.amount, shippingFee)   → 項目合計 + 送料
AVG(items.unitPrice)             → 単価の平均
COUNT(items.productName)         → 商品名がある行数
MIN(price1, price2, price3)      → 3 つの値のうち最小値
```

## 条件付き集計

| 関数 | 使い方 | 説明 |
|---|---|---|
| `SUMIF` | `SUMIF(条件範囲, 条件, [合計範囲])` | 条件に合う項目の合計。合計範囲を省略すると条件範囲を合算 |
| `COUNTIF` | `COUNTIF(範囲, 条件)` | 条件に合う項目数 |

条件は Excel スタイルの文字列をサポートします。

| 条件 | 意味 | 備考 |
|---|---|---|
| `"食品"` | 値が "食品" と等しい | `=` は省略可能（値だけを書くと一致比較） |
| `"=食品"` | 値が "食品" と等しい | 上と同じ |
| `"<>完了"` | "完了" ではないもの | 不一致 |
| `">=10"` | 10 以上 | 数値比較 |
| `"<1000"` | 1000 未満 | 数値比較 |

```
SUMIF(items.category, "식품", items.amount)    → "식품" カテゴリの合計
SUMIF(items.amount, ">=10000")                 → 1 万以上の金額の合計
COUNTIF(items.status, "완료")                   → "완료" 状態の行数
COUNTIF(items.status, "<>완료")                 → "완료" ではない行数
```

## 算術

| 関数 | 使い方 | 説明 |
|---|---|---|
| `ROUND` | `ROUND(数, [桁数])` | 四捨五入。桁数を省略すると整数に |
| `FLOOR` | `FLOOR(数, [桁数])` | 切り捨て |
| `CEIL` | `CEIL(数, [桁数])` | 切り上げ |
| `ABS` | `ABS(数)` | 絶対値 |

```
ROUND(1234.567, 2)    → 1234.57
FLOOR(VAT(10000), 0)  → 1000 (消費税の切り捨て)
```

## 文字列

| 関数 | 使い方 | 説明 |
|---|---|---|
| `CONCAT` | `CONCAT(値, ...)` | 文字列の連結 |
| `LEFT` | `LEFT(文字列, [文字数])` | 左から切り出し。文字数を省略すると 1 |
| `RIGHT` | `RIGHT(文字列, [文字数])` | 右から切り出し。文字数を省略すると 1 |
| `MID` | `MID(文字列, 開始, 長さ)` | 開始位置（1 から）から長さ分だけ切り出し |
| `REPLACE` | `REPLACE(文字列, 検索, 置換)` | すべての一致を置換 |
| `TRIM` | `TRIM(文字列)` | 前後の空白を除去 |
| `UPPER` | `UPPER(文字列)` | 大文字に |
| `LOWER` | `LOWER(文字列)` | 小文字に |

```
CONCAT(businessName, " 귀중")       → "ABC상사 귀중"
LEFT("2026-08-21", 4)                → "2026"
MID("123-45-67890", 5, 2)           → "45"
REPLACE("견적서", "견적", "거래명세") → "거래명세서"
```

## 条件

| 関数 | 使い方 | 説明 |
|---|---|---|
| `IF` | `IF(条件, 真の値, 偽の値)` | 条件が真なら真の値、そうでなければ偽の値。遅延評価 |
| `AND` | `AND(条件, ...)` | すべて真なら真。遅延評価（偽に出会うと残りは評価しない） |
| `OR` | `OR(条件, ...)` | いずれか 1 つでも真なら真。遅延評価（真に出会うと残りは評価しない） |

```
IF(total >= 100000, "대량", "일반")
IF(AND(quantity > 0, unitPrice > 0), quantity * unitPrice, 0)
```

## フォーマット

| 関数 | 使い方 | 説明 |
|---|---|---|
| `FORMAT_NUMBER` | `FORMAT_NUMBER(数, [小数桁数])` | 桁区切り表記。ロケールによって表記が変わる |
| `FORMAT_DATE` | `FORMAT_DATE(日付, [パターン])` | 日付フォーマット。パターンを省略すると `YYYY-MM-DD` |
| `NUMBER_TO_KOREAN` | `NUMBER_TO_KOREAN(整数)` | 金額のハングル表記（改ざん防止用） |

```
FORMAT_NUMBER(1234567)            → "1,234,567" (ko-KR)
FORMAT_NUMBER(0.123, 2)           → "0.12"
FORMAT_DATE("2026-08-21", "YYYY년 MM월 DD일")  → "2026년 08월 21일"
NUMBER_TO_KOREAN(110)             → "일백일십"
```

`FORMAT_DATE` パターントークン: `YYYY` `YY` `MM` `M` `DD` `D` `HH` `mm` `ss`

## 日付

| 関数 | 使い方 | 説明 |
|---|---|---|
| `TODAY` | `TODAY()` | 今日の日付（`YYYY-MM-DD`） |
| `DATE_ADD` | `DATE_ADD(日付, 増減, [単位])` | 日付の加算。単位: `"days"`（既定）/ `"months"` / `"years"` |
| `DATE_DIFF` | `DATE_DIFF(開始, 終了, [単位])` | 日付の差。単位: `"days"`（既定）/ `"months"` / `"years"` |

日付は ISO 形式の文字列（`YYYY-MM-DD`）を使います。

```
TODAY()                                    → "2026-08-21"
DATE_ADD("2026-08-21", 30)                 → "2026-09-20"
DATE_ADD("2026-01-15", 2, "months")        → "2026-03-15"
DATE_DIFF("2026-01-01", "2026-08-21")      → 232
```

## 税務

| 関数 | 使い方 | 説明 |
|---|---|---|
| `VAT` | `VAT(供給価額, [税率])` | 消費税額の計算。税率を省略すると 10% |

切り捨て・四捨五入は `ROUND`/`FLOOR` と組み合わせて使います。

```
VAT(10000)                → 1000
VAT(10000, 8)             → 800
FLOOR(VAT(12345), 0)      → 1234  (円未満の切り捨て)
```

## 型変換

| 関数 | 使い方 | 説明 |
|---|---|---|
| `TO_NUMBER` | `TO_NUMBER(値)` | 文字・論理値を数値に。空・空文字は 0 |
| `TO_STRING` | `TO_STRING(値)` | 数値・論理値を文字に |
| `TO_DATE` | `TO_DATE(値)` | 日付文字列を検証して `YYYY-MM-DD` に正規化 |

数値が必要な場所（四則演算・`SUM` など）では、文字を**自動で数値に変換しません** — `TO_NUMBER` で囲みます。

```
TO_NUMBER("1500") * 2     → 3000
TO_STRING(3) = "3"        → TRUE
TO_DATE("2026-01-05T09:00:00Z") → "2026-01-05"
```

## 数式の記述ルール

- **文字列**: ダブルクォートで囲みます。文字列の中にクォートを入れるには 2 回書きます（`""`）
- **範囲参照**: `バインディング名.フィールド名` の形で、グリッドの繰り返し範囲の項目フィールドを指します（例: `items.amount`）
- **四則演算**: `+` `-` `*` `/` が使え、括弧 `()` で優先順位を決めます
- **比較**: `=` `<>` `<` `>` `<=` `>=` — **同じ型どうし**のみ比較します（`3 = "3"` は偽）
- **型**: 数値の場所には数値のみ。未入力・空は 0 とみなします。文字→数値は `TO_NUMBER` で明示します（数値→文字は自動）
