# 로드맵 / 세션 인수인계

최종 갱신: 2026-08-22 (**G 묶음 재편** — 고정 그리드와 동적 표를 그리드 `grid` 하나로 합치고 반복 구간을 두기로
확정(ADR-037). 하부 엔진의 표는 열별 제어가 정렬 하나뿐이고 페이지 분할도 스키마 타입 이름으로만 켜져 확장할 수
없음을 직접 확인한 결과다. G-23(렌더러 교체)·G-28(셀 병합)이 이 작업에 흡수됐다.
1·2·3단계 전부 완료 — 포맷 0.4.0에서 옛 두 요소가 사라지고 표 요소는 그리드 하나가 됐다(요소 8종).
이어서 G-25 사이드바 펼침 표시 완료. **G 묶음을 단계로 다시 묶었다** — 포맷 0.5.0을 한 판으로 먼저 올리고
(24번), 그 필드를 쓰는 화면을 2단계로 나눴다. 24번에 뭉쳐 있던 화면 항목은 44~47번으로 떼어냈고
완료·흡수 항목은 뒤쪽 기록으로 옮겼다. **G-29를 「표 중첩」에서 「데이터 자동 병합」으로 교체**(ADR-038),
**G-26 VLOOKUP류 함수는 제외**(ADR-039). **포맷 0.5.0 완료** — 글자 조판·페이지 이름과 번호·변동 이미지·
바인딩 값 종류·그리드 열 자동 병합·바코드 요소(요소 9종). 이어 G-45 글자 조판 UI 완료 — 0.5.0 조판
필드를 속성 패널에서 고르고 캔버스·PDF를 맞췄다. G-47 변동 이미지 UI 완료 — 이미지 요소를 고정·변동으로
고르고 작성폼·샘플에 이미지 입력을 붙였다. 이전 갱신: 2026-08-21 — 피드백을 **F 묶음**으로 신설해 E보다 먼저 처리 중. F-17 요소·바인딩 분리 완료, F-18 패널 표시 정리 완료, F-19 표 너비 국소 변경 완료, F-20 캔버스 눈금자·격자 완료, F-21 수식 모달 보조 완료, F-22 React·Vue 데모 완료 — **F 묶음 종료**. 사용 가이드를 한국어·영어 2종으로 정리하고, 확정해 놓고 아직
만들지 않은 항목 4건을 점검해 G 묶음에 등재. 화면을 보며 나온 항목(표 안쪽 펼쳐 보기·펼침 표시·용지 크기
주입·바코드 요소·툴바 정리·페이지 목록)도 G에 추가. G 마지막에 일본어 대응. G-32 속성 패널 위치·크기 · G-35 페이지 목록 · G-36 이미지 업로드 완료)

- **국제화 반영 완료**: 수식 포맷 함수 로케일 지정(`RenderOptions.locale`, ADR-013) + UI 영어 사전·`locale` 전환(뷰어·디자이너·래퍼·저장소 어댑터, 기본 한국어, ADR-028)

- **변동 이미지 UI 완료** (2026-08-22, G-47): 0.5.0이 만든 이미지 `binding`을 화면에 붙였다 —
  전표마다 다른 이미지(도장·서명·로고)를 넣는다. 디자이너에서 이미지 요소를 고정(src)·변동(binding)
  중에 고르고, 변동이면 값 키를 고르거나 새로 만든다(값 종류를 이미지로 등록). 샘플 데이터 모달과
  작성폼(`<slip-form>`)은 그 값을 텍스트가 아니라 이미지 업로드로 받는다(미리보기·지우기 포함,
  기본 2MB 상한 `maxImageBytes`). 캔버스는 샘플 값이 있으면 그 이미지로 그려 미리보기(PDF)와
  어긋나지 않는다(ADR-012, 실PDF·실캔버스 직접 확인). PDF 변환은 0.5.0에서 이미 붙었다. 화면 전용
  변경이라 파일 포맷은 그대로다
- **글자 조판 UI 완료** (2026-08-22, G-45): 0.5.0이 만든 조판 필드를 속성 패널에서 고른다 — 수직
  정렬(상·중·하)·줄간격·자간·세로쓰기. 캔버스도 같은 값으로 그려 PDF와 맞춘다(ADR-012, 실PDF 직접
  확인). 기울임은 UI에서 뺐다 — 동봉 폰트에 Italic 자형이 없어 기본 상태에서는 PDF가 곧게 나오는데,
  캔버스에서 흉내 내면 캔버스만 기울어 화면·PDF가 어긋난다(ADR-012). 스키마 `italic` 필드는 그대로 둬
  호스트가 Italic 폰트를 주면 렌더된다. 화면 전용이라 파일 포맷은 그대로다
- **툴바 정리 완료** (2026-08-22, G-34): 다른 곳에 이미 있는 조작을 툴바에서 뺐다 — 이전·다음 페이지
  (사이드바 페이지 줄), 페이지 앞으로·뒤로(G-46 페이지 설정 화면), 삭제(사이드바 줄·Delete 키). 툴바
  버튼이 줄어 좁은 창에서 가로 스크롤이 덜 생긴다. 화면 전용이라 파일 포맷은 그대로다
- **페이지 설정 화면 완료** (2026-08-22, G-46): 사이드바 페이지 줄을 누르면 페이지가 선택 대상이 되어
  오른쪽 패널에서 이름·물리명·번호 표시(위치 6종)를 정한다. 이름을 정하면 썸네일·목록에 번호 대신
  그 이름이 나온다. 번호는 PDF 후처리로 실제 값이 들어가고 캔버스는 X / X 자리표시(ADR-012).
  페이지 순서 이동을 툴바에서 이 화면으로 옮겼다. 물리명 유일성 스키마 검사도 함께 넣었다(0.5.0 누락분)
- **데이터 자동 병합 완료** (2026-08-22, G-29, ADR-038): 그리드 열을 켜면 반복 구간에서 앞 벌과 값이
  같은 칸이 세로로 합쳐진다. 페이지가 바뀌면 끊고 값을 다시 쓴다. 빈 값은 합치지 않고, 켠 열의 칸이
  반복 구간 전체를 덮지 않으면 스키마가 거부한다. 필드(`columns[i].autoMerge`)는 0.5.0에서 신설했고
  이번에 합치는 동작을 붙였다 — 행 높이·페이지 분할은 그대로다. 실제 PDF로 확인
- **파일 포맷 0.5.0 완료** (2026-08-22, G-24): 글자 조판(수직 정렬·기울임·줄간격·자간·세로쓰기),
  페이지 이름·번호, 변동 이미지(`binding`), 바인딩 값 종류, 그리드 열 자동 병합 필드, 바코드 요소를
  더해 **요소가 9종**이 됐다. 더한 것이 전부 선택 필드라 0.4.0 파일은 그대로 열린다. 규격에 적기 전에
  실제 PDF로 하나씩 확인했고, 하부 엔진에 없는 세로쓰기는 변환 계층이 글자를 한 자씩 쌓아 그린다
- **사이드바 펼침 표시 완료** (2026-08-22, G-25): 값 목록에서 하위가 있는 줄 앞에 펼침 표시가 붙어
  누르면 열리고 닫힌다. 기본은 접힘이고, 그 값이나 그 그리드를 고르면 저절로 열린다. 하위가 없는 줄에는
  같은 폭의 빈 자리를 둬 페이지·요소·값 세 목록의 이름 시작 위치가 맞는다
- **그리드 통합 3단계 완료 — 그리드 통합 종료** (2026-08-22, ADR-037): 파일 포맷 0.4.0에서 옛
  `fixedGrid`·`dynamicTable`을 없앴다 — 표 요소는 그리드 하나뿐이고 요소는 8종이다. 옛 파일은 열면
  그대로 그리드로 바뀐다(고정 그리드 → 반복 없는 그리드, 동적 표 → 헤더 한 줄 + 반복 한 줄). 비율로
  잡혀 있던 트랙은 상자 크기 기준 mm로 환산된다. 프리셋 2종·작성폼·데모도 함께 옮겼고, 옛 표 열 설정
  화면을 없애 선택이 요소·칸 한 갈래로 합쳐졌다
- **그리드 통합 2단계 완료** (2026-08-22, ADR-037): 디자이너에서 그리드를 만들고 편집한다 — 툴바 도구,
  캔버스에 펼쳐진 반복 구간, 반복 구간·행 높이·열 너비(mm) 편집, 칸에 고정 문구·값·수식 붙이기.
  기존 `fixedGrid`·`dynamicTable`을 옮기고 없애는 것은 3단계(43번)
- **그리드 통합 1단계 완료** (2026-08-22, ADR-037): 파일 포맷 0.3.0에 그리드 `grid` 신설 — 고정 틀과 반복 목록을
  하나로 다루고, 페이지 분할·빈 줄·헤더 반복·넘치는 글 처리를 변환 계층이 직접 한다. 하부 엔진의 표 기능에서
  벗어나 열별 스타일·셀 병합·2단 헤더가 열렸다. 디자이너 편집은 2단계(42번)
