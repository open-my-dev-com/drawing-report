# 미결 사항

SlipKit의 구현이나 문서화를 진행하기 전에 사용자 또는 프로젝트 차원의 결정이 필요한 질문을 기록합니다.

확정된 결정과 그 근거는 [설계 결정 기록](./DECISIONS.md), 아직 일정이 정해지지 않은 작업과 아이디어는 [로드맵](./ROADMAP.md)을 참고합니다.

최종 갱신: 2026-08-31

## 현재 상태

> [!NOTE]
> `Q-16`의 답변을 기다리고 있습니다.

## 이 문서에 기록하는 내용

다음 조건에 해당하는 질문을 기록합니다.

- 선택 가능한 방향이 둘 이상인 경우
- 선택에 따라 공개 API, 파일 형식이나 사용자 경험이 달라지는 경우
- 구현자가 임의로 정하면 안 되는 제품 정책인 경우
- 요구사항이나 기존 ADR만으로 답을 판단할 수 없는 경우
- 현재 작업을 계속하려면 사용자 확인이 필요한 경우

다음 내용은 이 문서에 기록하지 않습니다.

- 구현 방법만 남은 작업
- 이미 ADR에서 확정된 결정
- 일정만 정해지지 않은 백로그
- 구체적인 사용 사례가 확인되지 않은 아이디어
- 버그와 단순 문서 오류
- 작업 진행 상황과 완료 기록

버그와 문서 오류는 해당 작업에서 바로 수정하고, 일정과 백로그는 `ROADMAP.md`에서 관리합니다.

## 상태

| 상태 | 의미 |
|---|---|
| 답변 대기 | 결정을 위해 사용자 또는 관계자의 답변이 필요한 상태 |
| 검토 중 | 선택지와 영향을 조사하고 있는 상태 |
| 보류 | 당장 결정할 필요가 없어 검토 시점을 미룬 상태 |
| 해결 | 방향이 확정되어 ADR이나 관련 문서에 반영된 상태 |

## 기록 원칙

- 질문 번호는 `Q-01`, `Q-02`와 같이 순서대로 부여합니다.
- 해결되거나 취소된 질문 번호를 다른 질문에 다시 사용하지 않습니다.
- 질문에는 가능한 선택지와 각 선택이 미치는 영향을 함께 작성합니다.
- 답변을 받기 전에는 특정 선택지를 확정된 요구사항처럼 다른 문서에 작성하지 않습니다.
- 결정이 확정되면 필요한 경우 `DECISIONS.md`에 ADR을 추가합니다.
- 결정과 함께 요구사항, 파일 형식이나 공개 API가 바뀌면 관련 문서도 같은 작업에서 갱신합니다.
- 해결된 질문은 삭제하지 않고 이 문서의 해결 기록으로 옮깁니다.

## 새 질문 작성 형식

새로운 질문은 다음 번호인 `Q-17`부터 작성합니다.

### Q-17: 질문을 한 문장으로 작성

**상태:** 답변 대기

**배경**

왜 이 질문이 생겼으며, 현재 무엇을 결정할 수 없는지 설명합니다.

**확인할 내용**

사용자가 실제로 답해야 하는 질문을 명확하게 작성합니다.

**선택지**

1. 첫 번째 선택지와 예상되는 영향
2. 두 번째 선택지와 예상되는 영향

필요하면 권장하는 선택과 그 이유를 구분해서 작성합니다. 확정되지 않은 선택을 이미 결정된 것처럼 표현하지 않습니다.

**관련 범위**

영향을 받는 기능, 파일 형식, 공개 API나 문서를 기록합니다.

**결과**

결정 전에는 비워 둡니다. 결정된 뒤 선택한 방향과 관련 ADR을 기록하고 해결된 질문으로 옮깁니다.

## 답변을 기다리는 질문

### Q-16: 보안 정책 문서를 몇 개 언어로 둘지

**상태:** 답변 대기

**배경**

루트에 `SECURITY.md`를 영어로 추가했습니다. ADR-066의 3벌 규칙은 가이드와 리포 `README`를 대상으로 하고 있어 보안 정책 문서는 대상에 들어 있지 않습니다. GitHub은 `SECURITY.md` 한 파일만 보안 정책으로 인식합니다.

**확인할 내용**

`SECURITY.md`도 가이드처럼 세 언어로 둘지 정해야 합니다.

**선택지**

1. 영어 한 벌만 둔다 — 신고 창구는 영어로 통일되고 관리할 문서가 늘지 않습니다. 한국어·일본어 사용자는 영어로 읽어야 합니다.
2. 3벌로 둔다 — `SECURITY.ko.md`·`SECURITY.ja.md`를 추가하고 첫머리에 전환 링크를 답니다. 내용이 바뀔 때마다 세 벌을 맞춰야 하고, 신고 기한 같은 수치가 어긋나면 혼란이 생깁니다.

**관련 범위**

루트 `SECURITY.md`, ADR-066의 3벌 규칙 범위, `.claude/rules/terms.md`.
