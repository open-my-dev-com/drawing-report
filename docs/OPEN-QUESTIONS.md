## ~~Q-03. 네이밍~~ → 해결됨 (2026-08-18)

**제품명 SlipKit, npm 스코프 `@slipkit/*`, 확장자 `.slip`, 엘리먼트 접두사 `slip-*`. ADR-018 참조.**

## ~~Q-04. 위변조 방지 서명의 방식 상세~~ → 해결됨 (2026-08-18)

**SHA-256 해시 필수 내장 + JWS(ES256) 서명 옵션(호스트 키). 대상은 스냅샷 포함 전체, JSON 정규화 규칙 스펙 명시. ADR-019 참조.**

## ~~Q-05. GUI 디자이너 v1 기능 범위 상세~~ → 해결됨 (2026-08-18)

**요소 6종 + 고정 그리드 셀 병합 + 색 스타일 + undo/스냅/복붙 + 프리셋 2종. ADR-020 참조.**

## ~~Q-06. 저장소 어댑터 인터페이스 상세~~ → 해결됨 (2026-08-18)

**save/load/delete/list(페이징·필터) 필수 + 버전 이력은 선택 인터페이스. 기본 동봉: 로컬 파일·IndexedDB. 폰트도 어댑터 경유. ADR-021 참조.**

## ~~Q-07. 표준 교환 포맷 명세 공개 수준~~ → 해결됨 (2026-08-18)
