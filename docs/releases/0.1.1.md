# SlipKit 0.1.1

## 한국어

### 주요 변경 사항

- npm에 공개된 다섯 패키지의 설치 안내와 지원 상태를 README, 가이드와 보안 정책에 반영했습니다.
- 다섯 패키지의 버전 변경, 세 언어 릴리즈 노트와 배포 입력을 하나의 준비 PR에서 검토하도록 규칙과 검사를 추가했습니다.
- Release 워크플로가 npm 배포의 무결성, dist-tag와 provenance를 확인한 뒤 같은 실행에서 태그와 GitHub Release를 만들도록 개선했습니다.
- 검토한 한국어·일본어·영어 릴리즈 노트와 검증한 tarball, `manifest.json`, `SHA256SUMS`를 GitHub Release에 함께 게시합니다.

## 日本語

### 主な変更点

- npm で公開済みの 5 パッケージについて、インストール方法とサポート状況を README、ガイド、セキュリティポリシーに反映しました。
- 5 パッケージのバージョン変更、3 言語のリリースノート、リリース入力を 1 つの準備 PR で確認するためのルールと検査を追加しました。
- Release ワークフローは npm 公開後に整合性、dist-tag、provenance を確認し、同じ実行でタグと GitHub Release を作成します。
- レビュー済みの韓国語・日本語・英語のリリースノートと、検証済みの tarball、`manifest.json`、`SHA256SUMS` を GitHub Release に掲載します。

## English

### Highlights

- Updated the README files, guides, and security policy to reflect the five packages now available on npm.
- Added rules and checks that keep all package versions, the three-language release notes, and release inputs together in one preparation pull request.
- Extended the Release workflow to verify npm integrity, the dist-tag, and provenance before creating the tag and GitHub Release in the same run.
- GitHub Releases now use the reviewed Korean, Japanese, and English notes and include the verified tarballs, `manifest.json`, and `SHA256SUMS`.
