# SlipKit 0.1.2

## 한국어

### 주요 변경 사항

- 다섯 패키지를 같은 `0.1.2` 버전으로 다시 맞춰 배포합니다.
- npm이 패키지를 접수한 뒤 자동 검토하는 동안 공개 조회가 느려지더라도, 일시적인 `E404`를 배포 실패로 판단하지 않고 기다립니다.
- 각 패키지의 무결성과 npm 배포 태그를 확인한 뒤 다음 패키지를 배포하며, 제한 시간 초과와 무결성 불일치는 기존처럼 중단합니다.
- npm 명령의 표준 출력과 오류 출력을 Actions 로그에 남겨 배포 문제를 확인할 수 있게 했습니다.

## 日本語

### 主な変更点

- 5 つのパッケージのバージョンを `0.1.2` に揃えて再度公開します。
- npm がパッケージを受け付けた後の自動審査中に公開反映が遅れても、一時的な `E404` を公開失敗と判定せずに待ちます。
- 各パッケージの整合性と npm の dist-tag を確認してから次のパッケージを公開し、タイムアウトや整合性の不一致は従来どおり停止します。
- npm コマンドの標準出力と標準エラー出力を Actions ログに残し、公開時の問題を確認できるようにしました。

## English

### Highlights

- Restored all five packages to a synchronized `0.1.2` release.
- The release workflow now waits when npm's automated review temporarily delays public registry visibility instead of treating an interim `E404` as a failed publish.
- Each package must expose the expected integrity and dist-tag before the next package is published, while timeouts and integrity mismatches still stop the release.
- npm standard output and error output are preserved in the Actions log for release diagnostics.
