# SCR-010 샘플 값 편집 모달

최종 갱신: 2026-09-28

## 개요

디자이너 캔버스와 PDF 미리보기에 사용할 파라미터별 샘플 값을 JSON으로 편집하는 모달을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 샘플 JSON 편집, 검증과 적용·취소 흐름을 정의했습니다. |

## 진입·종료 조건

파라미터 목록의 샘플 값 버튼을 누르면 진입하고 적용, 취소, 닫기 또는 Escape로 종료합니다.

## 화면 이미지

![샘플 값 진입 화면](../assets/SCR-001-designer-main-default-1440x810.png)

## 화면 영역

| 영역 | 입력·출력 항목 | 표시·활성화 조건 |
| --- | --- | --- |
| JSON 편집기 | 현재 샘플 값 객체 | 항상 표시합니다. |
| 검증 상태 | JSON·파라미터 구조 오류 | 입력할 때 갱신합니다. |
| 하단 명령 | 취소, 적용 | 유효한 객체만 적용합니다. |

## 이벤트와 호출 기능

| 사용자 동작 | 호출 기능 | 결과 |
| --- | --- | --- |
| JSON 입력 | FNC-021 | 구문과 파라미터 값 구조를 검사합니다. |
| 적용 | FNC-019 | 캔버스와 출력 계획을 다시 계산합니다. |

## 상태별 표시

변경 없음, 편집 중, 오류와 적용 가능 상태를 구분합니다. 배경 편집과 단축키는 모달이 열려 있는 동안
비활성화합니다.

## 입력 검증과 오류 표시

최상위 객체가 아닌 JSON, 값 종류 불일치와 손상 이미지 값을 구체적인 경로와 함께 표시합니다.

## 화면 전이

적용·취소 뒤 샘플 값 버튼으로 초점을 돌리고 현재 디자이너 선택을 유지합니다.

## 관련 데이터·인터페이스·오류

| 구분 | 식별자 | 관계 |
| --- | --- | --- |
