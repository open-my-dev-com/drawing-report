# SCR-004 속성 패널

최종 갱신: 2026-09-28

## 개요

양식, 페이지, 요소, 그리드 셀과 파라미터의 속성을 대상별 입력으로 편집하는 오른쪽 패널을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 선택별 패널, 공통 배치·스타일 입력과 검증 표시를 정의했습니다. |

## 진입·종료 조건

편집 모드에서 항상 표시하며 선택이 없으면 양식 설정을, 대상이 있으면 해당 속성을 표시합니다.

## 화면 영역

| 영역 | 입력·출력 항목 | 표시·활성화 조건 |
| --- | --- | --- |
| 대상 제목 | 현재 종류와 출력 보기 | 선택 대상에 따라 바뀝니다. |
| 배치 | 이름, 기준점, 좌표, 크기, 페이지 표시 | 요소·그리드 선택 때 표시합니다. |
| 종류별 속성 | 값 원본, 글자, 배경, 테두리, 반복 설정 | 지원하는 대상에만 표시합니다. |

## 이벤트와 호출 기능

| 사용자 동작 | 호출 기능 | 결과 |
| --- | --- | --- |
| 숫자·선택 입력 | FNC-019 | 검증한 속성을 즉시 반영합니다. |
| 수식 편집 | FNC-021 | SCR-007을 엽니다. |
| 조건부 서식 | FNC-021 | SCR-008을 엽니다. |

## 상태별 표시

대상 종류에 없는 항목은 감추며, 비동기 폰트·용지 목록을 불러오는 동안 관련 선택을 기다림 상태로
표시합니다.
