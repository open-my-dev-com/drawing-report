# SCR-002 캔버스와 용지 편집

최종 갱신: 2026-09-28

## 개요

현재 페이지의 용지, 요소 경계, 눈금과 선택 상태를 표시하고 포인터·키보드로 위치와 크기를 편집하는
화면을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 용지 배치, 선택·이동·크기 조정과 키보드 동작을 정의했습니다. |

## 진입·종료 조건

디자이너 편집 모드에서 양식과 현재 페이지가 있으면 표시합니다. 미리보기에서는 캔버스를 숨깁니다.

## 화면 이미지

![디자이너 캔버스](../assets/SCR-001-designer-main-default-1440x810.png)

## 화면 영역

| 영역 | 입력·출력 항목 | 표시·활성화 조건 |
| --- | --- | --- |
| 눈금 | mm 좌표 | 격자선 설정과 무관하게 용지 기준을 표시합니다. |
| 용지 | 여백·흐름 영역·요소 | 현재 페이지를 표시합니다. |
| 선택 테두리 | 이동·크기 조정 손잡이 | 하나 이상의 요소를 선택할 때 표시합니다. |

## 이벤트와 호출 기능

| 사용자 동작 | 호출 기능 | 결과 |
| --- | --- | --- |
| 클릭·Shift 클릭 | FNC-020 | 단일·다중 선택을 바꿉니다. |
| 끌기·크기 조정 | FNC-020 | 한 번의 실행 취소 단계로 좌표를 바꿉니다. |
| 화살표·Shift 화살표 | FNC-020 | 1 mm·10 mm 단위로 이동합니다. |

## 상태별 표시

선택 없음, 단일·다중 선택, 끌기 중과 요소 종류 표시를 구분합니다. 반복 그리드는 출력 보기에서 계획한
조각을 표시합니다.

## 입력 검증과 오류 표시

좌표와 크기는 허용 범위를 벗어나지 않게 제한합니다. 수식·그리드 오류는 해당 요소에 배지를 표시합니다.

## 화면 전이

요소 선택은 SCR-004 속성 패널을 바꿉니다. 출력 보기는 같은 화면에서 계획 결과 표시로 전환합니다.

## 관련 데이터·인터페이스·오류

| 구분 | 식별자 | 관계 |
| --- | --- | --- |
| 데이터 | DAT-002·DAT-004·DAT-007 | 페이지와 요소 기하를 표시합니다. |
| 인터페이스 | IF-005 | 디자이너 입력과 변경 이벤트를 사용합니다. |
| 오류 | ERR-002·ERR-003 | 요소별 계산·배치 오류를 표시합니다. |
