# SCR-002 캔버스와 용지 편집

최종 갱신: 2026-09-28

## 개요

현재 페이지의 용지, 요소 경계, 눈금과 선택 상태를 표시하고 포인터·키보드로 위치와 크기를 편집하는
화면을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 용지 배치, 선택·이동·크기 조정과 키보드 동작을 정의했습니다. |

## 진입·종료 조건

### 진입 조건

- SCR-001이 유효한 양식을 편집 상태로 열면 현재 페이지의 캔버스를 표시합니다.
- 양식의 첫 페이지를 기본으로 표시하며, SCR-005에서 고른 페이지가 있으면 그 페이지를 표시합니다.

### 종료 조건

- 미리보기 버튼을 누르면 캔버스를 숨기고 SCR-013을 표시합니다.
- 호스트가 `src`를 비우거나 컴포넌트를 제거하면 캔버스를 종료합니다.

| 선택 요소 | Shift와 방향키를 누릅니다. | FNC-020 | 선택 요소를 누른 방향으로 5mm 이동합니다. | 입력 필드에 초점이 있거나 모달 또는 미리보기 상태 |

| 용지 | 선 생성 도구를 선택한 뒤 끕니다. | FNC-019 | 끌기의 시작점과 끝점으로 선 요소를 추가하고 선택합니다. | 용지 밖, 모달 또는 미리보기 상태 |

## 상태별 표시

| 상태 | 진입 조건 | 표시 내용 | 허용 동작 |
| --- | --- | --- | --- |
| 선택 없음 | 페이지를 처음 열거나 빈 곳을 눌렀습니다. | 선택 테두리 없이 모든 요소를 표시합니다. | 요소 선택과 새 요소 생성을 사용할 수 있습니다. |
| 단일 선택 | 요소 하나를 선택했습니다. | 파란 선택 테두리와 크기 조정 손잡이를 표시합니다. | 이동, 크기 조정, 삭제와 속성 변경을 사용할 수 있습니다. |
| 다중 선택 | Shift 선택으로 요소를 둘 이상 선택했습니다. | 모든 선택 요소를 강조하고 주 선택 요소를 구분합니다. | 함께 이동, 정렬, 분배, 복사와 삭제를 사용할 수 있습니다. |
| 이동 중 | 선택 요소를 끌거나 방향키로 이동합니다. | 변경할 좌표와 포인터의 mm 위치를 즉시 표시합니다. | 포인터를 놓거나 키 입력을 끝내 변경을 확정할 수 있습니다. |
| 요소 생성 대기 | 상단에서 요소 생성 도구를 선택했습니다. | 캔버스 커서를 생성 상태로 바꾸고 선택 도구를 눌림 상태로 표시합니다. | 용지 안을 누르거나 끌어 요소를 만들 수 있습니다. |
| 그리드 출력 보기 | 그리드 속성에서 출력 보기를 켰습니다. | 원본 행 대신 샘플 값으로 계획한 출력 조각을 표시합니다. | 출력 페이지를 바꾸거나 원본 보기로 돌아갈 수 있습니다. |

## 입력 검증과 오류 표시

| 검사 대상 | 실패 조건 | 표시 위치와 표현 | 문서·화면 처리 | 복구 방법 |
| --- | --- | --- | --- | --- |
| 요소 위치 | 이동 결과의 왼쪽 또는 위쪽 좌표가 0보다 작습니다. | 요소를 용지의 왼쪽 또는 위쪽 경계에서 멈추고 좌표 표시를 갱신합니다. | 음수 좌표를 양식에 저장하지 않습니다. 오른쪽 또는 아래쪽으로 용지를 벗어나는 배치는 허용합니다. | 요소를 오른쪽 또는 아래쪽으로 이동합니다. |
| 요소 크기 | 크기 조정 결과가 종류별 최소 크기보다 작습니다. | 손잡이를 최소 크기 위치에서 멈춥니다. | 최소 크기보다 작은 값을 저장하지 않습니다. | 손잡이를 바깥쪽으로 이동합니다. |
| 요소 수식 | 수식의 문법이나 참조가 올바르지 않습니다. | 해당 요소 위에 경고 배지를 표시하고 접근성 이름으로 원인을 제공합니다. | 양식은 유지하지만 오류 결과를 정상 값으로 표시하지 않습니다. | SCR-007에서 수식을 고칩니다. |
| 반복 그리드 | 행 구간이나 페이지 계획을 만들 수 없습니다. | 캔버스 위쪽에 원인을 표시하고 해당 그리드를 오류 테두리로 표시합니다. 특정 행 구간이 원인이면 SCR-006의 행 구간 목록에도 같은 오류를 표시합니다. | 출력 결과를 표시하지 않고 원본 행 구조를 유지합니다. | 오류의 찾기 버튼을 누르거나 그리드를 선택한 뒤 SCR-006에서 반복 설정을 고칩니다. |
