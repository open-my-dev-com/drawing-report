# SCR-003 요소 목록과 추가

최종 갱신: 2026-09-28

## 개요

현재 페이지의 요소 계층을 탐색하고 새 요소를 추가·선택·삭제하는 왼쪽 패널과 도구 모음을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 요소 추가 도구와 계층 목록의 선택·삭제 동작을 정의했습니다. |

## 진입·종료 조건

편집 모드에서 현재 페이지가 있으면 표시합니다. 미리보기에서는 숨기고 명령을 비활성화합니다.

## 화면 이미지

![요소 목록과 추가 도구](../assets/SCR-001-designer-main-default-1440x810.png)

## 화면 영역

| 영역 | 입력·출력 항목 | 표시·활성화 조건 |
| --- | --- | --- |
| 요소 추가 도구 | 글자, 그리드, 이미지, 선, 도형, 입력 필드, 바코드 | 편집 모드에서 활성화합니다. |
| 요소 목록 | 이름, 종류, 하위 셀, 삭제 | 현재 페이지의 순서를 반영합니다. |
| 복사·붙여넣기 | 선택 요소의 내부 복사본 | 선택과 복사 내용이 있을 때 활성화합니다. |

## 이벤트와 호출 기능

| 사용자 동작 | 호출 기능 | 결과 |
| --- | --- | --- |
| 요소 종류 선택 | FNC-019 | 고유 ID를 가진 기본 요소를 추가합니다. |
| 목록 항목 선택 | FNC-020 | 캔버스와 속성 패널 선택을 맞춥니다. |
| 삭제 | FNC-019 | 참조를 검사한 뒤 요소를 제거합니다. |

## 상태별 표시

그리드는 펼쳐 셀을 표시할 수 있습니다. 선택 요소와 현재 셀은 강조하며 삭제 버튼에는 접근 가능한
이름을 제공합니다.

## 입력 검증과 오류 표시

페이지 상한, 요소 상한과 중복 ID를 검사합니다. 삭제할 수 없는 참조 관계는 이유를 알립니다.

## 화면 전이

요소를 고르면 SCR-004, 그리드 또는 셀을 고르면 SCR-006으로 이어집니다.

## 관련 데이터·인터페이스·오류

| 구분 | 식별자 | 관계 |
| --- | --- | --- |
| 데이터 | DAT-004·DAT-005 | 요소 종류와 공통 속성을 사용합니다. |
| 인터페이스 | IF-005 | 문서 변경을 외부에 알립니다. |
| 오류 | ERR-005 | 추가·삭제 실패를 화면에 표시합니다. |
