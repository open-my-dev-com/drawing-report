# SCR-001 디자이너 기본 화면

최종 갱신: 2026-09-28

## 개요

`<slip-designer>`는 양식의 페이지, 요소와 파라미터를 편집하는 화면입니다. 이 문서는 디자이너를
웹 페이지에 넣는 조건부터 기본 화면의 다섯 영역, 모든 상단 명령, 상태와 오류 표시까지 정의합니다.

## 진입·종료 조건

### 진입 조건

1. 호스트 웹 페이지가 `<slip-designer>` 요소를 화면에 배치합니다.
2. 호스트가 `src` 속성에 `.slip` 양식 문자열을 넣습니다.
3. `src`가 `kind: 'template'`인 유효한 양식이면 첫 번째 페이지를 선택한 편집 화면을 표시합니다.
4. `src`가 비어 있으면 편집 화면 대신 "양식이 없습니다" 안내를 표시합니다.
5. `src`를 해석할 수 없거나 전표이면 편집 화면 대신 해당 오류 안내를 표시합니다.

데모의 "양식 디자인" 탭은 위 조건을 갖춘 `<slip-designer>`를 표시하는 호스트 예시입니다. 이 탭은
컴포넌트의 공개 인터페이스가 아닙니다.

### 종료 조건

- 호스트가 `<slip-designer>`를 문서에서 제거하거나 다른 화면으로 교체하면 디자이너가 종료됩니다.
- 호스트가 새 `src`를 넣으면 현재 편집 기록과 선택을 지우고 새 양식의 첫 페이지를 엽니다.
- 미리보기 버튼은 디자이너를 종료하지 않고 같은 컴포넌트를 SCR-013 상태로 바꿉니다.

파란 번호는 아래 화면 구성 표의 번호와 같습니다. 이미지 위쪽의 데모 탐색과 저장 안내는
`<slip-designer>` 밖에서 호스트가 제공하는 영역입니다.

## 상태별 표시

| 상태 | 진입 조건 | 표시 내용 | 허용 동작 |
| --- | --- | --- | --- |
| 양식 없음 | `src`가 빈 문자열입니다. | 도구 모음과 편집 영역 대신 가운데에 양식이 없다는 안내를 표시합니다. | 호스트가 유효한 `src`를 넣을 때까지 화면 조작을 제공하지 않습니다. |
| 양식 읽기 실패 | `src`를 `.slip` 파일로 해석하거나 검증하지 못했습니다. | 가운데에 붉은 오류 문구를 표시합니다. | 호스트가 `src`를 수정할 수 있습니다. |
| 양식 종류 오류 | `src`가 양식이 아닌 전표입니다. | 디자이너에서는 양식만 열 수 있다는 붉은 오류 문구를 표시합니다. | 호스트가 양식 `src`를 넣을 수 있습니다. |
| 편집 기본 | 유효한 양식을 열었고 선택한 요소가 없습니다. | 첫 페이지, 요소·파라미터 목록과 양식 설정을 표시합니다. | 요소 추가, 페이지 관리, 프리셋, 미리보기와 양식 설정을 사용할 수 있습니다. |
| 요소 선택 | 목록 또는 캔버스에서 요소 하나 이상을 선택했습니다. | 선택 테두리와 주 선택 요소의 속성을 표시합니다. | 이동, 크기 조정, 복사, 삭제와 속성 변경을 사용할 수 있습니다. |
| 요소 생성 대기 | 요소 생성 버튼을 눌렀습니다. | 선택한 버튼을 눌림 상태로 표시하고 캔버스 커서를 생성 상태로 바꿉니다. | 캔버스 클릭 또는 끌기로 요소를 만들거나 Escape로 취소할 수 있습니다. |
| 모달 | 수식, 이미지, 샘플 값, 저장 또는 내 양식 모달을 열었습니다. | 모달과 반투명 배경을 표시하고 배경 편집 영역을 조작할 수 없게 합니다. | 모달 안의 입력, 적용, 취소와 닫기만 사용할 수 있습니다. |
| 미리보기 로딩 | 미리보기 버튼을 누른 뒤 PDF 생성이 끝나지 않았습니다. | 도구 모음과 가운데 로딩 안내를 표시합니다. | 편집 버튼으로 로딩을 취소하고 돌아갈 수 있습니다. |
| 미리보기 완료 | PDF 생성에 성공했습니다. | 도구 모음 아래 전체 영역에 PDF `iframe`을 표시합니다. | 편집 버튼과 저장소 명령을 사용할 수 있습니다. |
| 미리보기 오류 | PDF 생성에 실패했습니다. | PDF 영역 가운데에 미리보기를 만들 수 없다는 오류를 표시합니다. | 편집 버튼으로 돌아가 원인을 수정할 수 있습니다. |

## 입력 검증과 오류 표시

| 검사 대상 | 실패 조건 | 표시 위치와 표현 | 문서·화면 처리 | 복구 방법 |
| --- | --- | --- | --- | --- |
| `src` | 빈 문자열입니다. | 편집 영역 가운데에 일반 안내 문구를 표시합니다. | 기존 편집 문서, 선택과 실행 취소 기록을 지웁니다. | 호스트가 유효한 양식 문자열을 넣습니다. |
| `src` | JSON, 암호화 봉투 또는 `.slip` 스키마가 올바르지 않습니다. | 편집 영역 가운데에 붉은 오류 문구를 표시합니다. | 잘못된 내용을 편집 문서로 만들지 않습니다. | 호스트가 원본 파일을 고친 뒤 `src`를 다시 넣습니다. |
| `src` | 파일의 `kind`가 `voucher`입니다. | 편집 영역 가운데에 양식만 열 수 있다는 붉은 오류 문구를 표시합니다. | 전표 값을 편집 문서로 만들지 않습니다. | 호스트가 `kind: 'template'`인 파일을 넣습니다. |
| 속성 입력 | 숫자 범위, 필수값 또는 허용 목록을 벗어납니다. | 해당 입력 테두리를 위험 색으로 표시하고 바로 아래에 같은 색의 오류 문구를 표시합니다. 오류 문구는 `role="alert"`로 알립니다. | 잘못된 값을 양식에 반영하지 않고 마지막 유효값을 유지합니다. | 입력을 허용 범위의 값으로 고칩니다. |
| 속성 변경 | 특정 입력 하나로 위치를 정할 수 없는 일반 편집 오류입니다. | 오른쪽 속성 패널 맨 위에 테두리와 연한 배경이 있는 위험 색 오류 상자를 표시합니다. | 변경을 반영하지 않고 현재 양식과 선택을 유지합니다. | 오류 문구가 가리키는 설정을 고칩니다. |
| 수식 | 문법, 참조 또는 현재 샘플 값으로 계산하는 과정에 문제가 있습니다. | 캔버스 위쪽의 수식 경고 목록에 대상과 원인을 표시합니다. 해당 요소나 셀에는 경고 배지를 표시합니다. | 양식은 유지하며 계산하지 못한 값을 정상 결과처럼 표시하지 않습니다. | 경고 목록의 찾기 버튼을 눌러 대상을 선택한 뒤 SCR-007에서 수식을 고칩니다. |
| 반복 그리드 | 현재 반복 설정으로 출력 페이지를 배치할 수 없습니다. | 캔버스 위쪽의 페이지 계획 오류에 원인을 표시하고, 원인이 특정 요소이면 찾기 버튼을 함께 표시합니다. 해당 그리드는 오류 테두리로 표시합니다. | 출력 결과 보기로 전환하지 않고 원본 행 구조를 유지합니다. | 찾기 버튼으로 그리드를 선택한 뒤 SCR-006에서 반복 설정을 고칩니다. |
| PDF 미리보기 | 레이아웃, 폰트, 이미지 또는 바코드 처리에 실패합니다. | SCR-013의 PDF 영역 가운데에 오류 문구를 표시합니다. | 이전 PDF 주소를 해제하고 실패한 결과를 표시하지 않습니다. | 편집 화면으로 돌아가 ERR-003의 원인을 고친 뒤 다시 미리보기합니다. |
| 저장소 명령 | 저장, 목록 조회, 불러오기 또는 삭제가 실패합니다. | SCR-012의 현재 모달 안에 위험 색 오류 문구를 표시합니다. | 현재 양식과 모달 입력을 유지합니다. | 저장소 상태를 확인한 뒤 같은 명령을 다시 실행하거나 모달을 닫습니다. |

## 키보드와 접근성

- 아이콘 버튼은 보이는 이름, `title`과 `aria-label`에 같은 명령 이름을 사용합니다.
- 눌림 상태가 있는 도구는 `aria-pressed`, 메뉴 버튼은 `aria-haspopup`와 `aria-expanded`를 제공합니다.
- 도형, 격자와 프리셋 메뉴는 위·아래 방향키, Home, End와 Escape로 조작합니다.
- 모달은 초점을 내부에 두고 닫으면 모달을 연 버튼으로 초점을 돌려줍니다.
- 디자이너 전체는 키보드 초점을 받을 수 있으며 SCR-002의 이동 단축키와 FNC-020의 편집 단축키를 제공합니다.
