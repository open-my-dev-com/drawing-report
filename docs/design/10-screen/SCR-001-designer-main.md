# SCR-001 디자이너 기본 화면

최종 갱신: 2026-09-28

## 개요

사용자가 양식의 페이지, 요소와 파라미터를 한 화면에서 구성하는 `<slip-designer>`의 기본 배치를
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 도구 모음, 탐색 패널, 캔버스와 속성 패널의 기본 배치를 정의했습니다. |

## 진입·종료 조건

검증된 양식을 `src`로 받으면 진입합니다. 미리보기 전환, 다른 모드 선택 또는 컴포넌트 연결 해제로
편집 화면을 벗어납니다.

## 화면 이미지

![디자이너 기본 화면](../assets/SCR-001-designer-main-default-1440x810.png)

## 화면 영역

| 영역 | 입력·출력 항목 | 표시·활성화 조건 |
| --- | --- | --- |
| 상단 도구 모음 | 요소 추가, 복사·붙여넣기, 실행 취소, 페이지, 미리보기, 저장 | 현재 선택과 기록에 따라 각 명령을 활성화합니다. |
| 왼쪽 탐색 | 페이지, 요소, 파라미터 | 양식 구조를 계층으로 표시합니다. |
| 가운데 캔버스 | 용지와 요소 | 현재 페이지를 실제 비율로 편집합니다. |
| 오른쪽 속성 | 양식 또는 선택 대상 설정 | 선택 대상에 맞는 패널을 표시합니다. |

## 이벤트와 호출 기능

| 사용자 동작 | 호출 기능 | 결과 |
| --- | --- | --- |
| 양식 설정 변경 | FNC-019 | 새 양식을 검증하고 `slip-change`를 보냅니다. |
| 실행 취소·다시 실행 | FNC-020 | 이전·다음 문서 상태를 복원합니다. |
| 미리보기 | FNC-022 | 편집 도구를 잠그고 PDF 화면으로 전환합니다. |

## 상태별 표시

양식 없음, 편집, 모달 열림, 미리보기와 오류 상태를 구분합니다. 모달이 열리면 배경 편집은 비활성화합니다.

## 입력 검증과 오류 표시

필드 가까이에 오류를 표시하고 잘못된 값은 문서에 반영하지 않습니다. 파일 불러오기 오류는 현재 양식을
유지합니다.

## 화면 전이

왼쪽 또는 캔버스에서 대상을 고르면 관련 속성 화면으로 전환합니다. 미리보기에서 편집을 누르면 선택과
스크롤 상태를 유지한 채 돌아옵니다.

## 관련 데이터·인터페이스·오류

| 구분 | 식별자 | 관계 |
| --- | --- | --- |
| 데이터 | DAT-002·DAT-004·DAT-006 | 양식과 편집 대상을 표시합니다. |
| 인터페이스 | IF-005 | 공개 속성·이벤트 계약입니다. |
| 오류 | ERR-001·ERR-005 | 불러오기와 화면 오류를 표시합니다. |
