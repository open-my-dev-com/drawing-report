# SCR-007 수식 편집 모달

최종 갱신: 2026-09-28

## 개요

수식 원문을 편집하면서 계산 결과를 확인하고 함수와 값 참조를 삽입하는 모달을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 수식 입력, 실시간 결과, 함수·참조 탐색과 적용 조건을 정의했습니다. |

## 진입·종료 조건

수식을 지원하는 요소·셀·조건에서 편집 버튼을 누르면 진입합니다. 적용, 취소, 닫기 또는 Escape로
종료합니다.

![수식 편집 모달](../assets/SCR-007-formula-dialog-1440x810.png)

## 화면 영역

| 영역 | 입력·출력 항목 | 표시·활성화 조건 |
| --- | --- | --- |
| 편집 대상 | 요소·셀과 속성 이름 | 항상 표시합니다. |
| 수식 입력·결과 | 원문, 계산값 또는 오류 | 입력할 때마다 갱신합니다. |
| 탐색 탭 | 함수, 값과 범위 | 검색과 범주 필터를 제공합니다. |
| 하단 명령 | 취소, 적용 | 유효한 수식만 적용할 수 있습니다. |

## 이벤트와 호출 기능

| 사용자 동작 | 호출 기능 | 결과 |
| --- | --- | --- |
| 수식 입력 | FNC-004·FNC-005 | 문법과 현재 샘플 값의 결과를 표시합니다. |
| 함수·참조 선택 | FNC-006 | 커서 위치에 올바른 표기를 삽입합니다. |
| 적용 | FNC-021 | 대상 속성을 한 단계로 변경합니다. |

## 상태별 표시

정상 결과, 데이터 의존 오류와 수식 자체 오류를 구분합니다. 함수와 값 탭은 키보드로 전환할 수 있습니다.

## 입력 검증과 오류 표시

오류 위치와 자연스러운 설명을 결과 영역에 표시합니다. 공백 수식은 화면·PDF 공통으로 빈 값입니다.

## 화면 전이

닫으면 열기 전 대상에 초점을 돌려줍니다. 적용 뒤에는 해당 속성 패널을 유지합니다.

## 관련 데이터·인터페이스·오류

| 구분 | 식별자 | 관계 |
| --- | --- | --- |
| 데이터 | DAT-006·DAT-008 | 값 참조와 수식을 편집합니다. |
| 인터페이스 | IF-005 | 디자이너 내부 편집 화면입니다. |
| 오류 | ERR-002 | 수식 오류를 실시간으로 표시합니다. |
