# SCR-009 파라미터 관리

최종 갱신: 2026-09-28

## 개요

양식의 최상위 파라미터와 목록 하위 필드를 추가·선택·수정·삭제하는 왼쪽 목록과 속성 화면을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 파라미터 계층, 키 변경과 참조 무결성 처리를 정의했습니다. |

## 진입·종료 조건

디자이너 편집 모드에서 파라미터 또는 하위 필드를 선택하면 진입합니다.

![파라미터 목록](../assets/SCR-001-designer-main-default-1440x810.png)

## 화면 영역

| 영역 | 입력·출력 항목 | 표시·활성화 조건 |
| --- | --- | --- |
| 파라미터 목록 | 이름, 키, 종류, 하위 필드 | 계층을 펼치고 접을 수 있습니다. |
| 추가·삭제 | 최상위와 목록 필드 | 상한과 참조 상태에 따라 활성화합니다. |
| 속성 | 이름, 키, 값 종류와 제약 | 선택 대상에 맞춰 표시합니다. |

## 이벤트와 호출 기능

| 사용자 동작 | 호출 기능 | 결과 |
| --- | --- | --- |
| 추가·수정 | FNC-021 | 스키마와 샘플 값을 함께 갱신합니다. |
| 키 변경 | FNC-006·FNC-021 | 수식과 요소 참조를 안전하게 바꿉니다. |
| 삭제 | FNC-021 | 참조 영향을 확인한 뒤 제거합니다. |

## 상태별 표시

최상위와 목록 하위 필드의 허용 종류를 구분합니다. 선택한 항목은 캔버스 요소 선택과 별도로 표시합니다.

## 입력 검증과 오류 표시

빈 키, 중복 키, 허용하지 않는 하위 구조와 남은 참조를 해당 필드에 표시합니다.

## 화면 전이

샘플 값 버튼은 SCR-010을 열고 요소에서 파라미터를 고르면 현재 정의 목록을 사용합니다.

## 관련 데이터·인터페이스·오류

| 구분 | 식별자 | 관계 |
| --- | --- | --- |
| 데이터 | DAT-006 | 파라미터 정의와 샘플 값을 관리합니다. |
| 인터페이스 | IF-005 | 디자이너 문서에 반영합니다. |
| 오류 | ERR-002·ERR-005 | 참조와 입력 오류를 표시합니다. |
