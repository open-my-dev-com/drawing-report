# SCR-015 전표 뷰어

최종 갱신: 2026-09-28

## 개요

`<slip-viewer>`가 유효한 `.slip` 양식 또는 전표를 PDF로 만들어 표시하는 읽기 전용 화면을
정의합니다. 입력과 문서 편집 명령은 제공하지 않습니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 입력 파일 판정, PDF 로딩·표시·오류, 갱신과 종료 동작을 정의했습니다. |

## 설계 범위

- 양식 또는 전표를 읽기 전용 PDF로 표시하는 화면의 로딩·성공·오류 상태를 정의합니다.
- 새 파일을 연속으로 받을 때 마지막 파일의 결과만 표시하는 규칙을 정의합니다.
- 데모의 파일 내려받기와 저장 안내는 SCR-016에서 정의합니다.

## 진입·종료 조건

### 진입 조건

- 보기 화면에 유효한 양식 또는 전표를 열면 PDF 생성을 시작합니다.
- 양식은 샘플 값으로, 전표는 저장된 값으로 PDF 생성을 시작합니다.
- 열 파일이 없으면 PDF 대신 파일이 없다는 안내를 표시합니다.

### 종료 조건

- 호스트가 다른 화면으로 교체하거나 컴포넌트를 제거하면 PDF 주소를 해제하고 종료합니다.
- 다른 파일을 열면 기존 PDF와 오류를 지우고 새 파일을 처리합니다.

## 화면 이미지

첫 이미지는 데모 호스트 안의 `<slip-viewer>`를, 두 번째 이미지는 브라우저 PDF 도구와 관계없는 실제
출력 첫 페이지를 보여 줍니다.

## 상태별 표시

| 상태 | 시작 조건 | 화면 표시 | 가능한 다음 동작 |
| --- | --- | --- | --- |
| 입력 없음 | 열 파일이 없습니다. | 전표가 없다는 안내를 표시합니다. | 올바른 양식 또는 전표를 열면 로딩 상태로 이동합니다. |
| 입력 오류 | 연 파일을 해석하거나 검증하지 못했습니다. | 보기 영역 가운데에 오류를 표시합니다. | 올바른 양식 또는 전표를 열면 다시 처리합니다. |
| 로딩 | 양식 또는 전표를 검증했고 PDF를 만드는 중입니다. | PDF를 만드는 중이라는 안내를 표시합니다. | 완료될 때까지 기다릴 수 있습니다. |
| PDF 표시 | 최신 PDF 생성에 성공했습니다. | PDF를 보기 영역 전체에 표시합니다. | 브라우저 PDF 도구를 사용할 수 있습니다. |
| 렌더 오류 | 입력 파일로 PDF를 만들지 못했습니다. | 문서 대신 PDF 생성 오류를 표시합니다. | 호스트가 자원이나 입력을 고쳐 다시 넣을 수 있습니다. |

## 입력 검증과 오류 표시

| 발생 위치 | 발생 조건 | 표시 방법 | 처리와 복구 |
| --- | --- | --- | --- |
| 파일 구문 | JSON, 암호화 봉투 또는 전표 파일 구조가 올바르지 않습니다. | 보기 영역 가운데에 오류 문구를 표시합니다. | 기존 PDF를 정리하고 잘못된 파일을 표시하지 않습니다. 올바른 양식 또는 전표를 엽니다. |
| PDF 생성 | 레이아웃, 폰트, 이미지 또는 바코드 처리에 실패합니다. | 뷰어 영역 가운데에 렌더 오류를 표시합니다. | 불완전한 PDF를 표시하지 않습니다. 호스트 설정과 입력 파일의 자원을 복구합니다. |
| 오래된 생성 결과 | 새 파일 처리 뒤 이전 PDF 생성이 늦게 끝납니다. | 별도 오류를 표시하지 않습니다. | 이전 결과를 버리고 최신 파일의 결과만 표시합니다. |

## 화면 전이

| 사용자 동작 | 화면 변화 | 유지하는 내용 | 초기화하는 내용 |
| --- | --- | --- | --- |
| 입력 없음 또는 오류에서 양식 또는 전표를 엽니다. | 로딩 | 새 입력 파일 | 이전 오류와 PDF |
| 로딩에서 PDF 생성에 성공합니다. | PDF 표시 | 입력 파일과 새 PDF 주소 | 로딩 안내 |
| 로딩에서 PDF 생성에 실패합니다. | 렌더 오류 | 입력 파일 | 로딩 안내와 이전 PDF 주소 |
| 모든 상태에서 다른 파일을 엽니다. | 새 입력에 맞는 상태 | 새 입력만 유지합니다. | 이전 전표, 오류와 PDF |
