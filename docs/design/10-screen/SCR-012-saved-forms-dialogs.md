# SCR-012 내 양식 저장·목록·삭제 모달

최종 갱신: 2026-09-28

## 개요

현재 양식을 저장소에 이름으로 저장하고, 목록에서 불러오거나 확인 뒤 삭제하는 세 모달 흐름을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 저장, 페이지 목록, 불러오기와 삭제 확인 흐름을 정의했습니다. |

## 진입·종료 조건

도구 모음의 저장 또는 내 양식 버튼으로 진입합니다. `storage`가 없으면 명령을 사용할 수 없습니다.

## 화면 이미지

![내 양식 명령 위치](../assets/SCR-001-designer-main-default-1440x810.png)

## 화면 영역

| 영역 | 입력·출력 항목 | 표시·활성화 조건 |
| --- | --- | --- |
| 저장 | ID·이름과 현재 양식 | 양식 검증을 통과해야 저장합니다. |
| 목록 | 종류·검색·다음 페이지 | 저장소 결과를 표시합니다. |
| 삭제 확인 | 대상 이름과 확인·취소 | 삭제 버튼 뒤 별도 모달로 표시합니다. |

## 이벤트와 호출 기능

| 사용자 동작 | 호출 기능 | 결과 |
| --- | --- | --- |
| 저장·불러오기 | FNC-016 | 저장소를 갱신하거나 새 양식을 엽니다. |
| 삭제 확인 | FNC-016 | 대상만 삭제하고 목록을 새로 읽습니다. |

## 상태별 표시

목록 로딩·빈 결과·오류·다음 페이지를 구분합니다. 삭제 모달에서는 배경 목록을 조작할 수 없습니다.

## 입력 검증과 오류 표시

빈 ID, 유효하지 않은 현재 파일과 저장소 오류를 모달 안에 표시합니다. 실패해도 모달 입력과 양식을
유지합니다.

## 화면 전이

불러오기에 성공하면 모달을 닫고 편집 화면을 새 문서 상태로 초기화합니다.

## 관련 데이터·인터페이스·오류

| 구분 | 식별자 | 관계 |
| --- | --- | --- |
| 데이터 | DAT-011 | 목록 메타데이터를 표시합니다. |
| 인터페이스 | IF-003·IF-005 | 저장소와 디자이너 계약을 사용합니다. |
| 오류 | ERR-004·ERR-005 | 저장·화면 오류를 표시합니다. |
