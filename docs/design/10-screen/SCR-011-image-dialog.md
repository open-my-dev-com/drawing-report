# SCR-011 이미지 선택 모달

최종 갱신: 2026-09-28

## 개요

이미지 요소의 고정 이미지 파일을 선택하거나 에셋·파라미터 원본을 지정하는 화면을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 이미지 원본 선택, 파일 검사와 적용 흐름을 정의했습니다. |

## 진입·종료 조건

이미지 요소를 선택해 원본 설정 또는 파일 선택 명령을 실행하면 진입합니다.

## 화면 이미지

![이미지 요소가 있는 디자이너](../assets/SCR-001-designer-main-default-1440x810.png)

## 화면 영역

| 영역 | 입력·출력 항목 | 표시·활성화 조건 |
| --- | --- | --- |
| 원본 종류 | 고정·에셋·파라미터 | 선택 종류에 맞는 입력을 표시합니다. |
| 파일 선택 | PNG·JPEG 파일과 크기 | 고정 이미지를 선택할 때 사용합니다. |
| 미리보기·오류 | 선택 이미지 또는 검사 결과 | 읽기가 끝나면 표시합니다. |

## 이벤트와 호출 기능

| 사용자 동작 | 호출 기능 | 결과 |
| --- | --- | --- |
| 파일 선택 | FNC-011 | 형식·서명·크기를 검사합니다. |
| 원본 적용 | FNC-019 | 이미지 요소 원본을 바꿉니다. |

## 상태별 표시

선택 전, 읽는 중, 정상 미리보기와 오류를 구분합니다. 파일 대화상자 취소는 기존 이미지를 유지합니다.

## 입력 검증과 오류 표시

지원하지 않는 MIME, 손상 파일과 `maxImageBytes` 초과를 파일 선택 영역에 표시합니다.

## 화면 전이

적용·취소 뒤 이미지 속성 패널로 돌아가며 적용한 이미지는 캔버스에서 즉시 확인합니다.

## 관련 데이터·인터페이스·오류

| 구분 | 식별자 | 관계 |
| --- | --- | --- |
| 데이터 | DAT-005·DAT-009 | 이미지 요소와 에셋을 선택합니다. |
| 인터페이스 | IF-005 | 이미지 크기 설정을 사용합니다. |
| 오류 | ERR-001·ERR-003·ERR-005 | 파일·렌더·화면 오류를 표시합니다. |
