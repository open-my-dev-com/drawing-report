# SCR-013 출력 결과 미리보기

최종 갱신: 2026-09-28

## 개요

현재 양식과 샘플 값으로 만든 PDF를 디자이너 안에서 확인하는 읽기 전용 미리보기 화면을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 미리보기 전환, 로딩·오류와 PDF URL 생명주기를 정의했습니다. |

## 진입·종료 조건

편집 화면에서 미리보기를 누르면 진입하고 편집을 누르면 이전 편집 화면으로 돌아갑니다.

## 화면 이미지

![미리보기 진입 도구가 있는 디자이너](../assets/SCR-001-designer-main-default-1440x810.png)

## 화면 영역

| 영역 | 입력·출력 항목 | 표시·활성화 조건 |
| --- | --- | --- |
| 상단 도구 | 편집 전환, 저장·내 양식 | 미리보기 중 편집 명령은 비활성화합니다. |
| PDF 영역 | 로딩, 문서 또는 오류 | 렌더링 상태에 따라 하나만 표시합니다. |

## 이벤트와 호출 기능

| 사용자 동작 | 호출 기능 | 결과 |
| --- | --- | --- |
| 미리보기 진입 | FNC-013·FNC-022 | 현재 양식의 PDF를 생성합니다. |
| 편집 전환 | FNC-022 | 임시 URL을 정리하고 편집 화면을 표시합니다. |

## 상태별 표시

로딩 문구, PDF iframe과 오류 문구를 구분합니다. 양식·로케일·SlipKit 설정이 바뀌면 최신 요청으로
다시 렌더링합니다.

## 입력 검증과 오류 표시

레이아웃·폰트·이미지·바코드 오류를 현재 로케일의 미리보기 오류로 표시하고 편집 화면에서 원인을
고칠 수 있게 합니다.

## 화면 전이

편집으로 돌아가도 현재 페이지와 선택은 유지합니다. 컴포넌트가 분리되면 PDF URL을 해제합니다.

## 관련 데이터·인터페이스·오류

| 구분 | 식별자 | 관계 |
| --- | --- | --- |
| 데이터 | DAT-002·DAT-006·DAT-009 | 양식과 샘플 값을 출력합니다. |
| 인터페이스 | IF-001·IF-005 | SlipKit 렌더링과 디자이너 화면을 사용합니다. |
| 오류 | ERR-003·ERR-005 | PDF와 화면 오류를 표시합니다. |
