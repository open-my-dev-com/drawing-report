# SYS-005 국제화와 접근성

최종 갱신: 2026-09-28

## 개요

사용자 대면 문자열, 숫자·날짜 표시, 키보드 조작과 접근성 정보를 한국어·영어·일본어에서 일관되게
제공하는 공통 기준을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 로케일 선택, 번역 범위, 키보드와 보조 기술 지원 기준을 정의했습니다. |

## 로케일과 문자열

Core 인스턴스의 `locale`은 수식 형식 함수, 렌더링과 오류 메시지에 적용됩니다. UI 구성 요소는
`ko`, `en`, `ja` 문자열 묶음을 제공하고 `locale` 속성 또는 연결된 SlipKit 설정으로 언어를
선택합니다. 알 수 없는 로케일은 지원 언어의 기본값으로 정규화합니다.

| 대상 | 기준 |
| --- | --- |
| 버튼·메뉴·대화상자 | 세 언어에서 같은 기능과 상태를 표현합니다. |
| 오류·경고 | 원인과 사용자가 할 수 있는 조치를 함께 알립니다. |
| 숫자·날짜 | 수식 문법의 결정적 계산과 화면 표시용 로케일 형식을 구분합니다. |
| 파일 내용 | 키와 형식 식별자는 번역하지 않고 사용자 표시 이름만 번역할 수 있습니다. |

번역은 원문의 단어 순서를 그대로 옮기지 않고 해당 언어에서 자연스러운 문장으로 작성합니다. 코드
식별자와 파일 형식 값은 번역하지 않습니다.

## 키보드 조작

- 모든 명령 버튼, 탭, 메뉴와 대화상자는 키보드로 도달하고 실행할 수 있어야 합니다.
- 대화상자를 열면 초점을 내부로 옮기고 닫으면 진입한 컨트롤로 되돌립니다.
- 디자이너 이동·선택·실행 취소 단축키는 입력 필드 편집과 충돌하지 않아야 합니다.
- Tab 순서는 화면의 읽기 순서와 일치해야 하며 숨긴 컨트롤은 초점을 받지 않습니다.

## 의미 구조와 표시

컨트롤은 기능에 맞는 HTML 요소와 접근 가능한 이름을 사용합니다. 아이콘만 있는 버튼에는 이름과
도움말을 제공하고, 오류는 색만으로 구분하지 않습니다. 상태 변경과 검증 오류는 관련 입력과
연결하며, 동적인 미리보기는 불필요하게 보조 기술의 읽기 흐름을 방해하지 않도록 구성합니다.

## 글꼴과 문자

기본 폰트는 한국어, 영어와 일본어의 일반 문자를 표시할 수 있도록 제공합니다. 선택한 폰트에 필요한
글리프가 없으면 PDF 생성 단계에서 요소와 문자를 포함한 오류를 반환합니다. 대체 폰트를 사용하더라도
파일의 `fontName`을 바꾸지 않습니다.

## 검증 기준

- 세 로케일에서 텍스트가 잘리거나 기능 의미가 달라지지 않는지 확인합니다.
- 키보드만으로 주요 설계·작성·조회 흐름을 수행합니다.
- 실제 Chromium에서 초점 이동, 대화상자 복귀와 화면 크기별 배치를 확인합니다.
- 사용자 대면 문구와 문서의 한국어가 자연스럽고 현재 동작과 일치하는지 검토합니다.
