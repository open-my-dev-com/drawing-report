# ERR-005 화면·MCP·CLI 오류 전달

최종 갱신: 2026-09-28

## 개요

UI 비동기 작업, MCP 도구와 CLI 설정 오류를 사용자와 AI 호출자에게 일관되게 전달하는 기준을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 화면 상태, MCP 도구 오류와 CLI 설정 오류의 전달·기록 기준을 정의했습니다. |

## 오류 분류와 식별 기준

UI는 입력 필드 오류와 작업 상태 오류를 구분합니다. `McpToolError`는 도구 입력·대상·파일 작업 오류,
`SlipMcpConfigError`는 시작 전에 확인한 설정 오류입니다.

## 발생·검출 조건

컴포넌트의 불러오기·저장·렌더링, 데모 자동 저장, MCP 일곱 도구와 CLI 설정·PDF 링크 서버에서
검출합니다.

## 계층 간 전달

UI는 최신 비동기 요청만 표시하고 `slip-change`·`slip-issue` 성공 이벤트와 오류 상태를 섞지 않습니다.
MCP는 도구 실패로, CLI는 종료 코드와 표준 오류로 전달합니다.

## 사용자 표시와 호출자 처리

오류 문장은 수행하지 못한 작업, 대상과 다음 조치를 짧게 설명합니다. 번역투, 내부 구현명, 키·평문과
전체 파일 내용을 노출하지 않습니다.

## 복구·재시도·기록

입력 오류는 같은 화면에서 고칩니다. 저장·렌더·포트 오류는 원인을 고친 뒤 재시도하며, 실패한 변경은
파일에 기록하지 않습니다.

## 시험 기준

필드 오류, 비동기 경합, 자동 저장·삭제 실패, 모든 MCP 도구 오류, 잘못된 CLI 설정·포트와 ko·en·ja
문구를 시험합니다.
