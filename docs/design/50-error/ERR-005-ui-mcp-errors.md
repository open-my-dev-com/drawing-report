# ERR-005 화면·MCP·CLI 오류 전달

최종 갱신: 2026-09-28

## 개요

UI 비동기 작업, MCP 도구와 CLI 설정 오류를 사용자와 AI 호출자에게 일관되게 전달하는 기준을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 화면 상태, MCP 도구 오류와 CLI 설정 오류의 전달·기록 기준을 정의했습니다. |

## 오류 분류와 식별 기준

| 오류 식별자·종류 | 판정 조건 | 검출 위치 | 포함 정보 |
| --- | --- | --- | --- |
| 화면 입력 오류 | 한 필드 값이 필수·형식·범위 계약을 위반 | 입력 확정 전 검증 | 입력 이름과 고칠 이유 |
| 화면 작업 오류 | 파일 열기·저장·삭제·렌더링 같은 작업이 실패 | 비동기 작업 완료 | 작업 이름, 대상과 원인 |
| 오래된 화면 결과 | 완료한 요청의 세대가 현재 세대와 다름 | 비동기 결과 적용 직전 | 사용자에게 표시하지 않음 |
| `McpToolError` 입력 | 도구 JSON·ID·연산·경로가 계약을 위반 | 도구 입력 검증 | 도구, 입력 항목과 이유 |
| `McpToolError` 작업 | 파일 읽기·검증·편집·렌더링이 실패 | 도구 실행 | 대상 ID, 실패 단계와 수정 방향 |
| `SlipMcpConfigError` | 루트·로케일·폰트·포트·키 설정이 잘못됨 | 서버 시작 전 설정 검증 | 설정 항목과 기대 형식 |
| CLI 사용법 오류 | 모르는 옵션, 값 누락, 위치 인자 초과 | 인자 파싱 | 잘못된 인자와 사용법 |

## 발생·검출 조건

컴포넌트의 불러오기·저장·렌더링, 데모 자동 저장, MCP 일곱 도구와 CLI 설정·PDF 링크 서버에서
검출합니다.

## 계층 간 전달

| 검출 계층 | 전달 대상 | 전달 방식 | 변환·숨김 규칙 |
| --- | --- | --- | --- |
| 입력 컨트롤 | 화면 사용자 | 입력 가까운 붉은 문구와 오류 상태 | 마지막 유효 문서는 유지합니다. |
| 화면 비동기 작업 | 화면 사용자 | 모달·패널·PDF 영역의 작업 오류 | 최신 요청의 오류만 표시합니다. |
| MCP 도구 | AI 클라이언트 | `isError: true` 텍스트·구조 결과 | 키·평문·Base64 전체와 내부 스택을 숨깁니다. |
| CLI 설정·실행 | 운영자 | 표준 오류와 종료 코드 1 또는 2 | 프로토콜 표준 출력과 섞지 않습니다. |

## 사용자 표시와 호출자 처리

오류 문장은 수행하지 못한 작업, 대상과 다음 조치를 짧게 설명합니다. 번역투, 내부 구현명, 키·평문과
전체 파일 내용을 노출하지 않습니다.

## 복구·재시도·기록

| 오류 종류 | 보존하는 값 | 되돌리는 값 | 사용자의 복구 절차 | 자동 재시도·기록 |
| --- | --- | --- | --- | --- |
| 화면 입력 | 입력 중인 값과 마지막 유효 문서 | 실패한 문서 반영 | 같은 필드에서 값 수정 | 수정할 때 재검증, 자동 저장 금지 |
| 화면 저장·삭제 | 현재 양식·전표와 모달 입력 | 실패한 저장 결과 | 원인 해결 후 같은 모달에서 재시도 | 예약 자동 저장과 경합하지 않음 |
| 화면 렌더 | 입력 파일과 마지막 성공 PDF | 실패한 PDF·Blob URL | 값·양식·폰트 수정 후 재시도 | 최신 입력에는 자동 재생성 가능 |
| MCP 도구 | 기존 파일과 캐시의 이전 유효 결과 | 편집 복사본·임시 파일 | 요약 재조회 후 입력 수정 | 변경 묶음 전체 원자적 취소 |
| CLI 설정·포트 | 설정 파일과 기존 파일 | 시작 중인 서버 자원 | 설정·포트 수정 후 프로세스 재시작 | 같은 실패를 무한 재시도하지 않음 |

## 시험 기준

필드 오류, 비동기 경합, 자동 저장·삭제 실패, 모든 MCP 도구 오류, 잘못된 CLI 설정·포트와 ko·en·ja
문구를 시험합니다.
