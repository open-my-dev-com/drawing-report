# ERR-004 저장·암호화·파일 교환 오류

최종 갱신: 2026-09-28

## 개요

저장소 I/O, 사용자 취소와 암호화 키·봉투 문제를 구분해 호출자가 올바르게 복구하도록 하는 기준을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 저장 오류 코드, 암호화 오류와 재시도 경계를 정의했습니다. |

## 오류 분류와 식별 기준

`SlipStorageError.code`는 `not-found`, `unsupported`, `io`, `cancelled`입니다.
`SlipEncryptionError`는 키 없음·형식·불일치, 봉투 손상·미지원과 Web Crypto 부재를 나타냅니다.

## 발생·검출 조건

FNC-015~FNC-018과 MCP 파일 저장소가 구성 검증, 암·복호화, 트랜잭션과 파일 대화상자에서 검출합니다.

## 계층 간 전달

브라우저 원인은 `cause`에 남기고 사용자 메시지는 로케일 사전을 사용합니다. 키 불일치 표시만 이전 키
시도를 허용하며 다른 오류는 즉시 전달합니다.

## 사용자 표시와 호출자 처리

취소는 실패 경고와 구분합니다. 키나 평문, 파일 본문과 로컬 절대 경로를 사용자 메시지·로그에 넣지
않습니다.

## 복구·재시도·기록

I/O 실패는 기존 파일을 유지한 채 재시도할 수 있습니다. 잘못된 키 구성은 인스턴스 생성 시 고치고,
키 불일치는 올바른 키를 제공해야 합니다.

## 시험 기준

오류 코드 네 가지, 차단·닫힌 IndexedDB, 파일 선택 취소, 키 구성·교체·변조와 실패 뒤 기존 데이터
보존을 시험합니다.

- 인터페이스: IF-001·IF-003
