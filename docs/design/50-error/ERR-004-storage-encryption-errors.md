# ERR-004 저장·암호화·파일 교환 오류

최종 갱신: 2026-09-28

## 개요

저장소 I/O, 사용자 취소와 암호화 키·봉투 문제를 구분해 호출자가 올바르게 복구하도록 하는 기준을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 저장 오류 코드, 암호화 오류와 재시도 경계를 정의했습니다. |

## 오류 분류와 식별 기준

| 오류 식별자·종류 | 판정 조건 | 검출 위치 | 포함 정보 |
| --- | --- | --- | --- |
| 저장 `not-found` | 요청한 ID·버전·파일이 없음 | 저장소 조회·삭제 | 작업과 대상 ID |
| 저장 `unsupported` | 구현이 선택 기능을 제공하지 않음 | 기능 지원 확인 | 요청한 기능 이름 |
| 저장 `io` | 연결·트랜잭션·파일 읽기·쓰기 실패 | 저장소 구현 | 작업, 대상과 원인 예외 |
| 저장 `cancelled` | 사용자가 파일 선택·저장 대화상자를 닫음 | 브라우저 파일 교환 | 취소한 작업 |
| 암호화 키 설정 | 키 없음, 원시 키 길이 오류, 이전 키 형식 오류 | 인스턴스·서버 구성 | 잘못된 항목 이름, 기대 형식 |
| 암호화 키 불일치 | 봉투 인증을 현재·이전 키가 모두 통과하지 못함 | 복호화 | 키 불일치 종류만 포함 |
| 암호화 봉투 | 버전·알고리즘·KDF·인코딩·길이·인증 정보가 잘못됨 | 봉투 파싱·복호화 | 실패한 봉투 항목과 이유 |
| Web Crypto 부재 | 실행 환경에 필요한 암호화 API가 없음 | 암·복호화 시작 | 필요한 실행 환경 기능 |

## 발생·검출 조건

FNC-015~FNC-018과 MCP 파일 저장소가 구성 검증, 암·복호화, 트랜잭션과 파일 대화상자에서 검출합니다.

## 계층 간 전달

| 검출 계층 | 전달 대상 | 전달 방식 | 변환·숨김 규칙 |
| --- | --- | --- | --- |
| 저장소 구현 | Core·Elements | `SlipStorageError` | 원인 예외는 `cause`에 두고 코드는 유지합니다. |
| Core 암호화 | 직접 호출자 | `SlipEncryptionError` | 키 값, 평문과 인증 태그를 숨깁니다. |
| Elements | 화면 사용자 | 작업 모달 또는 화면 오류 | 취소는 실패 경고로 표시하지 않습니다. |
| MCP·CLI | AI·운영자 | 도구 오류 또는 표준 오류 | 절대 경로와 키 내용을 숨기고 설정 항목만 알립니다. |

## 사용자 표시와 호출자 처리

취소는 실패 경고와 구분합니다. 키나 평문, 파일 본문과 로컬 절대 경로를 사용자 메시지·로그에 넣지
않습니다.

## 복구·재시도·기록

| 오류 종류 | 보존하는 값 | 되돌리는 값 | 사용자의 복구 절차 | 자동 재시도·기록 |
| --- | --- | --- | --- | --- |
| 저장 I/O | 기존 파일·메타데이터와 현재 화면 | 임시 파일·실패한 트랜잭션 | 연결·권한·공간 확인 뒤 같은 작업 재시도 | 자동 반복 없음, 원자적 이전 상태 보존 |
| 없음 | 현재 화면과 다른 저장 항목 | 없음 | 최신 목록 확인 또는 새 ID 선택 | 같은 ID 자동 생성 없음 |
| 취소 | 현재 화면·입력·저장 파일 | 임시 파일 입력 요소 | 원하면 대화상자 다시 열기 | 오류 로그를 남기지 않음 |
| 키 설정 | 입력 봉투와 저장 파일 | 생성 중인 인스턴스·서버 | 올바른 키 설정 뒤 다시 생성 | 작업 시작 전 실패 |
| 키 불일치·봉투 오류 | 암호화 원문 그대로 | 복호화 중간 바이트 | 올바른 키 또는 정상 봉투 제공 | 키 불일치만 이전 키 순회 |

보존을 시험합니다.
