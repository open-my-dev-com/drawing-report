# ERR-001 파일 파싱·검증·마이그레이션 오류

최종 갱신: 2026-09-28

## 개요

외부 `.slip` 내용을 현재 파일 구조로 만들 수 없을 때 사용하는 오류와 전달 기준을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | JSON, 스키마, 의미 검증과 버전 오류의 검출·표시 기준을 정의했습니다. |

## 오류 분류와 식별 기준

`SlipParseError`는 JSON·구조·교차 필드 오류이며 경로별 문제를 담습니다. `SlipMigrationError`는 버전
형식, 미래 버전, 경로 누락과 순환을 나타냅니다.

## 발생·검출 조건

FNC-001·FNC-002가 BOM 제거와 JSON 파싱, 버전 이동, 스키마와 의미 검증 순서로 검출합니다.

## 계층 간 전달

Core는 원인 오류를 해당 공개 오류로 감싸고, Elements·MCP는 오류 이름과 메시지를 보존해 화면 또는
도구 결과로 전달합니다.

## 사용자 표시와 호출자 처리

사용자가 고칠 수 있는 경로와 이유를 현재 로케일로 표시합니다. 원문 전체나 암호화 평문을 로그에
남기지 않습니다.

## 복구·재시도·기록

원본 파일을 고친 뒤 처음부터 다시 읽습니다. 알 수 없는 필드를 삭제하거나 미래 버전을 현재 버전으로
추정하지 않습니다.

## 시험 기준

BOM, JSON 오류, 모든 스키마 경로, 중복 ID, 이미지, 현재·이전·미래 버전과 세 로케일을 시험합니다.

- 데이터: DAT-001~DAT-010
