# ERR-001 파일 파싱·검증·마이그레이션 오류

최종 갱신: 2026-09-28

## 개요

외부 `.slip` 내용을 현재 파일 구조로 만들 수 없을 때 사용하는 오류와 전달 기준을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | JSON, 스키마, 의미 검증과 버전 오류의 검출·표시 기준을 정의했습니다. |

## 오류 분류와 식별 기준

| 오류 식별자·종류 | 판정 조건 | 검출 위치 | 포함 정보 |
| --- | --- | --- | --- |
| `SlipParseError` JSON | BOM 제거 뒤 JSON 문법을 해석할 수 없음 | 문자열 파싱 | 문법 원인, 원인 예외 |
| `SlipParseError` 구조 | 필수 필드·자료형·범위·열거값이 맞지 않음 | Zod 구조 검증 | 값 경로, 로케일화된 이유 |
| `SlipParseError` 의미 | 중복 ID·잘못된 참조·이미지 내용 등 필드 간 규칙 위반 | 교차 필드 검증 | 값 경로, 대상과 이유 |
| `SlipMigrationError` 형식 | 버전이 숫자 세 부분 형식이 아님 | 파일 봉투 확인 | 받은 버전 문자열 |
| `SlipMigrationError` 미지원 | 현재보다 새 버전이거나 연결된 이전 단계가 없음 | 마이그레이션 경로 결정 | 입력 버전, 현재 버전 |
| `SlipMigrationError` 순환 | 같은 버전 단계로 다시 돌아옴 | 단계 적용 기록 확인 | 순환한 버전 경로 |

## 발생·검출 조건

FNC-001·FNC-002가 BOM 제거와 JSON 파싱, 버전 이동, 스키마와 의미 검증 순서로 검출합니다.

## 계층 간 전달

| 검출 계층 | 전달 대상 | 전달 방식 | 변환·숨김 규칙 |
| --- | --- | --- | --- |
| Core 파서 | 직접 호출자 | 공개 오류 예외 | 입력 경로와 원인을 보존합니다. |
| Elements | 화면 사용자 | 전체 화면 또는 입력 가까운 오류 문구 | 내부 스택과 전체 원문을 숨깁니다. |
| MCP | AI 클라이언트 | `isError: true` 도구 결과 | 파일 ID와 수정 가능한 원인을 남기고 평문 전체를 숨깁니다. |

## 사용자 표시와 호출자 처리

사용자가 고칠 수 있는 경로와 이유를 현재 로케일로 표시합니다. 원문 전체나 암호화 평문을 로그에
남기지 않습니다.

## 복구·재시도·기록

| 오류 종류 | 보존하는 값 | 되돌리는 값 | 사용자의 복구 절차 | 자동 재시도·기록 |
| --- | --- | --- | --- | --- |
| JSON·구조·의미 오류 | 현재 유효한 화면·저장 파일 | 실패한 입력으로 만든 임시 상태 | 보고된 경로를 고치고 전체 파일 다시 열기 | 자동 재시도 없음, 원문 전체 로그 금지 |
| 버전 형식·미지원 | 원본 파일 | 마이그레이션 중간 객체 | 지원 버전으로 내보내거나 마이그레이션 단계 추가 | 추정 변환 없음 |
| 단계 순환 | 원본 파일 | 모든 중간 객체 | 버전 단계 정의 수정 | 방문 버전 목록만 오류 정보로 기록 |

## 시험 기준

BOM, JSON 오류, 모든 스키마 경로, 중복 ID, 이미지, 현재·이전·미래 버전과 세 로케일을 시험합니다.
