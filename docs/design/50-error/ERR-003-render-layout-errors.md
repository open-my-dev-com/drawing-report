# ERR-003 레이아웃·렌더링·PDF 오류

최종 갱신: 2026-09-28

## 개요

출력 페이지 계획, 요소 변환과 PDF 생성이 완료되지 못할 때의 오류 경계를 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 배치와 렌더 오류의 검출, 전달과 전체 실패 원칙을 정의했습니다. |

## 오류 분류와 식별 기준

`SlipLayoutError`는 흐름 영역, 겹침, 높이, 페이지 상한과 계획 불안정 오류입니다.
`SlipRenderError`는 글자·폰트·이미지·바코드·조건부 서식과 PDF 생성 오류입니다.

## 발생·검출 조건

FNC-007·FNC-008 계획과 FNC-010~FNC-014 변환·생성 단계에서 검출합니다.

## 계층 간 전달

Core는 대상 이름·ID와 원인을 포함해 던집니다. UI는 PDF 대신 오류 상태를 표시하고 MCP는 도구 실패로
반환합니다.

## 사용자 표시와 호출자 처리

사용자가 고쳐야 할 요소·설정과 이유를 알려 줍니다. 여러 페이지 중 일부만 성공 결과로 제공하지
않습니다.

## 복구·재시도·기록

양식, 값, 이미지 또는 폰트를 고친 뒤 전체 계획과 PDF를 다시 만듭니다. 최신 UI 요청만 오류 상태를
바꿀 수 있습니다.

## 시험 기준

너무 큰 행·요소, 겹침, 페이지 상한, 글리프·이미지·바코드·조건 오류, pdfme 실패와 Node.js·Chromium
전달을 시험합니다.

## 관련 설계와 근거

- 기능: FNC-007~FNC-014·FNC-022
- 화면: SCR-013~SCR-015
- `packages/core/src/layout/errors.ts`
- `packages/core/src/render/errors.ts`
