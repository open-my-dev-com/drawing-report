# ERR-003 레이아웃·렌더링·PDF 오류

최종 갱신: 2026-09-28

## 개요

출력 페이지 계획, 요소 변환과 PDF 생성이 완료되지 못할 때의 오류 경계를 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 배치와 렌더 오류의 검출, 전달과 전체 실패 원칙을 정의했습니다. |

## 오류 분류와 식별 기준

| 오류 식별자·종류 | 판정 조건 | 검출 위치 | 포함 정보 |
| --- | --- | --- | --- |
| `SlipLayoutError` 흐름 | 고정 구간·항목·이어 배치 요소가 빈 흐름 영역에도 들어가지 않음 | 페이지·그리드 계획 | 페이지, 요소, 필요한 높이와 가능한 높이 |
| `SlipLayoutError` 관계 | 이어 배치 순환·겹침 또는 계획이 안정되지 않음 | 페이지 계획 | 관련 요소 ID와 관계 |
| `SlipLayoutError` 상한 | 한 원본 페이지의 출력 페이지가 2,000개를 넘음 | 페이지 계획 | 원본 페이지와 계산 수 |
| `SlipRenderError` 내용 | 글리프·이미지·바코드·조건식 결과가 출력 계약을 위반 | 요소 변환 | 요소·셀 이름, 값 종류와 이유 |
| `SlipRenderError` 생성 | PDF 생성기가 바이트를 만들지 못함 | 최종 PDF 생성 | 원인 예외와 렌더 단계 |

## 발생·검출 조건

FNC-007·FNC-008 계획과 FNC-010~FNC-014 변환·생성 단계에서 검출합니다.

## 계층 간 전달

| 검출 계층 | 전달 대상 | 전달 방식 | 변환·숨김 규칙 |
| --- | --- | --- | --- |
| Core 계획·변환 | 직접 호출자 | 공개 오류 예외 | 요소 이름·ID와 원인을 보존합니다. |
| Elements | 화면 사용자 | PDF 영역의 오류 상태 | 실패한 PDF와 Blob URL을 표시하지 않습니다. |
| MCP | AI 클라이언트 | `isError: true` 도구 결과 | 수정 대상과 이유를 남기고 내부 스택을 숨깁니다. |

## 사용자 표시와 호출자 처리

사용자가 고쳐야 할 요소·설정과 이유를 알려 줍니다. 여러 페이지 중 일부만 성공 결과로 제공하지
않습니다.

## 복구·재시도·기록

| 오류 종류 | 보존하는 값 | 되돌리는 값 | 사용자의 복구 절차 | 자동 재시도·기록 |
| --- | --- | --- | --- | --- |
| 레이아웃 | 양식·값과 마지막 성공 PDF | 실패한 계획 전체 | 흐름 영역·행 높이·반복·이어 배치 수정 | 전체 계획부터 다시 실행 |

| 비동기 UI | 최신 입력과 기존 표시 | 오래된 요청의 성공·오류 | 최신 입력으로 자동 재생성 | 요청 세대가 다른 결과 폐기 |

전달을 시험합니다.
