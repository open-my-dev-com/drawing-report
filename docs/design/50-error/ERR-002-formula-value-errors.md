# ERR-002 수식과 값 오류

최종 갱신: 2026-09-28

## 개요

수식 문법, 계산과 전표 값이 올바르지 않을 때의 오류 분류와 화면·렌더링 처리 기준을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 문법·평가·입력 값 오류의 구분, 전달과 복구 기준을 정의했습니다. |

## 오류 분류와 식별 기준

| 오류 식별자·종류 | 판정 조건 | 검출 위치 | 포함 정보 |
| --- | --- | --- | --- |
| `FormulaSyntaxError` | 토큰·괄호·문자열·참조·함수·인자 수·깊이가 문법 계약을 위반 | 수식 파서 | 수식 위치와 이유 |
| `FormulaEvalError` 수식 | 연산·함수·예약 참조를 올바른 값으로 계산할 수 없음 | 수식 평가기 | 오류 종류, 데이터 의존 여부, 원인 |
| `FormulaEvalError` 데이터 | 값 누락·종류 불일치·숫자 없는 집계처럼 입력에 따라 해소 가능 | 수식 평가기 | 참조 경로, 데이터 의존 표시 |
| 입력 값 오류 | 파라미터 종류, 날짜, 이미지 또는 목록 행 구조가 맞지 않음 | 작성 폼·발행 검증 | 파라미터 경로와 기대 형식 |

## 발생·검출 조건

FNC-004 파싱·진단, FNC-005 평가와 작성 폼의 값 검증에서 검출합니다. 공백 수식은 호출 화면과 PDF에서
빈 값으로 처리합니다.

## 계층 간 전달

| 검출 계층 | 전달 대상 | 전달 방식 | 변환·숨김 규칙 |
| --- | --- | --- | --- |
| 수식 파서·진단기 | 디자이너 | 수식 입력 아래 오류와 경고 배지 | 오류 위치와 이유를 보존합니다. |
| 수식 평가기 | 작성 폼 | 대상 입력 또는 계산값 가까운 오류 | 값 전체와 내부 스택을 숨깁니다. |
| 조건부 서식 | 렌더러 | 평가 오류는 규칙 미적용 | 문법 오류와 비논리 결과만 렌더 오류로 바꿉니다. |
| PDF 변환 | UI·MCP | `SlipRenderError` | 요소·셀 이름과 고칠 이유를 포함합니다. |

## 사용자 표시와 호출자 처리

필드·수식 대상과 고칠 이유를 자연스러운 문장으로 표시합니다. 내부 스택과 값 전체는 사용자 메시지에
넣지 않습니다.

## 복구·재시도·기록

| 오류 종류 | 보존하는 값 | 되돌리는 값 | 사용자의 복구 절차 | 자동 재시도·기록 |
| --- | --- | --- | --- | --- |
| 수식 문법 | 입력한 수식 원문과 이전 유효 문서 | 실패한 문서 변경 | 원문을 고친 뒤 다시 진단·적용 | 입력 변경마다 즉시 재진단 |
| 계산 오류 | 원본 수식과 값 | 실패한 계산 결과 | 값 또는 수식 수정 | 0이나 빈 문자열로 대체하지 않음 |
| 입력 값 오류 | 사용자가 입력한 화면 값과 마지막 유효 전표 | 실패한 발행 상태 | 해당 입력 수정 후 발행 재시도 | 유효해질 때 다시 계산 |

## 시험 기준

문법 위치, 함수 인자, 타입, 0 나누기, 값 누락, 예약 참조, 조건부 서식 분기와 화면·PDF 일치를
시험합니다.
