# ERR-002 수식과 값 오류

최종 갱신: 2026-09-28

## 개요

수식 문법, 계산과 전표 값이 올바르지 않을 때의 오류 분류와 화면·렌더링 처리 기준을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 문법·평가·입력 값 오류의 구분, 전달과 복구 기준을 정의했습니다. |

## 오류 분류와 식별 기준

`FormulaSyntaxError`는 위치가 있는 수식 자체 오류입니다. `FormulaEvalError`는 `formula` 또는 `data`
이유와 데이터 의존 여부를 가집니다. 입력 값 오류는 파라미터 경로로 식별합니다.

## 발생·검출 조건

FNC-004 파싱·진단, FNC-005 평가와 작성 폼의 값 검증에서 검출합니다. 공백 수식은 호출 화면과 PDF에서
빈 값으로 처리합니다.

## 계층 간 전달

수식 편집기는 상세 오류를 표시합니다. 조건부 서식은 모든 평가 오류를 규칙 미적용으로 처리하되 문법과
비논리 결과는 렌더 오류로 전달합니다.

## 사용자 표시와 호출자 처리

필드·수식 대상과 고칠 이유를 자연스러운 문장으로 표시합니다. 내부 스택과 값 전체는 사용자 메시지에
넣지 않습니다.

## 복구·재시도·기록

사용자가 수식이나 값을 고치면 즉시 다시 진단합니다. 잘못된 계산을 0이나 빈 문자열로 저장하지
않습니다.

## 시험 기준

문법 위치, 함수 인자, 타입, 0 나누기, 값 누락, 예약 참조, 조건부 서식 분기와 화면·PDF 일치를
시험합니다.

## 관련 설계와 근거

- 기능: FNC-004·FNC-005·FNC-009
- 화면: SCR-007·SCR-008·SCR-014
- `packages/core/src/formula/errors.ts`
