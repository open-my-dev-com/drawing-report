# 요구사항 추적표

최종 갱신: 2026-09-28

## 개요

요구사항 영역에서 관련 화면, 기능, 데이터, 인터페이스와 오류 설계로 이어지는 경로를 관리합니다.
표는 요구사항 영역별로 관련 설계 식별자를 연결합니다. 설계서를 작성한 묶음은 구현과 규범 문서를
대조한 상태이며, 남은 묶음은 문서를 작성할 때 세부 요구사항과 시험 근거를 보완합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 12개 요구사항 영역을 73개 설계 대상에 연결하고 공통·데이터·인터페이스 설계를 대조했습니다. |

| 범위 | 상태 | 확인 기준 |

| `SYS-001`~`SYS-006` | 검토 완료 | 아키텍처, 요구사항, 설계 결정과 패키지 구성을 대조했습니다. |
| `DAT-001`~`DAT-011` | 검토 완료 | 파일 명세, Core 스키마, 저장소와 MCP 설정을 대조했습니다. |
| `IF-001`~`IF-010` | 검토 완료 | 공개 export, 타입 선언, UI 래퍼와 MCP 도구 계약을 대조했습니다. |
| 나머지 설계 | 예정 | 해당 커밋 단계에서 구현, 규범 문서와 시험을 대조합니다. |

## 세부 추적 규칙

- 설계서를 작성할 때 관련 요구사항 ID, ADR, 다른 설계 문서와 시험 근거를 문서 안에 기록합니다.
- 요구사항 하나가 여러 설계서에 걸리면 주 설계서와 보조 설계서를 구분합니다.
- 코드 경로는 사실 확인 근거로만 사용하고 추적표의 종착점으로 삼지 않습니다.
- 설계서가 `검토 완료`가 되기 전에 요구사항 ID별 누락과 서로 끊어진 참조가 없는지 확인합니다.
