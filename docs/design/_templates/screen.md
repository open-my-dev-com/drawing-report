# SCR-### 화면 설계 제목

최종 갱신: YYYY-MM-DD

## 개요

화면의 목적, 사용자와 적용 범위를 설명합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| YYYY-MM-DD | 신규 작성 | 작성한 화면 영역, 상태와 상호작용을 구체적으로 요약합니다. |

## 설계 범위

- 이 문서가 직접 정의하는 화면 영역과 동작을 적습니다.
- 다른 화면 설계서가 맡는 하위 영역은 식별자와 이름만 연결하고 세부 조작을 반복하지 않습니다.

## 진입·종료 조건

### 진입 조건

- 사용자가 이 화면을 보게 되는 시작 위치와 실행 동작을 적습니다.
- 입력 데이터가 없거나 잘못되었을 때 화면 대신 무엇을 표시하는지 적습니다.

### 종료 조건

- 사용자가 화면을 닫거나 다른 화면으로 이동하는 동작을 하나씩 적습니다.
- 컴포넌트 연결 해제처럼 호스트가 화면을 끝내는 조건은 사용자 동작과 구분합니다.

## 화면 이미지

이 문서가 직접 설명하는 화면을 실제로 촬영하고, 설명할 항목마다 번호를 표시합니다. 번호는 아래
화면 구성 표와 같아야 합니다. 전체 화면의 일부를 설명하는 문서는 해당 부분을 알아볼 수 있는 크기로
잘라 사용하며 상위 화면의 번호를 그대로 재사용하지 않습니다.

| --- | --- | --- | --- | --- |

## 이벤트와 호출 기능

한 행에는 사용자 동작 하나만 적습니다. 추가와 삭제처럼 결과가 다른 동작을 한 행에 묶지 않습니다.
버튼이 비활성화되는 조건은 별도 열에 반복하지 않고 동작과 결과 문장에 포함합니다.
