# SCR-### 화면 설계 제목

최종 갱신: YYYY-MM-DD

## 개요

화면의 목적, 사용자와 적용 범위를 설명합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| YYYY-MM-DD | 신규 작성 | 작성한 화면 영역, 상태와 상호작용을 구체적으로 요약합니다. |

## 진입·종료 조건

### 진입 조건

- 사용자가 이 화면을 보게 되는 시작 위치와 실행 동작을 적습니다.
- 입력 데이터가 없거나 잘못되었을 때 화면 대신 무엇을 표시하는지 적습니다.

### 종료 조건

- 사용자가 화면을 닫거나 다른 화면으로 이동하는 동작을 하나씩 적습니다.
- 컴포넌트 연결 해제처럼 호스트가 화면을 끝내는 조건은 사용자 동작과 구분합니다.

## 화면 이미지

화면을 실제로 촬영한 이미지에 번호를 표시합니다. 번호는 아래 화면 구성 표의 번호와 같아야 합니다.
다른 화면의 이미지를 대신 사용하지 않습니다.

## 화면 구성

| 번호 | 화면 항목 | 표시 내용 | 표시 조건 | 활성화 조건 |
| --- | --- | --- | --- | --- |
| 1 | 항목 이름 | 사용자가 보는 값을 설명합니다. | 항목을 표시하는 조건을 설명합니다. | 조작할 수 있는 조건을 설명합니다. |

## 이벤트와 호출 기능

한 행에는 사용자 동작 하나만 적습니다. 추가와 삭제처럼 결과가 다른 동작을 한 행에 묶지 않습니다.

| 화면 항목 | 사용자 동작 | 호출 기능 | 결과 | 실행할 수 없는 조건 |
| --- | --- | --- | --- | --- |
| 항목 이름 | 동작 하나를 설명합니다. | FNC-### | 화면과 데이터가 어떻게 바뀌는지 설명합니다. | 해당 동작을 막는 조건을 설명합니다. |

## 상태별 표시

| 상태 | 진입 조건 | 표시 내용 | 허용 동작 |
| --- | --- | --- | --- |
| 상태 이름 | 상태가 시작되는 조건을 설명합니다. | 이전 상태와 달라지는 화면을 설명합니다. | 사용자가 실행할 수 있는 동작을 설명합니다. |

## 입력 검증과 오류 표시

| 검사 대상 | 실패 조건 | 표시 위치와 표현 | 문서·화면 처리 | 복구 방법 |
| --- | --- | --- | --- | --- |
| 입력 이름 | 실패 조건을 설명합니다. | 오류가 보이는 위치와 시각·접근성 표현을 설명합니다. | 반영, 차단 또는 기존 값 유지 여부를 설명합니다. | 사용자가 정상 상태로 돌아가는 방법을 설명합니다. |
