# 설계 자산 관리

최종 갱신: 2026-09-28

## 개요

화면 설계서에서 사용하는 화면 이미지와 설계 설명용 정적 자산을 관리합니다. 이미지는 실제 빌드의
동작을 재현한 뒤 저장하며 장식용 이미지는 두지 않습니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 설계 자산 관리 기준, 실제 화면, 출력 PDF와 화면별 번호 주석 이미지를 기록했습니다. |

## 저장 기준

- 화면 이미지는 `SCR-001-designer-main-default-1440x810.png`처럼 화면 식별자, 상태와 화면 크기를
  파일명에 포함합니다.
- 모든 화면 설계서는 주요 영역 번호가 보이는 `SCR-###-...-annotated.png`를 사용합니다. 번호는 화면
  구성 표와 같아야 하며 번호가 없는 원본 PNG도 함께 둡니다.
- 주석 PNG는 실제 화면 위에 번호와 연결선만 합성합니다. 구성 요소를 임의로 그려 실제 화면처럼
  제시하지 않습니다.
- 번호 위치를 수정할 수 있도록 같은 이름의 SVG 원본을 함께 둡니다. 화면 설계서에는 외부 이미지를
  참조하는 SVG 대신 배경까지 합친 PNG를 연결해 GitHub에서도 같은 화면이 보이게 합니다.
- 모달, 미리보기와 오류처럼 기본 화면과 구조가 다른 상태는 진입 버튼이 있는 화면으로 대신하지 않고
  해당 상태를 실제로 열어 촬영합니다.
- 예제 값만 사용하며 개인정보, 로컬 경로, 토큰과 암호화 키를 포함하지 않습니다.
- 같은 상태를 설명하는 이미지가 여러 문서에 필요하면 한 파일을 공유합니다.
- 이미지를 바꾸면 이를 참조하는 화면 설계서의 최종 갱신 날짜와 변경 이력을 함께 갱신합니다.
