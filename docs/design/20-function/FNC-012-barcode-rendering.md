# FNC-012 바코드 생성

최종 갱신: 2026-09-28

## 개요

바코드 요소의 고정값·파라미터·수식 결과를 종류별 규칙으로 검사하고 PDF용 바코드로 변환하는 흐름을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 값 해석, 종류별 형식 검사와 오류 처리를 정의했습니다. |

## 호출 조건

디자이너 미리보기와 PDF가 바코드 요소를 표시할 때 호출합니다.

## 입력·출력

| 구분 | 항목 | 자료형·단위 | 필수 여부·기본값 | 제약과 보장 |
| --- | --- | --- | --- | --- |
| 입력 | 바코드 종류 | 지원 종류 문자열 | 필수 | QR, Code 128·39, EAN-13·8, UPC-A·E, ITF-14, NW-7, Japan Post, GS1 DataMatrix, PDF417 중 하나입니다. |
| 입력 | 값 원본 | 고정 문자열·파라미터·수식 중 하나 | 필수 | 종류별 문자와 길이 규칙을 따라야 합니다. |
| 입력 | 평가 문맥 | `FormulaContext` | 수식·파라미터에 필수 | 현재 전표와 항목 값을 제공합니다. |
| 출력 | 렌더 설정 | 검증된 문자열과 종류별 옵션 | 성공 시 반환 | 바코드 플러그인에 바로 전달할 수 있습니다. |

## 사전·사후 조건

수식 결과는 문자열이나 숫자로 표현할 수 있어야 합니다. 종류별 허용 문자, 길이, 자리 수와 검사 숫자
규칙을 통과해야 합니다.

## 정상 처리 흐름

```mermaid
flowchart LR
    Source[값 원본] --> Resolve[값 해석]
    Resolve --> Validate[종류별 검사]
    Validate --> Render[바코드 렌더]
```

| 순서 | 처리 | 읽는 값 | 만드는 값·변경하는 값 | 다음 단계 |
| --- | --- | --- | --- | --- |
| 1 | 고정 문자열, 파라미터 또는 수식 가운데 지정한 값 원본을 해석합니다. | 바코드 요소, 전표 값 | 바코드 문자열 | 종류별 검증 |
| 2 | 선택한 바코드 규격의 길이, 문자 집합과 검사 숫자 조건을 확인합니다. | 바코드 종류와 문자열 | 검증된 바코드 값 | 그림 생성 |
| 3 | 요소 크기와 색을 사용해 막대 또는 셀 그림을 만들고 PDF 요소로 넘깁니다. | 검증된 값, 요소 스타일 | 바코드 출력 데이터 | 반환 |

## 분기와 예외 흐름

QR, Code 128, EAN, UPC, ITF, NW-7, GS1 DataMatrix와 PDF417에 서로 다른 규칙을 적용합니다. 값이
없거나 형식이 맞지 않으면 잘못된 바코드를 만들지 않고 렌더 오류로 알립니다.

## 데이터 조회·변경

전표 값과 요소 설정을 읽을 뿐 원본을 바꾸지 않습니다.

## 하위 기능과 시퀀스

FNC-005로 수식을 계산하고 `isValidBarcodeValue()`로 검사한 뒤 FNC-013 변환기가 플러그인 스키마를
만듭니다.

## 오류·복구

자동으로 검사 숫자를 덧붙이거나 값을 자르지 않습니다. 사용자가 값 또는 바코드 종류를 고쳐야 합니다.

## 동시 실행·반복 호출

바코드 검사는 전달받은 종류와 값만 읽으며 호출 간 상태를 공유하지 않습니다. 같은 종류와 값에는 같은
검사 결과를 반환하고, 렌더 플러그인은 요소마다 독립된 설정을 받습니다.

## 검증 기준

지원하는 모든 종류의 정상·길이 초과·문자 위반·검사 숫자 오류와 고정·파라미터·수식 값을 시험합니다.
