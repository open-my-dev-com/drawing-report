# FNC-017 IndexedDB 저장

최종 갱신: 2026-09-28

## 개요

브라우저 IndexedDB에 파일 본문과 목록 메타데이터를 나누어 저장하고 최근 수정순으로 조회하는 구현
흐름을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 데이터베이스 열기·이전, 본문 저장과 메타데이터 목록 조회를 정의했습니다. |

## 호출 조건

호스트가 `IndexedDbStorage`를 만들어 디자이너나 애플리케이션의 `StorageAdapter`로 제공할 때
사용합니다.

## 입력·출력

| 구분 | 항목 | 자료형·단위 | 필수 여부·기본값 | 제약과 보장 |
| --- | --- | --- | --- | --- |
| 입력 | 데이터베이스 이름 | 문자열 | 선택·기본 이름 | 같은 이름은 같은 브라우저 저장 공간을 사용합니다. |
| 입력 | 목록 페이지 크기 | 안전한 정수 | 선택·구현 기본값 | 1 이상이어야 합니다. |
| 입력 | 암호화 설정 | 현재·이전 키 | 선택·평문 저장 | 본문 Blob에만 적용하고 메타데이터는 평문입니다. |
| 출력 | 저장소 작업 결과 | 파일·목록 페이지·`void` | 메서드별 성공 시 | 본문과 메타데이터 트랜잭션이 완료된 뒤 반환합니다. |

## 사전·사후 조건

데이터베이스 버전은 3입니다. 버전 1 문자열 본문은 Blob으로 바꾸고, 기존 레코드의 목록 메타데이터를
채웁니다. 저장 시 본문과 메타데이터는 같은 트랜잭션에서 바뀝니다.

## 정상 처리 흐름

```mermaid
flowchart LR
    Open[데이터베이스 열기] --> Upgrade[필요한 이전 수행]
    Upgrade --> Body[본문 스토어]
    Upgrade --> Meta[메타데이터 스토어]
    Meta --> List[필터·정렬·페이지 조회]
```

| 순서 | 처리 | 읽는 값 | 만드는 값·변경하는 값 | 다음 단계 |
| --- | --- | --- | --- | --- |
| 1 | 데이터베이스를 열고 저장 구조 버전을 확인합니다. | 데이터베이스 이름과 버전 | 열린 연결 또는 업그레이드 요청 | 구조 준비 |
| 2 | 업그레이드가 필요하면 파일 본문과 목록 메타데이터 저장소·색인을 만듭니다. | 이전 데이터베이스 구조 | 현재 버전 구조 | 트랜잭션 실행 |
| 3 | 저장·삭제는 본문과 메타데이터를 같은 트랜잭션에서 바꿉니다. | 파일 또는 ID | 일치하는 본문·메타데이터 | 완료 |
| 4 | 목록은 메타데이터 색인만 읽어 필터, 정렬과 커서를 적용합니다. | 목록 조건, 메타데이터 | 목록 페이지와 다음 커서 | 반환 |

## 분기와 예외 흐름

암호화 저장을 선택하면 본문만 암호화하고 목록 메타데이터는 평문입니다. 불러오기는 설정과 관계없이
암호화 봉투를 감지합니다. 연결 차단·강제 종료·트랜잭션 실패는 `io`, 없는 ID는 `not-found`입니다.

## 데이터 조회·변경

목록은 본문 Blob을 읽지 않고 메타데이터 전체를 최근 수정순으로 정렬한 뒤 오프셋 커서를 적용합니다.
조회 중 저장·삭제가 일어나면 다음 페이지 경계가 달라질 수 있습니다.

## 하위 기능과 시퀀스

FNC-015 암호화와 FNC-016 저장소 계약을 구현합니다. 연결이 닫히면 캐시를 비우고 다음 호출에서 다시
엽니다.

## 오류·복구

버전 올리기가 막히면 기다리지 않고 오류를 알립니다. 실패한 연결 Promise는 버려 다음 호출에서 다시
시도할 수 있게 합니다.

## 동시 실행·반복 호출

데이터베이스 열기 요청은 진행 중인 연결 Promise를 공유합니다. 같은 ID의 저장과 삭제는 각각 하나의
트랜잭션으로 끝나며 실패하면 본문과 메타데이터를 함께 이전 상태로 유지합니다. 목록 커서는 조회 시점의
잠금을 보장하지 않으므로 조회 사이 저장·삭제가 있으면 결과 경계가 달라질 수 있습니다.

## 검증 기준

신규·이전 데이터베이스, 평문·암호화 저장, 메타데이터만 목록 조회, 커서·필터·정렬, 연결 차단과
트랜잭션 실패를 시험합니다.
