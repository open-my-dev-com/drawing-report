# FNC-017 IndexedDB 저장

최종 갱신: 2026-09-28

## 개요

브라우저 IndexedDB에 파일 본문과 목록 메타데이터를 나누어 저장하고 최근 수정순으로 조회하는 구현
흐름을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 데이터베이스 열기·이전, 본문 저장과 메타데이터 목록 조회를 정의했습니다. |

## 호출 조건

호스트가 `IndexedDbStorage`를 만들어 디자이너나 애플리케이션의 `StorageAdapter`로 제공할 때
사용합니다.

## 입력·출력

| 구분 | 항목 | 조건 |
| --- | --- | --- |
| 입력 | 데이터베이스 이름·페이지 크기·암호화 여부 | 페이지 크기는 1 이상의 안전한 정수입니다. |
| 출력 | 저장·불러오기·삭제·목록 결과 | 본문은 Blob, 목록 정보는 별도 스토어에 둡니다. |

## 사전·사후 조건

데이터베이스 버전은 3입니다. 버전 1 문자열 본문은 Blob으로 바꾸고, 기존 레코드의 목록 메타데이터를
채웁니다. 저장 시 본문과 메타데이터는 같은 트랜잭션에서 바뀝니다.

## 정상 처리 흐름

```mermaid
flowchart LR
    Open[데이터베이스 열기] --> Upgrade[필요한 이전 수행]
    Upgrade --> Body[본문 스토어]
    Upgrade --> Meta[메타데이터 스토어]
    Meta --> List[필터·정렬·페이지 조회]
```

## 분기와 예외 흐름

암호화 저장을 선택하면 본문만 암호화하고 목록 메타데이터는 평문입니다. 불러오기는 설정과 관계없이
암호화 봉투를 감지합니다. 연결 차단·강제 종료·트랜잭션 실패는 `io`, 없는 ID는 `not-found`입니다.

## 데이터 조회·변경

목록은 본문 Blob을 읽지 않고 메타데이터 전체를 최근 수정순으로 정렬한 뒤 오프셋 커서를 적용합니다.
조회 중 저장·삭제가 일어나면 다음 페이지 경계가 달라질 수 있습니다.

## 하위 기능과 시퀀스

FNC-015 암호화와 FNC-016 저장소 계약을 구현합니다. 연결이 닫히면 캐시를 비우고 다음 호출에서 다시
엽니다.

## 오류·복구

버전 올리기가 막히면 기다리지 않고 오류를 알립니다. 실패한 연결 Promise는 버려 다음 호출에서 다시
시도할 수 있게 합니다.

## 검증 기준

신규·이전 데이터베이스, 평문·암호화 저장, 메타데이터만 목록 조회, 커서·필터·정렬, 연결 차단과
트랜잭션 실패를 시험합니다.
