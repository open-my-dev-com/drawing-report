# FNC-020 선택·이동과 실행 취소

최종 갱신: 2026-09-28

## 개요

디자이너의 요소 선택, 끌기·키보드 이동과 실행 취소·다시 실행 기록을 하나의 편집 단위로 관리하는
흐름을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 다중 선택, 연속 이동, 스냅샷 기록과 보관 상한을 정의했습니다. |

## 호출 조건

캔버스 포인터, 요소 목록, 정렬 도구, 화살표 키와 실행 취소·다시 실행 명령에서 사용합니다.

## 입력·출력

| 구분 | 항목 | 자료형·단위 | 필수 여부·기본값 | 제약과 보장 |
| --- | --- | --- | --- | --- |
| 입력 | 선택 대상 | 페이지의 요소·그리드 셀 식별자 | 선택 동작에 필수 | 현재 문서에 존재해야 합니다. |
| 입력 | 편집 명령 | 이동·정렬·분배·복사·붙여넣기·실행 취소 | 동작마다 선택 | 입력란과 열린 모달에서는 캔버스 단축키를 처리하지 않습니다. |
| 입력 | 기록 예산 | 단계 수와 직렬화 문자 수 | 선택·내부 기본값 | 초과하면 오래된 실행 취소 기록부터 제거합니다. |
| 출력 | 선택·양식·기록 | 새 상태 객체 | 성공 시 | 연속 조작은 변경 이벤트와 기록 각각 한 건으로 확정합니다. |

## 사전·사후 조건

요소 ID를 선택의 기준으로 삼습니다. 기록은 최대 50단계와 JSON 문자열 32 Mi UTF-16 코드 단위
예산을 함께 적용하되 가장 최근 한 단계는 남깁니다.

## 정상 처리 흐름

```mermaid
flowchart LR
    Begin[조작 시작] --> Snapshot[직전 양식 기록]
    Snapshot --> Move[연속 선택·이동]
    Move --> Commit[한 단계 커밋]
    Commit --> Undo[실행 취소]
    Undo --> Redo[다시 실행]
```

| 순서 | 처리 | 읽는 값 | 만드는 값·변경하는 값 | 다음 단계 |
| --- | --- | --- | --- | --- |
| 1 | 문서를 바꾸는 조작이 시작되면 직전 양식과 선택을 한 번 기록합니다. | 현재 양식과 선택 | 실행 취소 스냅샷 | 연속 조작 |
| 2 | 끌기·키 반복처럼 이어지는 입력은 같은 조작 안에서 현재 상태만 갱신합니다. | 연속 입력 | 변경 중 양식과 선택 | 조작 확정 |
| 3 | 조작이 끝나면 결과를 실행 취소 한 단계로 확정하고 다시 실행 기록을 지웁니다. | 변경 중 상태 | 새 현재 상태와 기록 | 다음 명령 |
| 4 | 실행 취소는 현재 상태를 다시 실행 기록에 넣고 직전 스냅샷을 복원합니다. | 실행 취소 기록 | 복원한 양식과 선택 | 다시 실행 가능 |
| 5 | 다시 실행은 현재 상태를 실행 취소 기록에 넣고 취소한 스냅샷을 복원합니다. | 다시 실행 기록 | 복원한 양식과 선택 | 다음 명령 |

## 분기와 예외 흐름

Shift는 다중 선택과 10배 이동에 사용합니다. 화살표 키는 한 번에 0.5 mm, Shift와 함께 누르면
5 mm 이동합니다. Ctrl 또는 Cmd·Alt와 함께 누른 화살표는 브라우저나 다른 단축키에 맡깁니다.
실제 변경이 없는 조작은 기록하지 않습니다.

## 데이터 조회·변경

각 기록에는 양식 JSON과 당시 저장 대상 ID를 보관합니다. 새 편집을 커밋하면 다시 실행 기록을
비우고, 오래된 기록부터 제거합니다.

## 하위 기능과 시퀀스

선택 모델, 캔버스 포인터, 키보드 이동, 정렬·분배와 `HistoryController`가 협력합니다.

## 오류·복구

취소한 끌기는 시작 전 스냅샷을 복원합니다. 문서를 새로 불러오면 이전 문서의 기록을 모두 비웁니다.

## 동시 실행·반복 호출

포인터 끌기와 연속 키 이동은 조작 시작 시점의 스냅샷 하나를 공유하고 조작 종료 때 기록 한 건으로
확정합니다. 실행 취소 또는 다시 실행 중에는 새 기록을 만들지 않습니다. 새 편집을 확정하면 다시 실행
기록을 즉시 비우며, 기록 수와 문자 수 예산을 넘으면 가장 오래된 기록부터 제거합니다.

## 검증 기준

단일·다중 선택, 끌기 취소, 연속 키 이동, 정렬·분배, 저장 ID 복원, 단계·문자열 예산과 단축키 충돌을
시험합니다.
