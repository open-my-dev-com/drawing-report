# FNC-008 반복 그리드 계획

최종 갱신: 2026-09-28

## 개요

반복 그리드의 실제 항목, 빈 항목과 행 구간을 출력 페이지별 조각으로 나누는 흐름을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 자동·고정 페이지, 그룹, 최소·최대 항목과 시작 이동 규칙을 정의했습니다. |

## 호출 조건

FNC-007이 반복 설정이 있는 그리드의 출력 위치를 계산할 때 호출합니다.

## 입력·출력

| 구분 | 항목 | 자료형·단위 | 필수 여부·기본값 | 제약과 보장 |
| --- | --- | --- | --- | --- |
| 입력 | 반복 그리드 | 검증된 그리드 객체 | 필수 | 행 구간과 페이지 방식이 완전해야 합니다. |
| 입력 | 목록 항목 | JSON 객체 배열 | 선택·빈 배열 | 저장 순서를 유지하고 `maxItems`를 먼저 적용합니다. |
| 입력 | 흐름 공간 | 첫 페이지 시작점과 이후 페이지 상·하단, mm | 필수 | 용지 안의 양수 높이여야 합니다. |
| 출력 | 그리드 계획 | `GridPlan` | 성공 시 반환 | 페이지 조각, 행 구간, 항목·그룹 대응과 이월 수를 담습니다. |

## 사전·사후 조건

`item` 행 구간은 하나이며 스키마 검증을 통과해야 합니다. 자동 방식은 `minItems`까지 빈 항목을
채우고, 고정 방식은 `itemsPerPage`의 배수로 채웁니다.

## 정상 처리 흐름

```mermaid
flowchart LR
    Items[실제 항목] --> Limit[최대 항목 적용]
    Limit --> Group[연속 그룹 계산]
    Group --> Fill[최소 또는 페이지 단위 채움]
    Fill --> Fragments[페이지 조각 배치]
```

| 순서 | 처리 | 읽는 값 | 만드는 값·변경하는 값 | 다음 단계 |
| --- | --- | --- | --- | --- |
| 1 | 반복 파라미터의 배열을 읽고 최대 항목 수를 먼저 적용합니다. | 전표 값, 반복 설정 | 사용할 항목 목록 | 그룹 계산 |
| 2 | 연속한 항목의 그룹 키를 비교해 그룹 경계를 만듭니다. | 항목 목록, 그룹 키 | 그룹 목록 | 빈 항목 보충 |
| 3 | 최소 항목 수 또는 고정 페이지 단위에 맞춰 빈 항목을 뒤에 보충합니다. | 그룹 목록, 페이지 방식 | 출력할 실제·빈 항목 | 행 구간 배치 |
| 4 | 행 구간의 출력 시점과 페이지 남은 높이를 따라 페이지 조각을 만듭니다. | 항목, 행 구간, 용지 영역 | 페이지별 그리드 조각 | 반환 |

## 분기와 예외 흐름

실제 항목이 있거나 이어 배치된 그리드가 첫 페이지에 항목 하나도 놓지 못하면 다음 페이지로 한 번
옮깁니다. 데이터 없는 절대 배치 그리드는 `position.y`에서 빈 항목을 시작합니다. 머리·꼬리 구간,
그룹 또는 고정 페이지 묶음이 빈 흐름 영역에도 들어가지 않으면 `SlipLayoutError`입니다.

## 데이터 조회·변경

항목을 자르거나 복사해 계획하지만 원본 배열과 그리드는 바꾸지 않습니다.

## 하위 기능과 시퀀스

행 높이 계산, 연속 `groupBy` 묶음, 구간 블록 생성과 페이지 조각 배치를 순서대로 수행합니다.

## 오류·복구

들어가지 않는 행 구간을 잘라 표시하지 않습니다. 높이, 흐름 영역이나 페이지 방식을 고쳐야 합니다.

## 동시 실행·반복 호출

같은 그리드, 항목 순서와 흐름 공간에는 같은 페이지 조각을 반환합니다. 호출별 중간 배열과 그룹 정보를
새로 만들며 다른 그리드 계획과 공유하지 않습니다. 상위 페이지 계획이 같은 입력으로 다시 계산할 때도
원본 항목 배열은 잘리거나 채워지지 않습니다.

## 검증 기준

항목 0건·1건·다수, `minItems`, `maxItems`, 자동·고정 방식, 그룹 경계, 모든 행 구간과 시작 이동
경계를 시험합니다.
