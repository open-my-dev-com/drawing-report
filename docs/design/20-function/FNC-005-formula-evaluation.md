# FNC-005 수식 평가와 함수

최종 갱신: 2026-09-28

## 개요

파싱한 수식을 값 문맥에서 계산하고 산술·비교·논리·집계·문자열·날짜·형식 함수를 일관되게
적용하는 처리 흐름을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 값 조회, 연산 규칙, 내장 함수와 평가 오류 처리를 정의했습니다. |

## 호출 조건

작성 폼 계산, 디자이너 미리보기, 조건부 서식, 그리드 집계와 PDF 변환에서 같은 평가기를 사용합니다.

## 입력·출력

| 구분 | 항목 | 자료형·단위 | 필수 여부·기본값 | 제약과 보장 |
| --- | --- | --- | --- | --- |
| 입력 | 수식 | 문자열 또는 `FormulaAst` | 필수 | 문자열이면 FNC-004로 먼저 파싱합니다. |
| 입력 | 평가 문맥 | `FormulaContext` | 필수 | 값, 현재 항목, 페이지, 기준 시각과 로케일을 담습니다. |
| 출력 | 계산 결과 | `FormulaValue` | 성공 시 반환 | 유한한 숫자·문자열·논리값·빈 값 또는 이 값의 배열입니다. |

## 사전·사후 조건

객체가 직접 가진 프로퍼티만 읽으며 값 순회 깊이는 256으로 제한합니다. 배열 중간 참조는 남은
경로를 각 항목에 적용합니다. 숫자·문자열을 암묵적으로 서로 바꾸지 않습니다.

## 정상 처리 흐름

```mermaid
flowchart LR
    Ast[구문 트리] --> Resolve[값과 예약 참조 조회]
    Resolve --> Operator[연산자 계산]
    Operator --> Function[내장 함수 실행]
    Function --> Value[결과 값]
```

| 순서 | 처리 | 읽는 값 | 만드는 값·변경하는 값 | 다음 단계 |
| --- | --- | --- | --- | --- |
| 1 | 문자열 입력이면 먼저 구문 트리로 해석합니다. | 수식 문자열 또는 구문 트리 | 검증된 구문 트리 | 참조 해석 |
| 2 | 일반 값, 현재 항목과 예약 참조를 문맥에서 찾습니다. | 구문 트리, 평가 문맥 | 피연산자 값 | 연산자 계산 |
| 3 | 자료형 규칙을 확인하며 단항·이항 연산자를 계산합니다. | 피연산자 값 | 중간 계산값 | 함수 실행 |
| 4 | 내장 함수의 인자 수와 자료형을 검사하고 함수를 실행합니다. | 함수 호출 노드와 인자 | 최종 JSON 값 | 반환 |

## 분기와 예외 흐름

`IF`, `AND`, `OR`는 필요하지 않은 분기를 계산하지 않습니다. 없는 값은 `null`이며, 잘못된 타입,
0으로 나누기, 사용할 수 없는 예약 참조와 숫자 없는 집계는 `FormulaEvalError`입니다. 오류는 수식
자체와 입력 데이터 의존 오류를 구분합니다.

## 데이터 조회·변경

값 문맥을 읽기만 하며 날짜 함수는 전달된 `now`가 없을 때 현재 시각을 사용합니다.

## 하위 기능과 시퀀스

FNC-004 파싱 뒤 참조 해소, 연산자 적용과 내장 함수 호출 순서로 처리합니다. 형식 함수는 문맥의
로케일을 사용합니다.

## 오류·복구

호출 화면은 데이터 의존 오류를 사용자가 값을 고쳐 해결할 수 있게 표시합니다. 수식 자체 오류는
렌더링 성공으로 간주하지 않습니다.

## 동시 실행·반복 호출

전달된 값 문맥은 읽기만 합니다. 기준 시각을 명시하면 같은 구문 트리와 문맥의 결과가 반복 호출에서도
같아야 합니다. 기준 시각을 생략한 날짜 함수만 호출 시점의 현재 시각을 사용하므로 재호출 결과가 달라질
수 있습니다.

## 검증 기준

단락 평가, 배열 참조, 모든 내장 함수, 타입 불일치, 0으로 나누기, 깊이 제한, 기준 시각과 세 로케일을
시험합니다.
