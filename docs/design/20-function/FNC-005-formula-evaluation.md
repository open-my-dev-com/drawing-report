# FNC-005 수식 평가와 함수

최종 갱신: 2026-09-28

## 개요

파싱한 수식을 값 문맥에서 계산하고 산술·비교·논리·집계·문자열·날짜·형식 함수를 일관되게
적용하는 처리 흐름을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 값 조회, 연산 규칙, 내장 함수와 평가 오류 처리를 정의했습니다. |

## 호출 조건

작성 폼 계산, 디자이너 미리보기, 조건부 서식, 그리드 집계와 PDF 변환에서 같은 평가기를 사용합니다.

## 입력·출력

| 구분 | 항목 | 조건 |
| --- | --- | --- |
| 입력 | 문자열 또는 `FormulaAst` | 문자열이면 먼저 FNC-004로 파싱합니다. |
| 입력 | `FormulaContext` | 값, 예약 참조, 기준 시각과 로케일을 담습니다. |
| 출력 | `FormulaValue` | 숫자·문자열·논리값·빈 값 또는 이 값의 배열입니다. |

## 사전·사후 조건

객체가 직접 가진 프로퍼티만 읽으며 값 순회 깊이는 256으로 제한합니다. 배열 중간 참조는 남은
경로를 각 항목에 적용합니다. 숫자·문자열을 암묵적으로 서로 바꾸지 않습니다.

## 정상 처리 흐름

```mermaid
flowchart LR
    Ast[구문 트리] --> Resolve[값과 예약 참조 조회]
    Resolve --> Operator[연산자 계산]
    Operator --> Function[내장 함수 실행]
    Function --> Value[결과 값]
```

## 분기와 예외 흐름

`IF`, `AND`, `OR`는 필요하지 않은 분기를 계산하지 않습니다. 없는 값은 `null`이며, 잘못된 타입,
0으로 나누기, 사용할 수 없는 예약 참조와 숫자 없는 집계는 `FormulaEvalError`입니다. 오류는 수식
자체와 입력 데이터 의존 오류를 구분합니다.

## 데이터 조회·변경

값 문맥을 읽기만 하며 날짜 함수는 전달된 `now`가 없을 때 현재 시각을 사용합니다.

## 하위 기능과 시퀀스

FNC-004 파싱 뒤 참조 해소, 연산자 적용과 내장 함수 호출 순서로 처리합니다. 형식 함수는 문맥의
로케일을 사용합니다.

## 오류·복구

호출 화면은 데이터 의존 오류를 사용자가 값을 고쳐 해결할 수 있게 표시합니다. 수식 자체 오류는
렌더링 성공으로 간주하지 않습니다.

## 검증 기준

단락 평가, 배열 참조, 모든 내장 함수, 타입 불일치, 0으로 나누기, 깊이 제한, 기준 시각과 세 로케일을
시험합니다.
