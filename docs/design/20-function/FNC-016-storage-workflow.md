# FNC-016 저장소 조회와 변경

최종 갱신: 2026-09-28

## 개요

호스트 저장소가 `.slip` 파일을 저장·불러오기·삭제하고 필터와 커서로 목록을 제공하는 공통 흐름을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 저장소 기본 작업, 목록 계약과 선택적 버전 기능을 정의했습니다. |

## 호출 조건

디자이너의 내 양식 기능, 데모 저장, 사용자 저장소 또는 다른 영속 계층을 연결할 때 사용합니다.

## 입력·출력

| 구분 | 항목 | 자료형·단위 | 필수 여부·기본값 | 제약과 보장 |
| --- | --- | --- | --- | --- |
| 입력 | 저장 ID | 문자열 | 저장·조회·삭제에 필수 | 의미와 권한은 구현이 정하며 경로로 직접 신뢰하지 않습니다. |
| 입력 | 파일 | 검증된 `SlipFile` | 저장에 필수 | 전체 파일을 한 작업으로 저장합니다. |
| 입력 | 필터·커서 | 종류·검색어·불투명 문자열 | 목록에 선택 | 커서는 같은 구현과 필터에서 받은 값만 사용합니다. |
| 출력 | 파일·목록·완료 | `SlipFile`, `SlipListPage`, `void` | 메서드별 성공 시 | 목록에는 본문 없이 식별 정보와 다음 커서만 둡니다. |

## 사전·사후 조건

같은 ID 저장은 덮어쓰기입니다. 삭제는 구현 계약에 따라 존재하지 않는 ID에도 성공할 수 있습니다.
버전 이력은 `supportsVersions()`로 확인한 뒤 사용합니다.

## 정상 처리 흐름

```mermaid
flowchart LR
    Caller[호출자] --> Adapter[StorageAdapter]
    Adapter --> Store[호스트 저장소]
    Store --> Result[파일 또는 목록]
```

| 순서 | 처리 | 읽는 값 | 만드는 값·변경하는 값 | 다음 단계 |
| --- | --- | --- | --- | --- |
| 1 | 호출자가 저장, 읽기, 삭제, 목록 또는 버전 작업과 대상 ID를 지정합니다. | 작업 요청 | 어댑터 호출 | 저장소 실행 |
| 2 | 어댑터가 파일 검증과 구현별 저장 규칙을 적용해 작업을 끝냅니다. | 어댑터 호출, 저장소 상태 | 파일·목록·완료 결과 또는 오류 | 결과 전달 |
| 3 | 호출자는 성공 결과만 화면과 현재 상태에 반영합니다. | 어댑터 결과 | 갱신한 화면·업무 상태 | 종료 |

## 분기와 예외 흐름

`not-found`, `unsupported`, `io`, `cancelled` 코드로 복구 방향을 구분합니다. 목록 마지막 페이지에는
`nextCursor`가 없습니다. 조회 중 변경에 대한 일관성 수준은 구현 문서에서 명시합니다.

## 데이터 조회·변경

저장과 삭제만 외부 상태를 바꿉니다. 목록은 본문 전체를 불러오지 않는 구현을 권장합니다. 암호화
정책은 어댑터가 FNC-015를 조합해 적용합니다.

## 하위 기능과 시퀀스

기본 인터페이스는 IF-003이며 브라우저 구현은 FNC-017, 파일 대화상자는 FNC-018이 담당합니다.

## 오류·복구

오류 코드를 문자열 메시지로 다시 판별하지 않습니다. 취소는 실패와 구분하고, I/O 실패 뒤에는
호출자가 재시도 여부를 정합니다.

## 동시 실행·반복 호출

같은 ID에 대한 저장·삭제 순서와 목록 조회 일관성은 구현체가 명시합니다. `save`는 같은 ID의 기존
파일을 덮어쓰지만, 인터페이스 자체는 동시에 시작한 여러 변경의 완료 순서를 정하지 않습니다. 읽기와
목록을 반복해도 저장된 본문이나 전달받은 목록 커서를 변경하지 않습니다.

## 검증 기준

덮어쓰기, 없음, 삭제, 종류·검색 필터, 여러 페이지, 잘못된 커서와 선택적 버전 지원 판별을 시험합니다.
