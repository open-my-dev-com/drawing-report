# DAT-008 수식과 조건부 서식

최종 갱신: 2026-09-28

## 개요

필드·바코드·그리드 셀의 계산식과 값에 따라 표현을 바꾸는 조건부 서식의 저장 구조와 참조 범위를
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 수식 문자열, 평가 문맥, 조건부 서식의 적용 순서와 오류 계약을 정의했습니다. |

## 소유 계층

디자이너가 수식 문자열과 조건부 서식 규칙을 저장하고 Core 파서와 평가기가 실행합니다. 파일에는
실행 코드나 구문 트리를 보관하지 않으며 호스트 객체에 접근할 수 없습니다.

## 구조와 주요 항목

| 경로 | 자료형 | 필수 여부 | 기본값 | 허용 범위·형식 | 의미 |
| --- | --- | --- | --- | --- | --- |
| 수식 값 | 문자열 | 사용하는 요소에 필수 | 없음 | 0~20,000자, SlipKit 수식 문법 | 값 또는 조건을 계산할 원문 |
| `conditionalFormats` | 배열 | 선택 | 규칙 없음 | 0~20개, 선언 순서 유지 | 참인 조건의 표현 변경을 합성하는 목록 |
| `condition` | 문자열 | 규칙에 필수 | 없음 | 빈 문자열이 아닌 논리 결과 수식 | 규칙을 적용할 조건 |
| `fontColor` | 문자열 | 선택 | 기본 글자색 유지 | 6자리 또는 8자리 16진 색상 | 글자색 덮어쓰기 |
| `backgroundColor` | 문자열 | 선택 | 기본 배경 유지 | 6자리 또는 8자리 16진 색상 | 배경색 덮어쓰기 |
| `borderColor` | 문자열 | 선택 | 기본 테두리 유지 | 6자리 또는 8자리 16진 색상 | 테두리색 덮어쓰기 |
| 글자 강조 | 논리값 | 선택 | 기본 강조 유지 | 굵게·기울임·밑줄·취소선 각각 `true` 또는 `false` | 기존 강조를 켜거나 끄기 |

## 데이터 관계

| 기준 데이터 | 대상 데이터 | 관계·개수 | 연결 키 | 삭제·변경 시 처리 |
| --- | --- | --- | --- | --- |
| 수식 | 파라미터 값 | N:M | 구조화된 참조 경로 | 키 변경 시 파싱한 해당 참조만 바꿉니다. |
| 수식 | 현재 목록 항목 | N:0..1 | 항목 하위 필드 참조 | 항목 구간 밖에서는 사용할 수 없습니다. |
| 수식 | 페이지 계획 | N:0..1 | 예약된 페이지 참조 | 출력 페이지별 평가 문맥에서 값을 제공합니다. |
| 요소·셀 | 조건부 서식 | 1:N | 배열 순서 | 같은 속성은 뒤의 참 규칙이 덮어씁니다. |

## 수식 데이터

수식은 문자열로 저장하며 파일 안에 AST나 실행 코드를 보관하지 않습니다. 파라미터, 현재 반복 항목,
페이지 정보와 허용된 내장 함수만 참조할 수 있습니다. 필드와 바코드는 파라미터와 수식 중 하나만
값 소스로 사용합니다.

| 참조 | 범위 |
| --- | --- |
| 파라미터 키 | 전표 전체 값에서 조회합니다. |
| 현재 항목 필드 | 반복 그리드의 항목 구간에서만 조회합니다. |
| 페이지 참조 | 출력 페이지 번호와 전체 페이지 수를 사용합니다. |
| 기준 시각·로케일 | 평가 문맥에서 명시적으로 제공합니다. |

날짜 계산은 시간대와 무관한 달력 날짜 규칙을 사용합니다. 값 종류는 문자열, 숫자, 논리값, 날짜와
빈 값으로 제한하며 함수마다 인자 수와 타입을 엄격하게 검사합니다.

## 조건부 서식

각 규칙은 논리값을 반환할 조건식과 한 개 이상의 표현 변경을 가집니다. 조건이 참인 규칙을 배열
순서대로 합성합니다. 글자색, 배경색, 테두리색, 굵게, 기울임, 밑줄과 취소선을 바꿀 수 있습니다.

조건식의 `FormulaEvalError`는 해당 규칙을 적용하지 않는 결과로 처리합니다. 이는 렌더링 중단이
아니며 진단 정보의 `dataDependent` 여부도 적용 결과를 바꾸지 않습니다. 문법 오류와 지원하지 않는
구조는 편집·검증 단계에서 별도로 알려야 합니다.

## 참조 변경

파라미터 키나 목록 하위 필드 키를 바꾸면 수식 토큰을 파싱하여 해당 참조만 갱신합니다. 단순 문자열
치환을 사용하지 않으며 문자열 리터럴과 이름이 일부만 같은 다른 키는 바꾸지 않습니다.

## 불변 조건

- 공백만 있는 수식은 빈 값으로 취급하거나 사용자에게 동일한 계약으로 안내해야 합니다.
- 임의 JavaScript와 호스트 객체에는 접근할 수 없습니다.
- 조건부 서식 규칙에는 실제로 바꿀 속성이 하나 이상 있어야 합니다.
- 저장된 수식은 렌더링 환경에 따라 의미가 바뀌지 않아야 합니다.

## 생명주기

수식 원문은 요소나 셀과 함께 생성·수정·삭제합니다. 파라미터 키 변경은 관련 수식 전체를 먼저 파싱한
뒤 한 문서 변경으로 적용합니다. 조건부 서식은 대상 요소나 셀을 삭제할 때 함께 삭제합니다.

## 버전·검증·정규화·마이그레이션

저장 단계에서는 문법, 함수 인자 수와 참조 형식을 검사합니다. 조건부 서식은 조건과 변경 속성이 하나
이상 있어야 합니다. 공백 수식은 화면, 경고 수집과 PDF에서 모두 빈 값으로 해석합니다.
