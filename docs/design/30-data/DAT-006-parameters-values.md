# DAT-006 파라미터와 샘플 값

최종 갱신: 2026-09-28

## 개요

양식이 요구하는 입력값의 정의와 전표·미리보기에서 사용하는 실제 값 구조를 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 파라미터 종류, 목록 하위 필드, 값과 샘플 값의 관계를 정의했습니다. |

## 파라미터 정의

각 파라미터는 고유한 `key`, 표시 이름, 값 종류와 선택적 설명을 가집니다. 지원 값 종류는 문자열,
숫자, 논리값, 날짜, 이미지와 목록입니다. 목록 파라미터는 행 객체의 하위 필드 정의를 가지며 하위
필드는 목록 안에서 고유한 키와 값 종류를 사용합니다.

파라미터 키는 수식, 필드, 이미지, 바코드와 반복 그리드에서 공통으로 참조합니다. 프로토타입에 있는
이름과 같은 문자열도 일반 키로 보관하며 객체를 만들 때 안전한 자체 프로퍼티로 처리합니다.

## 값 구조

```json
{
  "customerName": "예시 상사",
  "issuedDate": "2026-09-28",
  "items": [
    { "name": "품목 A", "quantity": 2, "price": 1500 }
  ]
}
```

최상위 `values`와 `sampleValues`는 파라미터 키를 프로퍼티로 쓰는 평평한 객체입니다. 목록의 각 행만
하위 필드 객체를 사용합니다. 날짜는 달력 날짜 문자열이며 시각이나 시간대를 포함하지 않습니다.
이미지 값은 비어 있거나 지원하는 이미지 data URI여야 합니다.

## 샘플 값

`sampleValues`는 디자이너가 수식, 반복 그리드와 미리보기를 확인하기 위한 자료입니다. 양식 파일을
Core로 직접 렌더링할 때는 자동 적용되지 않습니다. 샘플 값은 실제 고객이나 거래 자료가 아닌 공개
가능한 예제로 작성합니다.

## 검증과 정규화

- 파라미터 키와 목록 하위 필드 키는 허용 형식과 길이를 따라야 합니다.
- 같은 범위의 키는 중복될 수 없습니다.
- 수식과 요소 참조가 존재하지 않는 키를 사용하면 작성 또는 렌더링 단계에서 진단합니다.
- 값 객체는 JSON으로 직렬화할 수 있어야 하며 `NaN`, 무한대와 실행 객체를 포함하지 않습니다.
- 날짜 형식과 목록 행 구조는 사용 시점의 검증 계약을 따릅니다.

## 생명주기

양식 설계자가 정의를 바꾸면 새로 작성하는 전표에 적용됩니다. 기존 전표는 스냅샷에 포함된 파라미터
정의를 유지합니다. 키 이름 변경은 기존 수식과 값을 자동 이전하지 않으므로 참조 변경 기능과 함께
처리해야 합니다.
