# DAT-006 파라미터와 샘플 값

최종 갱신: 2026-09-28

## 개요

양식이 요구하는 입력값의 정의와 전표·미리보기에서 사용하는 실제 값 구조를 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 파라미터 종류, 목록 하위 필드, 값과 샘플 값의 관계를 정의했습니다. |

## 소유 계층

양식 설계자가 파라미터 정의와 샘플 값을 관리하고 작성 폼이 전표 값을 만듭니다. Core는 키, 값 종류,
목록 하위 필드와 JSON 값 범위를 검증하며 화면 밖 업무 데이터는 추정하거나 채우지 않습니다.

## 구조와 주요 항목

| 경로 | 자료형 | 필수 여부 | 기본값 | 허용 범위·형식 | 의미 |
| --- | --- | --- | --- | --- | --- |
| `parameters[].key` | 문자열 | 필수 | 없음 | 1~20,000자, 파라미터 목록에서 고유 | 요소·수식·값 객체가 공유하는 참조 키 |
| `parameters[].label` | 문자열 | 선택 | 키 표시 | 1~20,000자 | 화면에 표시할 이름 |
| `parameters[].valueType` | 문자열 | 선택 | `text` | `text`, `number`, `date`, `boolean`, `image`, `list` | 입력과 계산에서 사용할 값 종류 |
| `parameters[].fields` | 배열 | 목록에 선택 | 하위 필드 없음 | 키가 목록 안에서 고유 | 목록 행 객체의 한 단계 하위 필드 |
| `fields[].key` | 문자열 | 필수 | 없음 | 1~20,000자 | 목록 행 객체의 프로퍼티 이름 |
| `fields[].label` | 문자열 | 선택 | 키 표시 | 1~20,000자 | 하위 필드 표시 이름 |
| `fields[].valueType` | 문자열 | 선택 | `text` | `text`, `number`, `date`, `boolean`, `image` | 하위 필드 값 종류이며 중첩 목록은 허용하지 않음 |
| 값 객체의 각 값 | JSON 값 | 선택 | 값 없음 | 문자열·유한한 숫자·논리값·`null`·배열·객체 | 전표 또는 미리보기에서 사용할 실제 값 |

## 데이터 관계

| 기준 데이터 | 대상 데이터 | 관계·개수 | 연결 키 | 삭제·변경 시 처리 |
| --- | --- | --- | --- | --- |
| 파라미터 정의 | 요소·수식 | 1:N | 파라미터 키 | 키 변경 시 모든 구조화된 참조를 함께 바꿉니다. |
| 파라미터 정의 | 전표·샘플 값 | 1:0..1 | 파라미터 키 | 정의 삭제 시 샘플 값은 지우되 기존 전표 값은 보존합니다. |
| 목록 파라미터 | 하위 필드 | 1:N | 하위 필드 키 | 하위 필드 삭제 시 양식 샘플 행과 연결된 셀을 함께 정리합니다. |
| 목록 파라미터 | 반복 그리드 | 1:N | 반복 설정의 키 | 정의를 지워도 참조 자체는 남겨 유추 항목으로 표시할 수 있습니다. |

## 파라미터 정의

각 파라미터는 고유한 `key`, 표시 이름, 값 종류와 선택적 설명을 가집니다. 지원 값 종류는 문자열,
숫자, 논리값, 날짜, 이미지와 목록입니다. 목록 파라미터는 행 객체의 하위 필드 정의를 가지며 하위
필드는 목록 안에서 고유한 키와 값 종류를 사용합니다.

파라미터 키는 수식, 필드, 이미지, 바코드와 반복 그리드에서 공통으로 참조합니다. 프로토타입에 있는
이름과 같은 문자열도 일반 키로 보관하며 객체를 만들 때 안전한 자체 프로퍼티로 처리합니다.

## 값 구조

```json
{
  "customerName": "예시 상사",
  "issuedDate": "2026-09-28",
  "items": [
    { "name": "품목 A", "quantity": 2, "price": 1500 }
  ]
}
```

최상위 `values`와 `sampleValues`는 파라미터 키를 프로퍼티로 쓰는 평평한 객체입니다. 목록의 각 행만
하위 필드 객체를 사용합니다. 날짜는 달력 날짜 문자열이며 시각이나 시간대를 포함하지 않습니다.
이미지 값은 비어 있거나 지원하는 이미지 data URI여야 합니다.

## 샘플 값

`sampleValues`는 디자이너가 수식, 반복 그리드와 미리보기를 확인하기 위한 자료입니다. 양식 파일을
Core로 직접 렌더링할 때는 자동 적용되지 않습니다. 샘플 값은 실제 고객이나 거래 자료가 아닌 공개
가능한 예제로 작성합니다.

## 불변 조건

- 파라미터 키와 목록 하위 필드 키는 허용 형식과 길이를 따라야 합니다.
- 같은 범위의 키는 중복될 수 없습니다.
- 수식과 요소 참조가 존재하지 않는 키를 사용하면 작성 또는 렌더링 단계에서 진단합니다.
- 값 객체는 JSON으로 직렬화할 수 있어야 하며 `NaN`, 무한대와 실행 객체를 포함하지 않습니다.
- 날짜 형식과 목록 행 구조는 사용 시점의 검증 계약을 따릅니다.

## 생명주기

양식 설계자가 정의를 바꾸면 새로 작성하는 전표에 적용됩니다. 기존 전표는 스냅샷에 포함된 파라미터
정의를 유지합니다. 키 이름 변경은 기존 수식과 값을 자동 이전하지 않으므로 참조 변경 기능과 함께
처리해야 합니다.

## 버전·검증·정규화·마이그레이션

정의 목록의 키 고유성과 `list`에서만 하위 필드를 가질 수 있다는 조건을 먼저 확인합니다. 값 객체는
프로토타입 이름을 포함한 키도 자체 프로퍼티로 보존합니다. 숫자 파라미터의 `undefined`, `null`, 빈
문자열은 계산 직전에 0으로 정규화하며 다른 값 종류와 목록 하위 필드는 바꾸지 않습니다.
