# DAT-004 요소 공통 속성과 스타일

최종 갱신: 2026-09-28

## 개요

텍스트, 필드, 이미지, 바코드, 도형과 그리드 요소가 공유하는 식별, 위치, 배치와 표현 속성을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 요소 공통 속성, 페이지 배치, 글자와 테두리 스타일을 정의했습니다. |

## 소유 계층

디자이너가 공통 속성을 편집하고 Core가 파일 검증, 페이지 계획과 PDF 변환에서 해석합니다. 렌더링 중
적용한 기본값과 대체 폰트는 원본 요소에 다시 기록하지 않습니다.

## 구조와 주요 항목

| 경로 | 자료형 | 필수 여부 | 기본값 | 허용 범위·형식 | 의미 |
| --- | --- | --- | --- | --- | --- |
| `id` | 문자열 | 필수 | 없음 | 1~20,000자, 양식 전체에서 고유 | 요소 참조와 편집 선택 기준 |
| `name` | 문자열 | 필수 | 없음 | 0~20,000자 | 화면과 오류에 표시할 이름 |
| `position.x`, `position.y` | 숫자 | 필수 | 없음 | 0~5,000mm의 유한한 수 | 원본 페이지 왼쪽 위 기준 좌표 |
| `width`, `height` | 숫자 | 그리드 외 요소에 필수 | 없음 | 0~5,000mm | 요소 상자 크기 |
| `group` | 문자열 | 선택 | 그룹 없음 | 1~20,000자 | 함께 선택할 요소 묶음 이름 |
| `pagePlacement` | 객체 | 선택 | 모든 출력 페이지의 원본 위치 | `absolute` 또는 `after` | 출력 페이지별 표시와 이어 배치 |
| `fontName` | 문자열 | 선택 | 대체 폰트 | 등록된 폰트 이름 | 글자를 측정하고 그릴 폰트 |
| `fontSize` | 숫자 | 선택 | 요소별 기본값 | 0 초과 500pt 이하 | 글자 크기 |
| `alignment` | 문자열 | 선택 | `left` | `left`, `center`, `right` | 가로 정렬 |
| `verticalAlignment` | 문자열 | 선택 | `top` | `top`, `middle`, `bottom` | 세로 정렬 |
| `lineHeight` | 숫자 | 선택 | `1` | 0 초과 10 이하 | 글줄 높이 배수 |
| `characterSpacing` | 숫자 | 선택 | `0` | -100~100pt | 글자 사이 간격 |
| 색상 값 | 문자열 | 선택 | 용도별 기본값 | `#RRGGBB` 또는 `#RRGGBBAA` | 글자·배경·테두리 색 |

`pagePlacement.mode`가 `absolute`이면 원본 위치를 유지하고 출력 페이지 필터를 적용합니다. `after`이면
같은 원본 페이지에 있는 대상 요소의 마지막 출력 조각 뒤에 간격을 두고 배치합니다. 대상이 없거나
배치 관계가 순환하면 검증에 실패합니다.

## 데이터 관계

| 기준 데이터 | 대상 데이터 | 관계·개수 | 연결 키 | 삭제·변경 시 처리 |
| --- | --- | --- | --- | --- |
| 원본 페이지 | 요소 | 1:N | 페이지의 요소 배열 | 페이지 삭제 시 요소도 함께 삭제합니다. |
| `after` 요소 | 기준 요소 | N:1 | `pagePlacement.target` | 같은 페이지의 대상이 없으면 검증에 실패합니다. |
| 요소 | 조건부 서식 | 1:N | 배열 순서 | 요소 삭제 시 규칙도 함께 삭제합니다. |
| 요소 | 폰트 제공 목록 | N:M | `fontName` | 이름이 없으면 대체 폰트를 쓰고 원본 이름은 보존합니다. |

## 글자 스타일

글자를 표시하는 요소는 폰트 이름·크기, 가로·세로 정렬, 굵게·기울임·밑줄·취소선, 줄간격, 자간과
세로쓰기를 선택적으로 지정합니다. 값을 생략하면 명세의 렌더링 기본값을 사용합니다. 요청한 변형
폰트가 없을 때는 해당 강조를 적용하지 않을 수 있습니다.

## 색상과 테두리

색상은 6자리 `#RRGGBB` 또는 투명도를 포함한 8자리 `#RRGGBBAA` 형식을 사용합니다. 배경색, 글자색,
테두리색·두께·종류를 요소 종류에 맞게 지정합니다. 그리드 셀은 상속과 공유 경계 규칙을 따르며 일반
요소와 별도의 기본 테두리를 사용합니다.

## 조건부 표현

텍스트·필드·그리드 셀은 조건식 결과에 따라 글자색, 배경색, 테두리색과 글자 강조를 덮어쓸 수
있습니다. 조건이 참인 규칙을 선언 순서대로 합성하며 같은 속성은 뒤 규칙이 우선합니다.

## 불변 조건

- 좌표와 크기는 유한한 비음수이며 명세의 상한을 넘지 않습니다.
- 요소 ID는 중복되지 않고 `after` 대상은 같은 페이지에 존재합니다.
- 페이지 배치 결과가 용지와 흐름 영역 계약을 위반하면 렌더링 오류가 됩니다.
- 렌더링을 위해 적용한 대체 폰트나 기본 스타일을 원본 파일에 다시 기록하지 않습니다.

## 생명주기

요소를 추가할 때 고유 ID와 종류별 기본 크기를 만들고, 속성 편집은 같은 요소를 새 객체로 교체합니다.
복사·붙여넣기는 새 ID를 부여합니다. 요소를 삭제하면 해당 요소의 조건부 서식도 함께 없어지지만 다른
요소가 가진 파라미터와 에셋 정의는 자동 삭제하지 않습니다.

## 버전·검증·정규화·마이그레이션

공통 범위 검사 뒤 요소 종류별 허용 필드와 교차 참조를 검사합니다. 생략한 스타일은 렌더링 시 기본값을
적용하며 직렬화 결과에 자동으로 추가하지 않습니다.
