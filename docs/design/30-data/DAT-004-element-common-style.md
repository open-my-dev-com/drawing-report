# DAT-004 요소 공통 속성과 스타일

최종 갱신: 2026-09-28

## 개요

텍스트, 필드, 이미지, 바코드, 도형과 그리드 요소가 공유하는 식별, 위치, 배치와 표현 속성을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 요소 공통 속성, 페이지 배치, 글자와 테두리 스타일을 정의했습니다. |

## 공통 구조

| 항목 | 설명 |
| --- | --- |
| `id` | 양식 전체에서 고유한 요소 식별자입니다. |
| `name` | 디자이너와 오류 메시지에 표시할 이름입니다. |
| `position` | 원본 페이지 왼쪽 위를 기준으로 한 `x`, `y` mm 좌표입니다. |
| `width`, `height` | 요소 상자의 mm 크기입니다. 그리드는 행·열 합계로 계산합니다. |
| `group` | 여러 요소를 함께 선택하기 위한 선택적 그룹 식별자입니다. |
| `pagePlacement` | 출력 페이지별 표시 또는 다른 요소 뒤 배치를 정의합니다. |

`pagePlacement.mode`가 `absolute`이면 원본 위치를 유지하고 출력 페이지 필터를 적용합니다. `after`이면
같은 원본 페이지에 있는 대상 요소의 마지막 출력 조각 뒤에 간격을 두고 배치합니다. 대상이 없거나
배치 관계가 순환하면 검증에 실패합니다.

## 글자 스타일

글자를 표시하는 요소는 폰트 이름·크기, 가로·세로 정렬, 굵게·기울임·밑줄·취소선, 줄간격, 자간과
세로쓰기를 선택적으로 지정합니다. 값을 생략하면 명세의 렌더링 기본값을 사용합니다. 요청한 변형
폰트가 없을 때는 해당 강조를 적용하지 않을 수 있습니다.

## 색상과 테두리

색상은 정규화된 6자리 `#RRGGBB`를 사용합니다. 배경색, 글자색, 테두리색·두께·종류를 요소 종류에
맞게 지정합니다. 그리드 셀은 상속과 공유 경계 규칙을 따르며 일반 요소와 별도의 기본 테두리를
사용합니다.

## 조건부 표현

텍스트·필드·그리드 셀은 조건식 결과에 따라 글자색, 배경색, 테두리색과 글자 강조를 덮어쓸 수
있습니다. 조건이 참인 규칙을 선언 순서대로 합성하며 같은 속성은 뒤 규칙이 우선합니다.

## 불변 조건

- 좌표와 크기는 유한한 비음수이며 명세의 상한을 넘지 않습니다.
- 요소 ID는 중복되지 않고 `after` 대상은 같은 페이지에 존재합니다.
- 페이지 배치 결과가 용지와 흐름 영역 계약을 위반하면 렌더링 오류가 됩니다.
- 렌더링을 위해 적용한 대체 폰트나 기본 스타일을 원본 파일에 다시 기록하지 않습니다.
