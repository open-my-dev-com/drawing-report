# DAT-005 요소별 데이터

최종 갱신: 2026-09-28

## 개요

양식 페이지에 배치할 수 있는 요소 종류와 각 요소가 보관하는 고유 데이터를 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 텍스트, 필드, 이미지, 바코드, 도형과 그리드 요소의 역할을 정리했습니다. |

## 소유 계층

디자이너가 요소 종류를 선택하고 종류별 값을 편집합니다. Core 스키마는 `type`에 맞지 않는 필드를
거부하고 PDF 변환기는 종류별 출력으로 바꿉니다.

## 구조와 주요 항목

| 경로 | 자료형 | 필수 여부 | 기본값 | 허용 범위·형식 | 의미 |
| --- | --- | --- | --- | --- | --- |
| `type` | 문자열 | 필수 | 없음 | `text`, `field`, `image`, `barcode`, `line`, `rect`, `ellipse`, `polygon`, `grid` 중 하나 | 요소 구조와 출력 방식을 구분합니다. |
| `text.content` | 문자열 | 필수 | 없음 | 0~20,000자 | 모든 전표에 같은 문구를 표시합니다. |
| `field.parameter` | 문자열 | 조건부 필수 | 없음 | 1~20,000자, `formula`와 함께 사용할 수 없음 | 전표 값에서 읽을 키입니다. |
| `field.formula` | 문자열 | 조건부 필수 | 없음 | 0~20,000자, `parameter`와 함께 사용할 수 없음 | 표시 값을 계산하는 수식입니다. |
| `image.src` | 문자열 | 조건부 필수 | 없음 | `http:`, `https:`, PNG·JPEG data URI 또는 `asset://`; `parameter`와 함께 사용할 수 없음 | 모든 전표에 사용할 고정 이미지입니다. |
| `image.parameter` | 문자열 | 조건부 필수 | 없음 | 1~20,000자, `src`와 함께 사용할 수 없음 | 전표별 이미지 data URI를 읽을 키입니다. |
| `barcode.kind` | 문자열 | 필수 | 없음 | `qrcode`, `code128`, `code39`, `ean13`, `ean8`, `upca`, `upce`, `itf14`, `nw7`, `japanpost`, `gs1datamatrix`, `pdf417` 중 하나 | 출력할 바코드 규격입니다. |
| `barcode.content` | 문자열 | 조건부 필수 | 없음 | 0~20,000자, 세 값 소스 가운데 하나만 사용 | 모든 전표에 사용할 바코드 값입니다. |
| `barcode.parameter` | 문자열 | 조건부 필수 | 없음 | 1~20,000자, 세 값 소스 가운데 하나만 사용 | 전표에서 바코드 값을 읽을 키입니다. |
| `barcode.formula` | 문자열 | 조건부 필수 | 없음 | 0~20,000자, 세 값 소스 가운데 하나만 사용 | 바코드 값을 계산하는 수식입니다. |
| `line.lineDirection` | 문자열 | 선택 | `horizontal` | `horizontal`, `vertical`, `down`, `up` 중 하나 | 요소 영역 안에서 선을 잇는 방향입니다. |
| `rect.radius` | 숫자(mm) | 선택 | `0`으로 처리 | 0~5,000, 파선·점선 테두리와 함께 사용할 수 없음 | 사각형 모서리의 반경입니다. |
| `polygon.sides` | 정수 | 필수 | 없음 | 3~12 | 정다각형의 꼭짓점 수입니다. |
| `grid.columns` | 배열 | 필수 | 없음 | 1~100개, 각 너비는 0 초과 5,000mm 이하 | 그리드 열과 각 열의 너비입니다. |
| `grid.rows` | 배열 | 필수 | 없음 | 1~1,000개, 각 높이는 0 초과 5,000mm 이하 | 그리드 행과 각 행의 높이입니다. |
| `grid.cells` | 배열 | 필수 | 없음 | 0~100,000개 | 셀 좌표, 병합 범위, 값과 서식을 저장합니다. |
| `grid.repeat` | 객체 | 선택 | 정적 그리드 | DAT-007의 반복·페이지 분할 구조 | 항목 배열을 행 구간별로 반복 출력합니다. |

각 행의 공통 위치·크기·스타일 형식은 DAT-004, 그리드 내부 구조는 DAT-007에서 정의합니다.

## 데이터 관계

| 기준 데이터 | 대상 데이터 | 관계·개수 | 연결 키 | 삭제·변경 시 처리 |
| --- | --- | --- | --- | --- |
| 필드·바코드 | 파라미터 | N:0..1 | `parameter` | 정의가 없어도 값 키로 사용할 수 있으며 화면에서 유추 항목으로 표시합니다. |
| 이미지 | 에셋 | N:0..1 | `asset://` 뒤 ID | 대상이 없으면 검증 또는 렌더링에 실패합니다. |
| 그리드 | 목록 파라미터 | 1:0..1 | 반복 설정의 파라미터 키 | 반복 설정 삭제 시 정적 그리드로 남습니다. |
| 그리드 | 셀 | 1:N | 행·열 좌표 | 행·열 삭제 시 범위와 병합을 함께 조정합니다. |

## 값 소스

필드는 `parameter`와 `formula` 중 하나만 사용합니다. 바코드는 고정 `content`, `parameter`,
`formula` 가운데 하나만 사용합니다. 이미지도 고정 `src`와 변동 `parameter`를 동시에 사용할 수
없습니다. 값이 없을 때 표시할 동작은 요소 종류와 형식 규칙에 따릅니다.

고정 이미지는 `https:`·`http:`, 이미지 data URI 또는 `asset://`를 구조상 사용할 수 있습니다.
Core PDF 렌더링은 외부 URL을 가져오지 않으므로 실제 출력에는 내장 이미지가 필요합니다.

## 도형과 크기

선은 공통 위치·너비·높이와 가로·세로·하향 대각선·상향 대각선 방향을 저장합니다. 사각형, 타원과
정다각형은 공통 위치·크기와 도형별 속성을 사용합니다. 정다각형의 첫 꼭짓점은 요소 영역의 위쪽에
놓입니다.

## 그리드 특성

그리드는 `width`와 `height`를 직접 저장하지 않고 열 너비와 행 높이 합계로 계산합니다. 셀은 행·열
범위, 병합 크기, 내용과 스타일을 가지며 행 구간과 반복 설정은 DAT-007에서 정의합니다.

## 불변 조건

- 요소의 `type`과 허용 프로퍼티 조합이 일치해야 합니다.
- 값 소스는 배타적이며 참조한 파라미터의 값 종류가 요소 용도와 맞아야 합니다.
- 셀 범위와 병합은 그리드 범위를 벗어나거나 서로 겹칠 수 없습니다.
- 발행 전표의 이미지는 외부 URL에 의존하지 않습니다.

## 생명주기

요소를 추가할 때 종류별 기본 구조를 만들고, 종류는 생성 뒤 다른 종류로 직접 바꾸지 않습니다. 다른
종류가 필요하면 새 요소를 만들고 기존 요소를 삭제합니다. 요소 삭제는 페이지 배열에서 해당 객체를
제거하며 전표 값과 양식의 파라미터 정의는 보존합니다.

## 버전·검증·정규화·마이그레이션

판별값으로 한 종류의 엄격한 구조만 선택합니다. 다른 종류의 전용 필드, 여러 값 소스와 정의하지 않은
필드는 거부합니다. 렌더러는 값이 없다는 이유로 요소 종류나 저장 구조를 바꾸지 않습니다.
