# DAT-005 요소별 데이터

최종 갱신: 2026-09-28

## 개요

양식 페이지에 배치할 수 있는 요소 종류와 각 요소가 보관하는 고유 데이터를 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 텍스트, 필드, 이미지, 바코드, 도형과 그리드 요소의 역할을 정리했습니다. |

## 요소 종류

| 종류 | 주요 데이터 | 출력 의미 |
| --- | --- | --- |
| 텍스트 | 고정 문자열과 글자 스타일 | 모든 전표에 같은 문구를 표시합니다. |
| 필드 | 파라미터 키 또는 수식, 표시 형식 | 전표 값이나 계산 결과를 표시합니다. |
| 이미지 | 고정 `src` 또는 이미지 파라미터 | PNG·JPEG 이미지를 표시합니다. |
| 바코드 | 파라미터 키 또는 수식, 바코드 종류 | 값을 1차원·2차원 코드로 표시합니다. |
| 선 | 두 점, 색과 두께 | 구분선과 표시선을 그립니다. |
| 사각형·타원·정다각형 | 테두리, 채움과 도형별 속성 | 배경과 시각적 구획을 그립니다. |
| 그리드 | 행·열·셀·행 구간·반복 설정 | 고정 표와 반복 목록을 같은 구조로 표시합니다. |

## 값 소스

필드와 바코드는 `parameter`와 `formula` 중 하나만 사용합니다. 이미지도 고정 `src`와 변동
`parameter`를 동시에 사용할 수 없습니다. 값이 없을 때 표시할 동작은 요소 종류와 형식 규칙에
따릅니다.

고정 이미지는 `https:`·`http:`, 이미지 data URI 또는 `asset://`를 구조상 사용할 수 있습니다.
Core PDF 렌더링은 외부 URL을 가져오지 않으므로 실제 출력에는 내장 이미지가 필요합니다.

## 도형과 크기

선은 저장 형식에서 끝점 좌표를 사용하며 디자이너는 길이와 각도로 편집할 수 있습니다. 사각형,
타원과 정다각형은 공통 위치·크기와 도형별 속성을 사용합니다. 정다각형의 꼭짓점 수와 회전값은
스키마 범위 안이어야 합니다.

## 그리드 특성

그리드는 `width`와 `height`를 직접 저장하지 않고 열 너비와 행 높이 합계로 계산합니다. 셀은 행·열
범위, 병합 크기, 내용과 스타일을 가지며 행 구간과 반복 설정은 DAT-007에서 정의합니다.

## 불변 조건

- 요소의 `type`과 허용 프로퍼티 조합이 일치해야 합니다.
- 값 소스는 배타적이며 참조한 파라미터의 값 종류가 요소 용도와 맞아야 합니다.
- 셀 범위와 병합은 그리드 범위를 벗어나거나 서로 겹칠 수 없습니다.
- 발행 전표의 이미지는 외부 URL에 의존하지 않습니다.
