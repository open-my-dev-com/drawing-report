# IF-005 `<slip-designer>`

최종 갱신: 2026-09-28

## 개요

양식 파일을 시각적으로 편집하는 Web Component의 입력, 확장 설정, 출력 이벤트와 저장소 연결 계약을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 디자이너의 공개 프로퍼티, 이벤트와 호스트 확장 지점을 정의했습니다. |

## 입력 프로퍼티

| 프로퍼티 | 필수 | 설명 |
| --- | --- | --- |
| `src` | 필수 | `kind: template`인 `.slip` JSON입니다. |
| `locale` | 선택 | UI 언어입니다. |
| `slipkit` | 선택 | PDF·수식·폰트·암호화 설정입니다. |
| `settings` | 선택 | 용지 목록·저장과 바코드 종류를 비동기로 제공합니다. |
| `presets` | 선택 | 툴바의 양식 프리셋을 동봉 목록 대신 사용합니다. |
| `storage` | 선택 | “내 양식” 저장·목록·불러오기·삭제에 사용합니다. |
| `maxImageBytes` | 선택 | 업로드할 이미지 원본 바이트 상한이며 기본값은 2MiB입니다. |

`settings.getPaperSizes`와 `settings.getBarcodeKinds`의 실패는 해당 패널에 표시하고 다른 편집 기능은
유지합니다. `storage`가 없으면 저장된 양식 관련 명령을 표시하지 않습니다.

## 출력 이벤트

유효한 편집이 양식을 바꿀 때마다 `slip-change`를 발생시키고 `detail.file`에 전체
`SlipTemplateFile`을 담습니다. 선택, 패널 열기와 미리보기 이동처럼 파일을 바꾸지 않는 동작은
이벤트를 발생시키지 않습니다.

## 편집 세션

디자이너는 선택, 실행 취소·다시 실행, 클립보드, 현재 원본·출력 페이지와 대화상자 상태를 내부에서
관리합니다. 호스트는 이벤트 결과를 저장할 수 있지만 같은 `src`로 계속 되돌려 내부 세션을
재생성하지 않습니다.

## 오류 처리

입력 파일이 양식이 아니거나 파싱에 실패하면 편집 화면 대신 오류를 표시합니다. 요소·파라미터 키,
용지, 이미지와 수식 입력 오류는 관련 컨트롤에 표시하고 파일을 바꾸지 않습니다. 저장소 오류는
목록·저장·삭제 작업별로 표시합니다.
