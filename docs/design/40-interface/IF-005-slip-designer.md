# IF-005 `<slip-designer>`

최종 갱신: 2026-09-28

## 개요

양식 파일을 시각적으로 편집하는 Web Component의 입력, 확장 설정, 출력 이벤트와 저장소 연결 계약을
정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 디자이너의 공개 프로퍼티, 이벤트와 호스트 확장 지점을 정의했습니다. |

## 제공자와 소비자

Elements 패키지가 제공하고 양식 편집 화면을 포함하는 호스트와 프레임워크 래퍼가 소비합니다. 호스트는
초기 양식과 확장 설정을 전달하고, 변경 이벤트의 전체 양식을 업무 저장소에 보관합니다.

## 호출 방향과 사용 조건

요소를 연결한 뒤 편집할 양식과 선택 설정을 프로퍼티로 전달합니다. 입력은 양식 파일이어야 하며 전표는
편집 세션을 시작하지 않습니다. 저장소가 없으면 로컬 저장 명령을 노출하지 않습니다.

## 입력·출력 또는 이벤트 계약

| 이름 | 방향 | 호출·발생 시점 | 입력·상세 자료형 | 반환·전달값 | 생략·오류 처리 |
| --- | --- | --- | --- | --- | --- |
| `src` | 호스트→요소 | 최초 연결 또는 다른 양식 열기 | 양식 `.slip` JSON 문자열 | 새 편집 세션 | 없으면 양식 없음, 전표·손상 파일이면 오류 화면 |
| `locale` | 호스트→요소 | 연결 전후 | 로케일 문자열 | 화면 문구 변경 | 생략하면 SlipKit 로케일 또는 기본값 |
| `slipkit` | 호스트→요소 | 연결 전후 | `SlipKit` 인스턴스 | PDF·수식·폰트·암호화 설정 공유 | 생략하면 요소가 기본 인스턴스 사용 |
| `settings` | 호스트→요소 | 연결 전후 | 용지·바코드 비동기 제공 함수 | 속성 패널 선택지 | 조회 실패는 해당 패널에 표시 |
| `presets` | 호스트→요소 | 연결 전후 | 양식 프리셋 배열 | 프리셋 메뉴 | 생략하면 동봉 목록 사용 |
| `storage` | 호스트→요소 | 연결 전후 | `StorageAdapter` | 저장·목록·불러오기·삭제 | 생략하면 관련 명령 숨김 |
| `maxImageBytes` | 호스트→요소 | 이미지 선택 전 | 양의 정수 바이트 | 업로드 검사 상한 | 생략하면 2MiB |
| `slip-change` | 요소→호스트 | 유효한 문서 변경 확정 직후 | `CustomEvent` | `detail.file`의 전체 양식 | 실패한 변경과 선택 변경에는 발생하지 않음 |

`settings.getPaperSizes`와 `settings.getBarcodeKinds`의 실패는 해당 패널에 표시하고 다른 편집 기능은
유지합니다. `storage`가 없으면 저장된 양식 관련 명령을 표시하지 않습니다.

## 동기·비동기 처리

일반 편집과 변경 이벤트는 같은 사용자 동작 안에서 끝납니다. 설정 조회, 저장소와 PDF 미리보기는
비동기이며 새 요청이 시작되면 이전 요청의 늦은 결과가 현재 화면을 덮지 않게 요청 세대를 비교합니다.

## 생명주기

디자이너는 선택, 실행 취소·다시 실행, 클립보드, 현재 원본·출력 페이지와 대화상자 상태를 내부에서
관리합니다. 호스트는 이벤트 결과를 저장할 수 있지만 같은 `src`로 계속 되돌려 내부 세션을
재생성하지 않습니다.

연결 해제 시 전역 이벤트 리스너, 진행 중인 미리보기 표시와 Blob URL을 정리합니다. 다시 연결하면 현재
입력에서 세션을 다시 구성합니다.

## 반복 호출·동시 호출

편집 명령은 발생 순서대로 적용하고 한 명령마다 변경 이벤트를 최대 한 번 발생시킵니다. 같은 양식을
연속 저장하면 저장소가 정한 덮어쓰기 규칙을 따릅니다. 다른 양식을 열면 이전 양식의 저장·미리보기
결과를 무시하고 선택, 복사 내용과 실행 기록을 초기화합니다.

## 오류 처리

입력 파일이 양식이 아니거나 파싱에 실패하면 편집 화면 대신 오류를 표시합니다. 요소·파라미터 키,
용지, 이미지와 수식 입력 오류는 관련 컨트롤에 표시하고 파일을 바꾸지 않습니다. 저장소 오류는
목록·저장·삭제 작업별로 표시합니다.

## 호환성·보안·확장 경계

공개 프로퍼티와 `slip-change` 이벤트만 호스트 계약입니다. 내부 패널 DOM과 편집 상태 객체는 공개하지
않습니다. 외부 파일, 프리셋, 설정 조회 결과와 저장소 반환값은 검증한 뒤 사용합니다.
