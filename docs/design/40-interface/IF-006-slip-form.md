# IF-006 `<slip-form>`

최종 갱신: 2026-09-28

## 개요

양식 또는 미발행 전표를 입력받아 값을 작성하고 전표를 발행하는 Web Component의 계약을 정의합니다.

## 변경 이력

| 날짜 | 구분 | 변경 내용 |
| --- | --- | --- |
| 2026-09-28 | 신규 작성 | 작성 폼의 입력, 변경·발행 이벤트, 초기화와 오류 처리를 정의했습니다. |

## 제공자와 소비자

Elements 패키지가 제공하고 전표 작성 화면을 포함하는 호스트와 프레임워크 래퍼가 소비합니다. 호스트는
양식 또는 미발행 전표를 전달하고 변경·발행 이벤트의 전체 전표를 업무 저장소에 보관합니다.

## 호출 방향과 사용 조건

요소를 연결한 뒤 양식 또는 미발행 전표를 `src`로 전달합니다. 발행 전표는 읽기 전용으로 표시하며 같은
세션에서 값을 바꾸거나 다시 발행하지 않습니다.

## 입력·출력 또는 이벤트 계약

| 이름 | 방향 | 호출·발생 시점 | 입력·상세 자료형 | 반환·전달값 | 생략·오류 처리 |
| --- | --- | --- | --- | --- | --- |
| `src` | 호스트→요소 | 최초 연결 또는 다른 전표 열기 | 양식·전표 `.slip` JSON 문자열 | 작성 또는 읽기 전용 세션 | 없으면 빈 상태, 손상 파일이면 오류 화면 |
| `locale` | 호스트→요소 | 연결 전후 | 로케일 문자열 | 화면 문구 변경 | 생략하면 SlipKit 로케일 또는 기본값 |
| `slipkit` | 호스트→요소 | 연결 전후 | `SlipKit` 인스턴스 | 수식·PDF·폰트 설정 공유 | 생략하면 기본 인스턴스 사용 |
| `maxImageBytes` | 호스트→요소 | 이미지 선택 전 | 양의 정수 바이트 | 이미지 검사 상한 | 생략하면 2MiB |
| `slip-change` | 요소→호스트 | 유효한 값 변경 직후 | `CustomEvent` | `issued: false` 전표 | 오류가 있는 변경에는 발생하지 않음 |
| `slip-issue` | 요소→호스트 | 전체 발행 검증 성공 직후 | `CustomEvent` | `issued: true` 전표 | 검증 실패 또는 중복 발행에는 발생하지 않음 |
| `reset()` | 호스트→요소 | 같은 양식으로 새 작성 시작 | 인수 없음 | `void`, 빈 미발행 전표로 초기화 | 현재 입력을 읽을 수 없으면 상태와 이벤트 유지 |

양식 입력은 빈 값의 미발행 전표 세션을 만들고, 미발행 전표 입력은 저장된 값을 복원합니다. 발행
전표는 읽기 전용으로 취급하며 새 작성 세션으로 바꾸지 않습니다.

## 동기·비동기 처리

일반 값 변경과 `slip-change`는 같은 입력 처리 안에서 끝납니다. 이미지 읽기와 PDF 미리보기는
비동기이며, 최신 값 세대와 일치하는 결과만 표시합니다. 발행 중에는 발행 버튼을 잠그고 모든 검증이
끝난 뒤 이벤트를 한 번 발생시킵니다.

## 생명주기

같은 양식으로 새 전표를 시작할 때는 공개 `reset()` 메서드를 호출합니다. 이 메서드는 현재 `src`를
다시 해석해 값을 지우고 발행 상태를 해제한 뒤 `slip-change`를 발생시킵니다. `src`를 읽을 수 없으면
파일과 이벤트를 바꾸지 않습니다. 요소를 다시 마운트하는 방법도 사용할 수 있지만 같은 `src`
문자열을 다시 쓰는 것만으로는 발행 상태를 해제하지 않습니다. 구성 요소가 연결 해제됐다가 다시
연결되면 현재 값으로 미리보기를 복구합니다.

## 반복 호출·동시 호출

연속 값 변경은 발생 순서대로 최신 값 객체에 적용합니다. 오래된 미리보기 성공·실패는 버리고 Blob
URL을 해제합니다. 발행 호출이 겹치면 첫 호출만 처리하고, `reset()`은 진행 중인 미리보기와 발행 결과를
무효로 만든 뒤 변경 이벤트를 한 번 발생시킵니다.

## 오류 처리

파라미터 종류에 맞는 입력 컨트롤을 만들고 수식 결과를 읽기 전용으로 표시합니다. 이미지 업로드는
형식, 파일 서명과 크기를 검사합니다. 파싱, 수식, 값 검증과 PDF 미리보기 오류는 각각 관련 영역에
표시하고 값 데이터는 임의로 버리지 않습니다.

## 호환성·보안·확장 경계

프로퍼티, 두 이벤트와 `reset()`이 공개 계약입니다. 입력 컨트롤의 내부 DOM은 계약이 아닙니다. 발행
여부는 UI 잠금 정보이며 사용자 인증, 전자서명과 감사 기록을 대신하지 않습니다.
